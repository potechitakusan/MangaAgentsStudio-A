# 作例について

Codexの指示に従って漫画制作用の別プロジェクトを作って、簡単なプロンプトで漫画の作成を指示しました。

## 01

以下のプロンプトで作りました。

- 日本の高校
- 仲の良い二人の女の子が、淡い恋心に気付くシーン
- セリフは雑談のみ、画作りでシーンの意味を読者に伝える
- ひとりは黒髪ショートカット、ひとりは茶髪ハーフアップ
- ハーフアップの女の子の方が恋心に気付く

以下はいったん作成後に人間が修正指示しました。

- セリフ中の「！」「？」「…」は一を指定して追加
- 一部の破綻は人間が目視で見つけ、修正指示

## 02

以下のプロンプトで作りました。

- ファンタジー漫画で魔法バトルトーナメントの決勝戦を漫画で描いてください。
- キャラクターはどちらも女の子で、幼馴染です。属性の違う魔法が得意です。絵柄はポップな感じで、どちらも強いです。
- なるべくセリフは少なめにして、イメージで説明してください。最後は強い光でどっちが勝ったかわからないコマにしてください。

以下はいったん作成後に人間が修正指示しました。

- 空中戦を追加する
- 単調にならないようにコマの区切りを一部斜めにする

## 03

character1.png、character2.png は、事前にChatGPTに相談しながら作ってinputフォルダに格納しました。

以下のプロンプトで作りました。

- inputフォルダの画像の二人のキャラクターを参照して、ファンタジー世界で「雨の日の約束」というタイトルの漫画を作ってください。
- フキダシによるセリフは、文字ではなくイメージや記号で伝わるようにしてください。

自動での作成後に人間が修正や修正指示した部分はありません。
