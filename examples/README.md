# 作例について

Codexの案内に従って、このキットとは別に漫画制作用のプロジェクトを作成し、
その後、簡単なプロンプトで制作した漫画の作例です。

## 01

制作時に使用したプロンプトです。

- 日本の高校
- 仲の良い二人の女の子が、淡い恋心に気付くシーン
- セリフは雑談のみ、画作りでシーンの意味を読者に伝える
- ひとりは黒髪ショートカット、ひとりは茶髪ハーフアップ
- ハーフアップの女の子の方が恋心に気付く

生成された漫画を人間が確認し、次の修正を指示しました。

- セリフ中の「！」「？」「…」を追加する位置を指定しました。
- 絵の一部に見られた不自然な箇所を目視で確認し、修正を指示しました。

## 02

制作時に使用したプロンプトです。

- ファンタジー漫画で魔法バトルトーナメントの決勝戦を漫画で描いてください。
- キャラクターはどちらも女の子で、幼馴染です。属性の違う魔法が得意です。絵柄はポップな感じで、どちらも強いです。
- なるべくセリフは少なめにして、イメージで説明してください。最後は強い光でどっちが勝ったかわからないコマにしてください。

生成された漫画を人間が確認し、次の内容で修正を指示しました。

- 空中戦を追加する
- 単調にならないようにコマの区切りを一部斜めにする

## 03

参照用のキャラクター画像（`03/character1.png`、`03/character2.png`）は、事前にChatGPTに相談しながら作成し、作品プロジェクトの `input` フォルダに保存しました。

制作時に使用したプロンプトです。

- inputフォルダの画像の二人のキャラクターを参照して、ファンタジー世界で「雨の日の約束」というタイトルの漫画を作ってください。
- フキダシによるセリフは、文字ではなくイメージや記号で伝わるようにしてください。

自動生成後、人間による修正や追加の修正指示は行っていません。

## 04

参照用のキャラクター画像（`04/character1.png`、`04/character2.png`、`04/robot1.png`）は、事前にChatGPTに相談しながら作成し、作品プロジェクトの `input` フォルダに保存しました。

制作時に使用したプロンプトです。

- タイトル『少しだけ寂しいボクらの世界で』
- メインのキャラクターはinputフォルダのpng画像を参照してください。他のキャラクターも、絵柄が同じものを適宜追加してよいです。赤ちゃん以外は全てロボットです。
- フキダシは基本的にイメージと記号のみにしてください。四角い枠の中のナレーションは文字でOKです、この世界観や設定を説明する際のみナレーションを使ってください。
- character1が主人公です。
- 世界は、人類が感染症で滅びてから300年後、ロボットたちが平和に暮らしていました。ロボットは思い思いの場所に住んでいるので、森の中だったり、近代的な街などいろいろです。
- 主人公は森の中で気楽に平和に暮らしていたが、ある日、森の中で謎の施設を見つける。そこには、滅びたはずの人間の赤ちゃんが泣いている。生後10日前後。
- 人間向けの食べ物は施設に少しあったが、長くても一年分ぐらいしかない。
- 人見知りの主人公だったが、前に助けてもらった科学者のロボットのことを思い出し、その相手に相談をしに向かう。
- その後のストーリーは随時足していってください。世界観の設定も適宜追加してください。
- 赤ちゃんが徐々に大人になっていきます。ストーリーは、最終的に15～20話ぐらいで、最後は○○（※ここはネタバレなので省略、実際にはざっくり書きました）。
- 1話あたり10ページ前後、いったん全体のプロットを作ってから、各話を作成してください。

１回のセッションだと最後まで作り切れなかったので、何回か「続きを作成してください」のように依頼しました。
自動生成後、人間による目視で、手の破綻の修正を一部指示しました。（まだちょっと残っています）
