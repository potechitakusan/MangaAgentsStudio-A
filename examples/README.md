# 作例について

Codexの案内に従って、このキットとは別に漫画制作用のプロジェクトを作成し、
その後、簡単なプロンプトで制作した漫画の作例です。

## 01

制作時に使用したプロンプトです。

- 日本の高校
- 仲の良い二人の女の子が、淡い恋心に気付くシーン
- セリフは雑談のみ、画作りでシーンの意味を読者に伝える
- ひとりは黒髪ショートカット、ひとりは茶髪ハーフアップ
- ハーフアップの女の子の方が恋心に気付く

生成された漫画を人間が確認し、次の修正を指示しました。

- セリフ中の「！」「？」「…」を追加する位置を指定しました。
- 絵の一部に見られた不自然な箇所を目視で確認し、修正を指示しました。

## 02

制作時に使用したプロンプトです。

- ファンタジー漫画で魔法バトルトーナメントの決勝戦を漫画で描いてください。
- キャラクターはどちらも女の子で、幼馴染です。属性の違う魔法が得意です。絵柄はポップな感じで、どちらも強いです。
- なるべくセリフは少なめにして、イメージで説明してください。最後は強い光でどっちが勝ったかわからないコマにしてください。

生成された漫画を人間が確認し、次の内容で修正を指示しました。

- 空中戦を追加する
- 単調にならないようにコマの区切りを一部斜めにする

## 03

参照用のキャラクター画像（`03/character1.png`、`03/character2.png`）は、事前にChatGPTに相談しながら作成し、作品プロジェクトの `input` フォルダに保存しました。

制作時に使用したプロンプトです。

- inputフォルダの画像の二人のキャラクターを参照して、ファンタジー世界で「雨の日の約束」というタイトルの漫画を作ってください。
- フキダシによるセリフは、文字ではなくイメージや記号で伝わるようにしてください。

自動生成後、人間による修正や追加の修正指示は行っていません。
