# 文書の入口

このフォルダは制作キットの保守・配布用です。まず `scripts/New-MangaProject.ps1` でキット外に作品プロジェクトを作り、表示された絶対パスのフォルダでCodexを開き直します。その作品側で[制作プロセス](knowledge/manga/08-workflow-review.md)に沿い、企画からPNG確認、指示のあるPSDの引き渡しまでを進めます。キット内での制作は[READMEの例外手順](../README.md#どうしてもこのキット内で漫画を作る場合の例外)がそろうまで始めません。

| 知識と雛形を選ぶ | [ノウハウ一覧](../templates/manga-project/docs/MANGA-KNOWHOW.md) |
