# コマ割りテンプレートの使い方

更新・確認日：2026-09-20。日本語右開きのページ漫画で、ページの形と緩急を検討するときに参照する。

## 適用する場面

字コンテからページ配置を決める段階、またはコマ割りの反復をレビューするときに使う。企画相談やセリフだけの修正では、詳細資料やカタログを読み込む必要はない。

制作開始時は [オプションの適用手順](project-options.md) に従い、作品の `OPTION.md` を反映した採用率を一度説明する。テンプレートを使用しない指定なら、テンプレート由来の割合・反復制限とID検証は適用しない。割合や反復制限はキットの初期設定であり、漫画一般の品質基準ではない。ユーザー指定を優先し、短編、４コマ漫画、縦スクロール、意図的な反復などには一律に当てはめない。

## 原則使用とページ単位の例外

既定の「原則使用する」と「使用する」は、テンプレートを利用する実行方針。ページ作画の生成前に、テンプレートを使うページの採用IDを決める。

既存テンプレートでは意図した演出を十分に表現できない場合、Codexは該当ページを独自のコマ割りにできる。対象ページ・演出意図・不使用の理由を `docs/production/PANEL-LAYOUT-POLICY.md` のページ別記録へ残す。この判断に都度の承認は不要で、作品全体のOPTIONを「使用しない」へ変更しない。単なる選び忘れや、生成結果が違う配置になったことを後付けの演出理由にしない。

ユーザーが「必須」と指定した範囲ではこの例外を使わない。「使用しない」と指定した場合は自由に設計し、各ページで既存テンプレートでは表現できない理由を求めない。いずれも生成前の配置・読み順の設計と生成後の照合は行う。

## 選択と確認

1. ページの感情の変化、見せ場、必要な出来事からコマ数を考える。
2. [作品のコマ割り方針](../production/PANEL-LAYOUT-POLICY.md)の該当節と、[一覧](../../templates/panel-templates/index.html)を参照する。全79種類から、用途とコマ数で候補を絞る。
3. 採用ID、または独自配置とその理由をページ別記録へ残す。座標が必要になったら、選んだIDの個別JSONを読む。`catalog.json` 全文は会話へ展開せず、スクリプトで必要な候補・項目だけ抽出する。
4. 全ページがテンプレートを使う割当て案は、作品の設定に合わせて `scripts/validate_panel_plan.py` で検査できる。同スクリプトは全ページに既存IDを要求し、独自配置には未対応。混在する計画はページ別記録と実際の配置で点検し、架空IDを付けたり例外ページを抜いて詰め直したりして検査しない。未実行の自動検査を合格扱いにしない。短い相談や部分修正のたびに計画JSONの作成を必須にしない。
5. 各コマに出来事・演技・セリフを読み順の番号で割り当て、絵と本番量の文字を置く。読み順、顔の大きさ、余白、前後の緩急を確認する。数値検査だけで読みやすさを判定しない。

独自配置を含む場合も全ページの実際のコマ数と緩急を確認する。横長３段等の反復は実際の形状と元のページ番号で数え、独自配置という名前で制限を回避しない。演出に伴う採用割合の調整は理由を記録する。作品全体で「使用しない」を採用した場合は、テンプレート由来の配分・制限は非適用とする。

## imagegenへ渡すものと生成後の照合

imagegenではページ全体の一括生成を基本とする。テンプレートを使うことはコマ別生成を意味しない。キャラ参照絵の作成などページ作画ではない生成には、このページ別の準備を要求しない。

1. ページ作画の生成前に、コマ配置と読み順を確定する。テンプレートを使う場合は `templates/panel-templates/previews/ID.png` を番号付き参照画像として使える。作品の寸法・余白・配置を変えた場合は [ページ設定](page-layout.md) に従って配置し直し、その配置に読み順の番号を付けた参照画像を作る。独自配置も同様に番号付きの画像へ描き起こす。
2. 参照画像を目視し、番号・配置が字コンテと対応することを確認して、画像入力に対応するimagegenへ実際に渡す。IDやファイルパスをプロンプトへ書くだけで添付済みと扱わない。キャラ参照絵を併用するときは、どれがレイアウト・人物の参照かを区別する。
3. 各番号に対応する場面・人物の演技・確定セリフを指定し、コマ数・配置・読み順を保った１ページの漫画として生成する。「番号・色分け・補助線は説明用で、完成画像には描かない」と伝える。枠・吹き出し・文字を含めた生成も許容する。文字を後置きする指定や、分離したPSD要素が必要な場合は、その制作条件を優先する。
4. 生成後は実寸と、コマ数・配置・読み順・各コマの内容・人物・セリフ原文・番号等の混入を実画像で照合する。ずれや誤字は修正し、参照画像を渡しただけで再現できたとみなさない。分割位置がずれた絵へ、枠だけを重ねて直った扱いにしない。

ページ別記録には採用IDまたは独自配置、演出意図・例外理由、番号付き参照画像、各コマの内容を記した字コンテ、生成方式、出力画像と照合結果を相対パスで残す。コマ別生成は必要な場合に選び、その理由も記録する。NovelAI等にはimagegenの一括生成・参照画像入力を一律に要求せず、各環境の制作手順と費用条件に従う。

ページ寸法・基本枠・文字安全範囲は [ページ設定](page-layout.md) に従い、コマの分割形状と分けて管理する。初期値は既存素材と同じ配置。好みに応じて余白やガイドを変更できる。最終PNGへガイドやカタログの番号を含めない。

割合・制限の値は [作品設定](../../config/panel-layout-policy.json)、形式・演出の説明は [作品のコマ割り方針](../production/PANEL-LAYOUT-POLICY.md)にまとめる。

## 根拠と適用範囲

- 出典：ユーザー提供の制作フィードバック。取得日：2026-09-15。外部公開URLなし。個別作品の情報・評価原文・制作履歴は配布に含めず、汎用的な選択手順だけを整理した。
- 運用指定：2026-09-20のユーザー指示により、原則使用・演出上のページ単位の例外・番号付き参照画像を渡すimagegenのページ一括生成を採用。外部公開URLなし。一般的なモデル性能の保証ではなく、このキットの制作手順として適用する。
- 制作提案：枠の候補を先に用意し、ページの輪郭の反復を点検する。初期割合は調整の出発点として使う。
- 未検証：この割合によって読者評価が改善するかどうか、番号付き参照画像に生成結果が正確に従うか。テンプレートの幾何学的な検査、実際の生成画像の照合、読者による評価は別に扱う。
