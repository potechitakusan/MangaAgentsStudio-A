# Web用ページの寸法・基本枠

更新日：2026-09-20。ページ漫画をインターネットで読むための制作設定。数値は本キットの初期案で、投稿サイトの必須仕様や読者効果を保証する値ではない。

## 生成・配置・書き出しの関係

キャラ・あらすじ・ページ数があれば、右から左へ読む単ページ漫画を作る。白地、PNG、画面用のRGB・sRGBを基準とし、モノクロ表現もこの書き出しで扱える。寸法は次の３段階で決める。全項目への回答は求めず、未指定ならCodexが使用ツールに合わせて仮決めする。

| 段階 | 何の寸法か | 既定の扱い |
| --- | --- | --- |
| 生成する寸法 | ツールに希望する幅×高さと、実際に得られた画像の幅×高さ | 縦長2:3を目安にツールの対応寸法から選ぶ。希望値と実寸は別に記録する |
| 枠を合わせる寸法 | 絵・コマ枠・文字を配置する作業用ページ | １ページ全体を生成する場合は、生成画像の実寸に合わせる |
| 最終PNGの寸法 | 読者へ渡すページ画像 | 枠配置と同じ。指定がある場合だけ別寸法で書き出す |

例えば生成結果が1024×1536pxなら、既定では枠配置も最終PNGも1024×1536pxになる。この数値は説明例であり、内蔵画像生成ツールの固定出力サイズではない。「最終PNGを2000×3000pxにする」は書き出しの指定で、生成がその寸法で行われる保証ではない。単に「3000px」と案内せず、幅×高さと対象の段階を示す。

１ページ全体を生成する場合は、次の順に進める。

1. 使用ツールで指定できる寸法を確認する。imagegenでは [コマ割りの手順](panel-layout-policy.md) に従い、テンプレートまたは演出上の独自配置を決め、番号付きレイアウト画像と各コマの内容を実際に渡す。予定寸法で仮配置し、任意の幅×高さを指定できないツールには、対応していない設定を渡さない。
2. 生成後、保存された画像の実寸を読む。予定寸法で作った枠を無条件に重ねず、実寸に合わせて枠を再配置する。生成結果のコマ位置が枠と一致するかは実画像でも確認する。
3. 最初に採用した枠配置寸法を作品の共通値として `canvas` に記録する。以後の生成画像が異なる寸法なら、同じ縦横比での拡縮か、配置・切り抜きの調整かを区別する。元画像は保持する。
4. 絵・フキダシ・確定文字・必要な枠を整える。imagegenで一括生成した要素は確認して使い、不足・修正が必要な要素を別工程で合成する。既定ではこの寸法のままPNGにする。

コマごとに生成する方式では、各コマの生成画像と組み立て先のページは別の寸法になる。必要な掲載条件とコマ内の画素数を基にページ寸法を決め、`canvas` へ設定する。１コマの画像をページ全体の実寸として扱わない。

投稿先が指定されたときは、その公式の寸法・容量・形式条件を確認して公開用コピーへ反映する。実際に用いた色設定と書き出し方法は制作仕様に残す。画素数を増やすだけで元の絵の細部が増えるとは扱わない。外部への投稿は人間が判断する。

## 余白・線幅を寸法に連動させる

同梱の枠素材PNGは2000×3000px。この値は素材原本と換算の基準として保持し、生成・最終PNGの既定寸法にはしない。

| 設定 | 基準2000×3000pxでの値 | 枠配置寸法への換算 |
| --- | --- | --- |
| 基本枠の余白 | 上下左右120px | 左右は幅の倍率、上下は高さの倍率を掛ける |
| 文字安全範囲の余白 | 上下左右160px | 左右は幅の倍率、上下は高さの倍率を掛ける |
| 枠線 | 10px | 幅・高さの倍率の小さい方を掛ける |
| 確認用ガイド | 線幅3px、破線16px・間隔10px | 枠線と同じ倍率を掛ける |

1024×1536pxなら倍率は0.512で、基本枠の余白61.44px、文字安全範囲81.92px、枠線5.12pxになる。配置計算とSVGでは小数を保持し、画像化する段階で描画する。縦横比を変える場合、左右・上下は別倍率、線は一つの倍率で換算する。絵や文字は縦横に引き伸ばさず配置を見直す。

作品の `config/page-layout.json`（版2）で設定する。`OPTION.md` の採用値をCodexが反映する。

- `generationCanvas`：生成時の希望寸法。`null` は使用ツールに合わせる。指定してもこの配置処理から画像生成は実行されない。
- `canvas`：枠配置の幅・高さ。`null` は生成画像の実寸に合わせる。生成前は希望寸法または `--canvas` で仮配置する。
- `exportCanvas`：最終PNGの幅・高さ。`null` は枠配置と同じ。ここへの指定だけで画像の拡縮・PNG保存が実行されるわけではない。
- `referenceCanvas`：余白・線幅の換算元。既定は2000×3000。`basicFrame`、`textSafeArea`、`frameStroke` はこの基準での数値。サイズ変更のたびに基準から換算し、換算後の値をここへ書き戻さない。
- `fixedPixels`：連動させず、枠配置時のpxで固定したい項目だけを指定する。例：`{"basicFrame":{"left":80},"frameStroke":6}`。他の余白は自動換算する。最終書き出しでページ全体を拡縮するときは、固定指定の値も合成画像と一緒に拡縮される。
- `showGuide`：確認専用ガイドの表示。掲載PNGには含めない。

旧版1の設定も読み込める。従来の `canvas` と余白・線幅のpx指定をそのまま使い、`--canvas` で寸法を変更した場合は元の `canvas` を基準として換算する。既存作品を版2へ移す場合は、従来の寸法を `referenceCanvas` と `canvas` の両方に保持し、元の余白・線幅を保持する。自動寸法へ切り替える指示がなければ `canvas` を `null` にしない。

## 枠の配置とガイド

基本枠は配置の基準であり、絵を切り抜くマスクではない。はみ出しは意図と読順を確認して使える。コマを分ける線、ページ端、文字の目安とは区別する。

作品ルートから実行する。Python 3.10以上の標準ライブラリだけを使う。

```powershell
# １ページ全体の生成PNGの実寸に合わせる。PNGの内容は変更しない
python scripts/prepare_page_layout.py --template P5-212-equal-normal-straight --page-image output/page-001-art.png --output output/layout/page-001-v1 --guide
# 生成前の仮配置、またはコマ別制作のページ寸法を指定する例
python scripts/prepare_page_layout.py --template P5-212-equal-normal-straight --canvas 1024 1536 --output output/layout/page-001-v2
```

枠配置寸法は `--canvas` → 設定の `canvas` → `--page-image` の実寸 → `generationCanvas` の順で採用する。全て未指定なら寸法を決める案内を出し、3000pxへ自動的に置き換えない。画像を渡していない段階の生成実寸は未確認として記録する。

- `frames.svg`：枠配置寸法の透明なコマ枠。最終合成に使える。
- `guide.svg`：`showGuide: true` または `--guide` の場合だけ出力する透明な補助線。青が基本枠、紫が文字安全範囲、茶が人物ぶち抜き領域。編集画面で別に重ね、表示・非表示を切り替える。`--no-guide` なら設定にかかわらず生成しない。
- `layout.json`：換算後の座標・余白・線幅と、生成希望寸法、生成実寸（未確認なら `null`）、枠配置寸法、最終PNG寸法、変換倍率を記録する。原本の79種と設定ファイルは変更しない。

`prepare_page_layout.py` は既存テンプレートIDを使う枠配置処理であり、独自配置の作成や番号付き参照PNGの出力は行わない。出力の `guide.svg` は基本枠等の補助線で、カタログの番号付き `guides/ID.svg` とは別物。変更後の配置や独自配置をimagegenへ渡す場合は、配置座標に読み順の番号を加え、利用可能な描画手段で参照PNGを別に用意する。独自配置でも作品のページ寸法・余白・線幅の設定を引き継ぐ。

SVGを参照PNGや合成用画像にする場合は、利用可能な描画手段でSVGの幅×高さどおりに書き出す。同梱の2000×3000pxの枠PNGを、異なる寸法の絵へ無変換で重ねない。この処理は枠の配置までで、SVGの画像化、絵の拡縮、画像生成、最終合成は各制作工程で行う。

生成画像→枠配置、枠配置→最終PNGの縦横比が異なる指定は、この処理ではエラーにする。余白追加・切り抜き・再配置などの方針を決め、別工程で調整した後の画像・配置寸法を使う。

比率変更で変換するのは枠と演出領域だけ。絵・文字は配置を見直し、縦横伸縮しない。人物ぶち抜きの枠消しは、実際の人物の輪郭に合わせて行う。ツールは文字の可読性やはみ出しの演出を自動判定しない。出力先は毎回新規のフォルダにし、過去のガイドを誤使用しない。

このツールは元テンプレートの読む順を保持する。左から読む形式や縦スクロールなどを選んだ場合は、配置・読順も設計し直し、既存テンプレートを必須にしない。最初の実寸確認や依頼どおりの設定反映のために、ユーザーへ同じ寸法の承認を繰り返し求めない。

## 書き出し時の確認

別寸法で書き出す場合は、同じ縦横比なら絵・枠・文字をまとめて同倍率で拡縮するか、各要素を同じ倍率で再配置・描画する。最終PNGを2000×3000pxにしたい場合もこの工程で扱う。用いた手段、元寸法、先寸法、倍率を `docs/production/PSD-HANDOFF.md` に残す。

最終PNGには絵・フキダシ・確定文字・必要なコマ枠をそろえる。一括生成済みの枠や文字を確認せず二重に重ねない。`guide.svg` やカタログの番号付きプレビューは参照用とし、最終PNGへそのまま合成しない。生成画像に番号・色分け・補助線が残った場合も修正する。ガイド表示の有無で絵と枠の座標が動かないこと、ページ端の文字欠けがないこと、掲載相当の縮小で読めることを実画像で確認する。PSDにガイドを渡す場合は「補助線」等の独立した非表示レイヤーにし、再読込した合成結果にも混入していないことを確かめる。

印刷を選んだ場合だけ、作品ルートの [PRINT-OPTION.md](../../PRINT-OPTION.md) を使う。

## 根拠と限界

- 確認事実：[CLIP STUDIO公式・基本的なコマ枠の作り方](https://tips.clip-studio.com/ja-jp/articles/610)は基本枠のサイズ・余白指定とコマ枠配置を説明している。取得日：2026-09-19。適用範囲は同ソフトの基本枠設定。
- 制作提案：生成・配置・書き出しの寸法を区別し、実寸に合わせて枠を換算する。基準寸法と基本枠120pxは既存素材との互換を保持するための値。文字安全範囲160pxと、異なる縦横倍率での線幅の扱いはキット独自の出発点。
- 未検証：この余白や画素数による読者評価の改善、すべての生成ツール・投稿先への適合、印刷への適合。生成画像が枠の座標に正確に従うことは寸法指定だけでは確認できない。
