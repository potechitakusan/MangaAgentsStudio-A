# 制作オプションの適用手順

更新日：2026-09-20。作品プロジェクトの制作開始・再開・設定変更に適用する。ユーザーの設定ファイル・Web制作を基本とする依頼に基づく運用手順。NovelAI Opusの仕様・出典は [AI制作](ai-production.md#novelai-opus)を参照。

## 読むタイミング

作品ルートの `OPTION.md` を制作開始時に読む。再開時と、字コンテ・ネーム・作画・文字配置・納品へ着手する前は、ファイルの有無とSHA-256を前回の記録と比較する。変更がある場合だけ本文を読み直す。常駐監視や毎コマの読み込みは不要。この手順書も初回と変更処理に必要なときだけ参照する。

`OPTION.md` はCodexが解釈して制作判断と関連設定へ反映する。推敲スキルの初期化だけは該当行を直接読み取れる。ページ設定・コマ割り等の処理は、採用した値を設定JSONへ反映してから実行する。

## デフォルト

この表を、`OPTION.md` の欠落・項目削除・空欄の際の既定値として使う。ユーザーが編集するのは作品の `OPTION.md`。キットの既定値を変更するときは、この表と雛形を合わせて保守する。

| 項目 | デフォルト |
| --- | --- |
| 掲載形式 | Web用の単ページ漫画・右から左。縦長2:3を目安に使用ツールに合わせる |
| 生成する画像の寸法 | 使用する画像生成ツールに合わせる。実寸は生成後に確認 |
| NovelAI Opusの生成条件 | Anlasを消費しない条件に合わせる。１回１枚・28ステップ以下。初期値はV5で23、V4.5以前で28。参照等の追加機能は既定で使わない |
| 枠を合わせる寸法 | １ページ全体の生成画像と同じ。コマ別生成では組み立て先のページ寸法を決める |
| 最終PNGの寸法 | 枠を合わせる寸法と同じ（拡大なし） |
| 基本枠の余白 | ページ寸法に連動。基準2000×3000pxで上下左右120px |
| 文字安全範囲の余白 | ページ寸法に連動。同じ基準で上下左右160px |
| 枠線の太さ | ページ寸法に連動。同じ基準で10px |
| 基本枠ガイド | 表示しない |
| 日本語推敲スキル | 使用しない |
| 日本語推敲の対象 | 台詞・内語（スキル有効時のみ） |
| コマ割りテンプレート | 使用する |
| コマ数別の採用率 | ５コマ60％・４コマ15％・３コマ15％・６コマ10％ |
| 横長３段の反復制限 | 間に４ページ以上・任意の連続20ページで最大３回（傾斜版も合算） |
| 斜め５コマの頻度 | 任意の連続20ページで１回以下を目安にする |
| セリフ・モノローグの文字方向 | 縦書き（絵中の短い説明は横書き可） |
| セリフの文字揃え | 原則上詰め。縦書きの各列の書き出しを上でそろえる |
| セリフ・ナレーションの句読点 | 「。」は使わない。「、」は１枠20文字以上で長文を読みやすく区切るために必要な場合だけ。つながった枠は１個として合算 |
| PSD作成 | 作成指示がなければ、作るか聞いて回答を待つ |
| CBZ作成 | 明示依頼時のみ |
| 動画試作 | 明示依頼時のみ |
| フィードバック記録 | 記録を依頼された場合のみ |

## 開始時の適用

1. `docs/PROGRESS.md` で制作が未着手かを確認する。制作開始は作品側で企画・字コンテなどへ着手する時点であり、プロジェクトをコピーしただけの時点ではない。
2. 上表を基に `OPTION.md` の「現在の設定」を項目ごとに重ねる。未記載・空欄は既定値に戻す。説明欄の変更例は設定とみなさない。会話で明示した指定を優先し、その指定を削除したい意図が曖昧なら該当項目だけ確認する。過去にOPTIONから転記したJSONの値を、欠落項目の代わりに使わない。
3. 採用する設定の要点を一度説明する。コマ割りを使う場合は採用率がデフォルトまたは変更後の目安であることも伝える。全項目への回答や設定確認を一律に求めず、キャラ・あらすじ・ページ数があれば未指定の制作詳細は仮決めして進める。希望の絵柄や投稿先、印刷仕様の未指定を制作開始の妨げにしない。
4. 採用した全項目の実効値と出所（既定値／OPTION／会話）、ファイルの有無・SHA-256、適用日、制作開始済みの状態を、作品の `docs/PROGRESS.md` の「制作オプション」に記録する。作品固有の設定や記録を配布元へ戻さない。
5. 最初の作業時に [推敲スキルの初期化](optional-skills.md) を実行する。スクリプトはOPTIONの「日本語推敲スキル」行を読む。会話の指定や変更確認待ちの採用値を使う場合は、実効値を `-Provider` に渡す。無効なら取得しない。Git未導入時のインストールと、Geminiを前提とするスキルの導入・利用枠消費は、それぞれユーザーの明示許可を得る。推敲の保留だけで通常の漫画制作を止めない。

寸法を案内するときは「生成時の希望／生成後の実寸 → 枠配置 → 最終PNG」の順に示す。実寸未確認なら未確定と記し、3000pxなどの長辺だけを生成仕様として案内しない。未指定ならCodexが利用ツールの対応寸法から仮決めでき、追加質問を制作開始の条件にしない。

NovelAIを選び、有効なOpus契約を確認した場合は、[Opusの既定手順](ai-production.md#novelai-opus)でステップ数・枚数・追加機能を決め、採用寸法を含む全設定の費用を確認する。生成寸法は共通のページ設定に従って使用ツールに合わせる。既に会話でOpusと指定されていれば再質問しない。プランが不明なら生成前に確認し、企画・字コンテ等は進められる。この項目が雛形にあるだけでNovelAIの利用・Opus契約・有料生成が指示されたとは扱わない。

旧OPTIONの「掲載形式・ページ寸法」に残る幅×高さは、従来の完成ページ寸法として保持し、生成寸法の指定へ読み替えない。新しい個別項目の指定があればそちらを優先する。既存作品を新しい自動寸法へ無断で変更しない。

## 開始後に変更されていた場合

- ファイルの編集・追加・削除、項目削除・空欄化による既定値への復帰を、採用中の値と比較する。改行・表の整形など意味が変わらない編集は質問せず、確認済みのSHA-256だけ更新する。
- 値が変わる場合は「変更前 → 変更後」と影響する工程を示し、意図した変更か確認する。過去の会話での指定と食い違う編集も、記載値の変更として確認し、古い指定を優先して黙って無視しない。完成済みページにも変更が必要なら、その適用範囲も同時に確認する。回答までは変更を採用値や設定JSONに上書きせず、影響する作業を保留し、無関係な作業は続ける。
- 会話で既に明示された変更、またはその指示どおりにCodex自身が行った編集は再確認しない。開始後に初めてこのファイルが追加された場合や、制作済みなのに採用値の記録がない場合も、初回設定として無条件に採用せず、進捗の決定事項と比較して変更の意図を確認する。
- 「変更確認待ち」の間は、採用中の値、保留する変更、確認済みのファイル状態を分けて記録する。同じ差分を再開のたびに質問し直さず、回答なしを承認とみなさない。回答前に再編集されていたら、新しい差分で確認を取り直す。
- 承認されたら関連設定と採用値を更新する。意図しない変更だった場合は従来値を維持し、その回答と確認済みファイル状態を残す。ユーザーの編集は復元指示なしに書き戻さない。再開時はこの記録を使い、同じ未採用値を自動適用しない。

## 制作と設定への反映

| 対象 | 反映内容 |
| --- | --- |
| 掲載形式・生成寸法・枠配置・最終PNG | 形式は `docs/story/BRIEF.md`。`config/page-layout.json` の `generationCanvas` は生成時の希望、`canvas` は枠配置、`exportCanvas` は最終PNG。`null` はそれぞれツールに合わせる／生成画像の実寸に合わせる／枠配置と同じ。生成寸法の希望は実際の生成ツールへ別途反映し、生成後の実寸と変換倍率を引き継ぎ仕様に残す。詳細は [ページ設定](page-layout.md) |
| NovelAI Opusの生成条件 | 使用時に採用寸法を `generationCanvas` と生成ツールへ反映する。Steps・１回の枚数・参照等の追加機能は生成ツールと作品の制作記録へ反映する。実行前に0 AnlasとV5の利用上限を確認し、不足時は回復を待つ。範囲外の指定や有料利用の扱いは [Opusの手順](ai-production.md#novelai-opus)。他の環境や既存作品へ一律適用しない |
| 余白・枠線・ガイド | 基準値から配置処理が自動換算する。px固定の指定だけ `fixedPixels` へ反映し、未指定の辺や線幅は連動を保つ。換算後の値を基準値へ書き戻さない。ガイド表示を選んでも掲載PNGには含めない |
| 日本語推敲スキル・対象 | 既定は使用しない。有効時は `humanizer-jp` または `japanese-natural-writing` を [初回導入手順](optional-skills.md) で作品内へ自動導入する。Gemini版は環境の有無によらず導入前の利用許可が必要。選択した対象だけ [比較手順](japanese-manga-readability.md#optional-polish) を使う。通常の誤字・話者・意味・原文照合は選択によらず行う |
| コマ割りテンプレートを使用しない | 自由に配置を設計する。テンプレートIDの割当て・検証と、テンプレート由来の採用率・反復制限を要求しない。一般的な読み順・緩急は引き続き点検する |
| 採用率 | `config/panel-layout-policy.json` の `recommended.standardPercent` に反映する。`standard20PageMix` は20ページ相当の目安へ合わせ、端数はページ計画で調整する。最多のコマ数も `hardRules.mostCommonPanelCount` に反映し、同率最多なら `null` にする。５コマ最多を固定しない |
| 横長３段の反復制限 | 同JSONの `hardRules.horizontalThree` の間隔・窓幅・上限に反映する。「制限なし」は `enabled: false`。傾斜版は指定がなければ合算する。説明用の `example` も合わせる |
| 斜め５コマの頻度 | 同JSONの `recommended.diagonalFiveMaximumPer20` に反映する。「制限なし」は `null` |
| 文字方向 | 字コンテ・ネーム・文字配置・読みやすさレビューへ適用する。既定の縦書きを採用済みの横書き指定より優先しない |
| セリフの文字揃え・セリフとナレーションの句読点 | 字コンテ・確定原文・推敲後の文章・ネーム・PNGへ適用する。採用した揃え方と例外は `docs/production/DIALOGUE.md` に記録する。読点の文字数・接続枠の数え方は [上詰めと句読点](japanese-manga-readability.md#dialogue-typesetting)に従い、20文字以上でも不要な読点は入れない |
| PSD | 「作成する」は作成指示として `docs/production/PSD-HANDOFF.md` に記録し、PNGの修正確認後に作成・検証する。「作成しない」「保留」は未作成で維持し、別の指示があるまで質問を繰り返さない。既定値では未依頼なら質問して回答を待つ |
| CBZ・動画 | 採用済みの「作成する」「試作する」は明示依頼として扱い、対象を制作計画に記す。既定値や空欄から依頼を推定しない |
| フィードバック | 採用済みの記録指定は記録依頼として扱い、その対象・頻度に限って `docs/feedback/` に残す。外部送信や共通知識への還元は別の依頼が必要 |

採用率は0〜100％・合計100％の目安とする。率の一部だけを指定した場合、未指定のコマ数は既定値（１・２・７コマなどは０％）を補い、合計が合わなければ確認する。負の回数、意味の取れない値、同じ項目への矛盾する指定も、その項目だけを確認してから使う。勝手に正規化したり既定値へ置き換えて続行しない。コマ割りテンプレートを使用しない場合、非適用の率や制限の調整で制作を止めない。

コマ割りの詳細は必要な段階で [選択手順](panel-layout-policy.md)、PSDは [引き渡し手順](psd-handoff.md) を参照する。外部公開・送信や、PNGの修正がないことの確認は、このファイルの設定から推定しない。

## 印刷オプションとの分離

印刷専用の項目・記録は作品ルートの `PRINT-OPTION.md` に置く。未指定・欠落・空欄は「使用しない」。通常のWeb制作では印刷の詳細を読まず、入稿仕様を質問しない。開始時は印刷用出力の有効・無効だけを確認し、ファイル状態を記録する。変更検出時は有効化の指定が変わったかを確認し、有効な場合だけ詳細を読む。開始後の意味のある変更はOPTIONと同じ確認手順を使う。会話で指示済みなら再質問しない。

数値を記した `config/page-layout.json` は採用設定の反映先。直接編集されていた場合も採用値と比較し、開始後に値が変わるなら上の手順で扱う。設定JSONを黙って雛形の値へ書き戻さない。
