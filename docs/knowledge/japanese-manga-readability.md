# 日本語漫画の読みやすさ

更新: 2026-09-17。外部情報確認日: 2026-09-12。対象: 右開き、縦書きの日本語ページ漫画。伝達・表示条件の制作提案は作品の形式に合わせて使う。読者試験は未実施。

## 基準の区別

出版社の講座で確認できた慣習、作品ごとの方針、制作提案を区別する。読み順を見失う問題は修正対象とし、意図を説明できる演出上の逸脱は、想定読者が読めるかで評価する。

このテンプレートでは**セリフ・モノローグは縦書き**を基本とし、**画中のものの短い説明には横書きも使う**。日本語漫画全体に横書きを禁止する規格ではない。看板・画面表示など描かれた物の表記と、読者へ向けた説明文を区別する。作品の形式に合わせて変更する場合は、対象範囲と理由を制作記録へ残す。

## 絵と台詞に違う仕事を与える（制作提案）

台詞が目的や自己像を示し、絵が実行や結果を示すことで、読者が比較できる。絵で明瞭な結果を、反応の台詞でも説明し直していないかを見る。削除後も主語・対象・因果・動機が分かることを条件に、重複した説明を短くする。

発話、内語、地の文を区別し、誰に届く情報かを明らかにする。他者の内語を聞いたように応答させない。画面外の声や場所をまたぐ声は、どの人物・時空間に属するかを示す。

## 読む順と理解する順をそろえる（制作提案）

- 本番量の文字で話者と返答を追う。文字を小さくする前に、重複する意味や不要な応答を確認する。
- 条件、結論、言い直しを区別する。一定文字数で機械的に分けて、関係を切らない。
- 目立つ語や絵が、想定より先に答えを明かしていないか確認する。題・予告も先に渡る情報に含める。
- 語義・指示対象・保証範囲の読み分けを使う場合は、複数の解釈が元の言葉から成立するかを確かめる。
- 想像、人物の推測、実際の結果を区別する。後で覆す推測を、客観的事実として提示しない。

## 視線誘導を三つの大きさで確認する（制作提案）

**見開き・ページ**: 入口を右上、出口を左下に置くのを基本に、コマの読む順を番号で書けるか確かめる。大きな顔・濃いベタ・強い効果文字が、読む前のコマから先に目に入らないかを確認する。右上から左下へ一直線に動くという意味ではない。

段の区切り、長いコマから隣の列へ戻る位置、大きな画面から細部へ移る入口を追う。斜線やはみ出しの使用自体を推奨せず、使った場合に次の入口・文字・顔を隠さないか確認する。複数の像を一画面でまとめた認識として見せるか、時点を順次読ませるかを区別する。

**コマ**: 最初のセリフ→次のセリフ→見せたい反応の順を想定して、人物の位置を決める。すでに構図がある場合も、セリフを置いて読みづらくなったら構図のほうも再検討する。会話の途中で左右を入れ替えるときは背景や向きで位置関係を保つ。

**フキダシ内部**: 上から下に1行を読み、隣の行へ右から左に進む。文節の切れ目とセリフの息継ぎを両立させる。縮小表示したときに句読点・小書き文字・ルビが潰れないかを最終出力寸法で確認する。

| 症状 | 確認点 | 最小の修正候補 |
| --- | --- | --- |
| 返事を先に読んでしまう | 後のフキダシが上や右に張り出していないか | フキダシを移す。必要なら会話を2コマにする |
| しっぽが交差する | 発話順と人物の位置が逆になっていないか | 人物配置を変えるか、相手の寄りへ分ける |
| 次の段へ飛ぶ | コマ間隔と縦の境界が別の経路を作っていないか | 段の区切りを明確にし、間隔を調整する |
| 見せ場の答えが先に見える | 同一ページ・見開きに答えがあるか | 掲載時の表示単位に合わせ、めくり後へ送る |
| 文字が絵を隠す | ラフに本番量のセリフを置いたか | 先に文字領域を確保し、画の重要部分を避ける |

## 動作と位置を追えるようにする（制作提案）

「誰が」「何へ」「どちらに」「何をして」「どうなったか」を追う。接触・結果・目撃者の反応のうち、省くと原因を取り違える部分を補う。全動作を均等に描く必要はない。

細部を続けたため位置関係を失ったら、必要な範囲の全体像で定位する。一定間隔で全景を入れる規則にはしない。音や擬音で行為を伝える場合も、音源と実行の結果が分かるかを見る。

足元・手元・物の差し込みが、後の行為の準備なのか別の意味なのかを確かめる。目立たせた細部を不要な伏線と受け取らせていないかも読む。客観的な全体像と人物から見える範囲を切り替えるときは、視線・位置の手掛かりを残し、主観と実際の出来事の関係を整理する。

## フキダシの意味を一貫させる（制作提案）

下表は本プロジェクトの初期の使い分け案。J03で確認できるのは楕円と強調の基礎までで、トゲ型とウニフラの細かい感情分類は作品内で試す運用である。同じ形が声・心内語・衝撃の複数に使われる作品もあり得るため、形だけで話者や発話の有無を決めない。

| 種類 | 初期の使い方 | レビューで見る点 |
| --- | --- | --- |
| 楕円 | 普通の会話の基準形 | 大きさが声量と不用意に結びつかないか。発話者が特定できるか |
| トゲトゲ／破裂型 | 実際に声を張る、叫ぶ、強い驚きなど | 静かな発話なのに大声へ見えないか。通常会話との強度差があるか |
| ウニフラッシュ | 強い内的反応、衝撃、切迫した思考の強調候補 | 声に出したセリフと区別できるか。線の密度で小さな文字が読めなくならないか |
| 枠なしのモノローグ | 声に出していない言葉の候補。縦書き | どの人物の内面か、時間や語りの主体が分かるか |
| 無言・省略記号 | 返答しない、言いよどむ等の候補 | 「……」だけに頼らず、間の前後に変化があるか |

トゲトゲとウニフラッシュは図形としての見分けも記録する。前者は輪郭自体の角張り、後者は文字の周囲へ集まる多数の線を目印にするが、混合形もある。ツール名と物語上の意味を同一視しない。

## 文字組みと最終寸法（制作提案）

- セリフを縦書きにし、文節での改行候補を作る。括弧や句読点を用いる場合、読みづらい行頭・行末を避ける。意図的な崩しは理由を残す。
- 英文の「何wordsまで」を日本語の文字数に置き換えない。同じ文字数でもルビ、漢字の密度、フキダシ形で必要面積が違う。
- 長いセリフを分けた結果、同じ人物の発話だと分からなくならないか確認する。分割の目的を「話題の転換」「息継ぎ」「反応を挟む」から選ぶ。
- AIが描いた文字をそのまま採用せず、確定セリフを文字レイヤーなどで配置して照合する。誤字・脱字と、読む順・読みやすさは別々に確認する。
- 画面拡大だけで合否を決めない。予定する紙寸法、電子書籍の1ページ表示、必要ならスマートフォンで確認する。

単ページ、見開き、スクロールでは同時に見える範囲が違う。画像の一部分だけで、実際のめくりや先読みを確認済みとしない。掲載サイズで必要な文字と細部を読む。画面上のピクセルを印刷寸法の標準値へ換算しない。

## はみ出し・裁ち切り・外連味（制作提案）

**コマはみ出し**は人物等がコマ枠を越えること、**裁ち切り**は画を仕上がり端まで広げることとして区別する。1ページ1コマ、枠なしの絵、見開きもそれぞれ別の操作であり、一括して「大ゴマ」と扱わない。

キャラクター登場時には、顔や上半身を枠の外へ出す候補を試せる。はみ出した部分が隣のコマの出来事に参加して見えないか、読む順をふさがないか、文字の安全範囲へ干渉しないかを確認する。

ここでの**外連味**は、現実そのままの見え方を離れて印象を強める、誇張された構図・ポーズ・比喩・効果・枠の操作を指す作業用語とする。採用前に「何の感情や強さをどこで強調するか」を一文で書く。誇張によって伝わるものと、失われる空間情報を比較する。写実から外れること自体を不具合とはしない。

## 白い小コマと顔を描かない演出（制作提案）

**白コマとコマ間の余白を区別する。** 枠に囲まれた白い小コマは独立した拍として読む可能性がある。枠のない余白は通常の区切りにも見える。「白コマ3個＝3秒」のような対応は今回の出典では確認していない。

時間経過を狙う場合、前後で時刻、光、物の位置、人物の動作などを変えると、白コマだけに時間の意味を負わせずに済む。白コマが記憶の欠落、眩しさ、場面転換に見える場合は、経過が伝わるかを読者に聞く。複数入れるほど必ず間が長くなるとは扱わない。

顔を見せないコマは、身体の一部・背中・周囲の物に読み取れる変化があるかを確認する。何も読み取れない絵を繰り返すだけでは、説明がないことと、余韻があることを区別できない。具体例は [没入と映画的演出](immersion-and-cinema.md) の字コンテを参照。

## 独自字コンテ例: 返事の前の一拍

1. 右上のコマ。Aが右、Bが左。「明日も／ここに来る？」をAの近くに縦書きで置く。「／」は制作メモ上の改行候補であり、文字として出力しない。
2. 左上の小コマ。Bの手がバッグのひもを握る。セリフなし。袖で誰の手か分かるようにする。
3. 下段の右。枠で囲んだ小さな白コマ1つ。返事を待つ拍として試す。
4. 下段の左。Bの横顔。「うん」を縦書きの楕円フキダシで置く。

初読で4の表情が先に見えるなら、返事を待つ狙いが弱まる。4を次ページへ移す案、顔を描かず返事だけにする案を比較する。白コマが場面転換に見える場合は、3を同じ場所の静かな背景へ替える。これは新規に作った制作例で、効果は未検証。

## レビュー手順

作品ごとの文字の実値と用途別の例外は `docs/production/DIALOGUE.md` に集約する。未指定なら最初のページで会話の基準を仮決めし、掲載サイズで確認する。小声でも必要な情報を読める大きさにし、長文は縮小以外に分割・言い回し・配置の変更を比べる。同じ用途の設定を次ページへ引き継ぎ、感情や視点が変わる場面の例外は保つ。参考：[CLIP STUDIO公式・テキスト設定](https://tips.clip-studio.com/ja-jp/articles/851)（取得2026-09-19、サイズ・行間・ルビ等の設定が対象）。用途別の固定値は同資料から採用せず、以上はキットの制作提案とする。

1. 字コンテで発話順・発話者・時系列を確認する。
2. サムネイルで、コマとフキダシを読む順を記入する。意図した順と異なる経路がないかを見る。
3. 想定表示寸法で文字、細い線、余白、はみ出しを確認する。
4. 問題を「誤読」「可読性」「意図した演出への疑問」に分け、ページ・コマ番号と最小修正案を記す。
5. レビュー重点1～5に応じて提案の深さを変える。低重点でも文字欠落・発話者の取り違え・読み順の破綻は残さない。

完成画像がなければ、字コンテから判定できる項目とできない項目を分ける。文章だけで「文字が読みやすい」「印刷で切れない」「視線誘導が完成した」とは判定しない。

## 任意の日本語推敲

OPTIONの「日本語推敲スキル」を有効にした場合に使う。既定は使用しない。無効でも通常の誤字・話者・意味・原文照合は進める。有効化した最初の作業時に [導入手順](optional-skills.md) に従い作品内へ自動導入し、「日本語推敲の対象」で選んだ文章だけに使う。Geminiを前提とするスキルは、利用できる環境でも導入前に利用枠消費の許可を得る。

1. 対象の原文と、人物ごとの一人称・敬語・語彙・承認済みの口調見本を確認する。台詞、内語、地の文、作品紹介を分ける。
2. 選択したスキルで候補を作り、引っ掛かる箇所の原文と候補を並べる。変えない案も残す。推敲で新しい事実、体験、感情、本音、関係を足さない。スキルの一般的な文体規則より、ユーザーの指定と人物の口調を優先する。
3. 意味と確実性、人物の声、言外の意味、文字量を個別に比較する。意図的な定型語・繰り返し・言いよどみを一律に消さず、内語を説明しすぎない。文長や語尾のばらつきを数値目標にしない。
4. メインが作品の狙いと指定に沿って採否を決め、候補の採用理由を通常の修正記録へ残す。ユーザーから原文固定・候補提示のみの指定があれば、その範囲を守る。
5. 採用した文字は `DIALOGUE.md` と配置の両方を更新し、PNGで感情・読順・収まりを確かめる。AIの文章点検を人間の試読の結果と扱わない。

2026-09-19のキット独自の比較手順。漫画では意味・人物の声・含み・吹き出しへの収まりを保つことを優先した。外部スキル本文は同梱せず、選択されたスキルだけ作品側で取得する。出典・固定版・許諾の確認範囲は [導入手順](optional-skills.md) を参照。実作品の読み心地への効果は未検証。

## 未検証・追加調査

- ウニフラの具体的な感情ごとの標準的使い分け。今回の公式資料は作成法を裏づけるが、意味の統一までは示さない。
- 白コマの数と知覚時間の関係、顔の連続に対する読者の疲労。現段階はユーザーの観察と制作仮説。
- 紙・単ページ画面・見開き画面・縦スクロールで、同じネームの順序や驚きがどう変わるか。
- 集英社「読みやすい画面作り」は本文図版を確認できていないため、具体的な作画指針の根拠には採用していない。参照URLは出典台帳に保持する。
