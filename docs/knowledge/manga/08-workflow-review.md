# 08 漫画のネームからPSD引き渡しまで

更新：2026-09-20。漫画を企画から人間への引き渡しまで進める制作運用。映画の字コンテ・動画生成は必要時の補助。

## 制作工程

基本の入力はキャラ・あらすじ・ページ数。作品フォルダでこの3点を受け取ったら、未指定の細部はCodexが仮決めして [Web用の既定値](../page-layout.md) で制作する。企画の記入欄やオプションの全項目を追加質問にしない。指定されたページ数を守り、全ページのPNGを順番が分かる形で用意する。投稿先未定でも進め、印刷設定・追加の文体推敲・PSD作成をPNG制作の前提にしない。PNGの修正確認は引き続きユーザーの回答を待つ。

開始前に作業場所を確認する。配布元の制作キットを開いている場合は、原則 `scripts/New-MangaProject.ps1` でキット外に作品プロジェクトを作り、作成先の絶対パスをユーザーへ示す。[開き直しの案内](../codex-operation.md#作品フォルダでcodexを開き直す)に従い、作品側でCodexを開き直してから以下の工程へ進む。既に作品プロジェクトを開いていればそのまま制作・再開する。配布元でどうしても制作したいという明示指示がある場合だけ、配布元ルートにユーザー自身が `特別な理由でこのフォルダの中で漫画を作ります.txt` を作成したことを確認してから始める。通常の作品プロジェクトにはこのファイルは不要。

| 工程 | 作るもの | 次へ進むための判断 |
| --- | --- | --- |
| 企画と読者体験 | 作品の狙い、形式、ページ数、読後感 | 何を楽しみ、誰を追う漫画か |
| 場面と人物 | 場面の前後、目的、障害、選択、結果 | 設定上の理由が行動として描けるか |
| 情報と変化 | 行動と反応、読者と人物の知識、小道具の反復 | 何をいつ理解し、何を待ってもらうか |
| 漫画の字コンテ | コマ候補、主対象、動作、台詞、無言の目的 | 文章を絵と文字へ移せるか |
| コマ割り計画 | ページ別の採用ID、または独自配置・演出意図・不使用の理由。imagegen用の番号付きレイアウト画像と各コマの内容 | 原則テンプレートを使い、ユーザーの必須・不使用指定に従う。ページ作画の生成前に [コマ割りの手順](../panel-layout-policy.md) で配置と読み順を決める |
| ネームと比較 | 本番量の文字を採用した文字方向で入れたページ配置 | 読み順、実際の表示形式での先読み、時間の切替、画面密度。迷う場面は配分の違う案を比較 |
| 通読と統合改稿 | 採用案、修正理由、失う効果 | 個別のよい案をつなげても感情・因果・空間が通るか |
| 作画と文字配置 | 参照絵、ページ絵またはコマ絵、枠、フキダシ、効果、確定セリフと用途別文字設定。imagegenは番号付き画像を実際に渡すページ一括生成が基本 | コマ数・配置・読み順・内容と計画の一致、同一人物、誤字、説明用番号の混入、掲載寸法での情報の大きさ、前後接続、前ページの修正条件 |
| PNGプレビューと修正 | 対象ページのPNG、修正・再提示の記録 | 最新のPNGをユーザーが確認し、修正がないことを確認。返答なしは確認待ち |
| PSD作成の確認 | 確認済みPNGの版・対象ページ、作成指示の記録 | 指示がなければ作るか聞いて回答を待つ。既に指示がある場合は再確認しない |
| PSD作成と検証 | ページ別PSD、確認用画像、引き継ぎ記録、セリフ原文 | 全ページを再読し、層・寸法・表示・未確認事項を検査 |
| 人間の仕上げと公開 | CLIP STUDIO PAINTで仕上げた原稿、公開用書き出し | 人間が仕上げ・公開を判断する工程。Codexの通常の完成範囲には含めない |

「漫画を完成させて」という依頼でも、PSD作成の指示がなければPNGでの確認・修正後に作るか聞く。PSD作成には時間がかかるため、PNGの修正確認と作成指示がそろうまでPSDを作らない。依頼されたPSDは[引き渡しの条件](../psd-handoff.md)を満たして人間へ渡す。PNGだけ・ネームだけ・部分修正だけという依頼は、その対象を完了条件にする。既存原稿があれば必要な工程から再開する。

動作を作るときは、コマ候補の段階で主動作を１つに絞り、接点がある場合は接触前・接触中・接触後を分けて記録する。文字量を増やして可視情報の不足を補ったとは扱わず、必要な人物・手・小道具・背景を短く固定してから画面へ移す。生成や外部送信を使う場合は、送信・再試行・再生成・採用を別の時刻と理由で記録し、既存成果物を確認してから再送する。

収録された監修テーマの効果が必要な場面は、字コンテ作成時に `manga-supervision` へ表現案を相談する。PNGプレビュー作成後は対象画像を実際に見て、同じ狙いが伝わるかの改善案を得る。[監修の進め方](../supervision/routing.md)に沿い、メインが中心効果と残したい感情を指定して採否を統合する。追加15テーマは試行版。確認範囲と未確認事項は [監修記録](../../reviews/SUPERVISION.md) に残す。

## 改稿は原因に合わせる

主役と目的→動機と因果→情報順→主対象と構図→間→コマ・フキダシの読み順→語句の順で原因を探す。誤字や話者違いなど局所の明確な誤りはその場で直す。「テンポが悪い」を文字量、同じ行為の反復、目的の不足、重要な反応の省略へ分けて考える。

通読では意図の説明を先にせず、誰が何を望んだか、どこで事情が変わったか、どこを戻って読んだか、次に何を予想したか、最後の関係をどう受け取ったかを記録する。エージェントによる点検と、初めて読む人間による試読は別に記録し、未実施の読者評価を補わない。

## 記録と練習

次ページにも使える修正は、採用理由・適用条件・例外・ページ範囲を既存の `docs/reviews/NAME-REVIEW.md` に短く残す。次ページに入る際に当てはまるか確認し、局所的なミスを作品全体の禁止事項へ変えない。文字設定は `docs/production/DIALOGUE.md` に集約する。この作品内の引き継ぎと、依頼時だけ行うキットへのフィードバック記録を区別する。

作品の決定事項・未確定事項・次に直す箇所は進捗へ、採否はレビューへ、再利用できる観察のフィードバックは記録依頼がある場合だけ残す。依頼がなければ記録するかの確認はしない。設定集を会話のたびに作り直さず、変わった理由を追記する。

練習には、二人の頼み事を無言で描く、聞き手だけで会話を描く、同じ場面を8コマと5コマにする、同じ構図の人物や小物を変える、同じ会話を玄関と台所で比べる、といった小さい課題を使える。個数は練習条件であり、作品の固定規則ではない。

ページ数・背景量・人数の制約があれば、削る機能と残す感情を先に決める。映画の撮影費や尺を作画負荷・ページ数へ換算しない。通常はCBZを作らず、作成は明示指定がある場合に限る。
