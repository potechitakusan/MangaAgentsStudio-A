# 06 連載・群像・ギャグ

更新：2026-09-13。漫画の制作とレビューに使う点検項目。以下は制作提案であり、作品に応じて選ぶ。映画・脚本の関連資料は[出典と参照範囲](../manga-sources.md)を参照。

<a id="l01"></a>

## L01　毎話なにをする漫画かを動詞で書く

毎話繰り返せる行動や課題を動詞で表す。人物や場所が同じだけでなく、新しい選択や結果を作り続けられるか複数の話案で確認する。

<a id="l02"></a>

## L02　話の解決と継続する葛藤を分ける

その話で読者へ返す答えと、続きへ持ち越す課題を分ける。何も解決しない引きや、次を読む理由のない完結になっていないか点検する。

<a id="l03"></a>

## L03　長所が問題も生む人物網を作る

一人の得意な行動が別の人物には困り事になる関係を設計する。毎回同じ喧嘩を繰り返すだけでなく、経験で関係が少し変わる余地を残す。

<a id="l04"></a>

## L04　主線と副線を別に成立させてから編む

主線と副線それぞれに始まり、変化、結果を置いてから交互に並べる。切り替えた先が、直前の疑問や感情へどう響くかを確認する。

<a id="l05"></a>

## L05　切り替えを時間の省略と対比に使う

別の人物へ切り替える間に省略できる時間と、対比して見せたい情報を決める。戻ったときの場所・時刻・目的を迷わず取り戻せるようにする。

<a id="l06"></a>

## L06　引きに複数の型を持つ

続きへの引きは危険だけでなく、決断、発見、約束、関係の変化からも作れる。前の話の報酬を奪わず、次に期待する内容を示す。

<a id="l07"></a>

## L07　群像では反応と利害を分ける

同じ出来事を見ても、人物ごとに得るものと失うものを変える。反応を並べる場合は、新しい情報を渡す人物を優先する。

<a id="l08"></a>

## L08　ギャグを設定と人物から生ませる

人物の欲求や思い込みが状況と噛み合わないところから笑いを作る。単発の語呂合わせだけで場面の目的が消えていないか確認する。

<a id="l09"></a>

## L09　フリ→展開→オチの順に読ませる

オチの理解に必要な情報を先に渡し、予想ができる状態を作る。ページ内でオチの文字が先に読めてしまう場合は配置を変える。

<a id="l10"></a>

## L10　笑いが弱いときはフリへ戻る

笑いが伝わらない場合は、オチを派手にする前に、何を予想していたか確認する。説明不足と、予想どおりすぎる展開を分けて直す。

<a id="l11"></a>

## L11　繰り返しギャグは意味を更新する

繰り返す冗談は、対象、状況、結果のどれかを変える。同じ出来事を知っていることが次の面白さにつながるかを確かめる。

<a id="l12"></a>

## L12　笑わせ方と重い場面の位置を人物に合わせる

誰を笑いの対象にするか、どこで深刻な問題を扱うかを作品の人物像に合わせる。重い場面の感情を意図せず打ち消していないか前後を通読する。
