# 02 注目対象・画角・アングル・視点

更新：2026-09-13。漫画の制作とレビューに使う点検項目。以下は制作提案であり、作品に応じて選ぶ。映画・脚本の関連資料は[出典と参照範囲](../manga-sources.md)を参照。

<a id="v01"></a>

## V01　画面の主体を一言で言えるようにする

そのコマで最初に見てほしい対象を一つ決める。顔、手、小物、空間のどれが判断材料かを選び、文字や背景との競合を減らす。

<a id="v02"></a>

## V02　引きで状況、寄りで判断材料を渡す

位置や逃げ道を理解させたいコマは広く、細かな変化を読ませたいコマは近く描く。距離の変化が新しい情報を渡しているか確認する。

<a id="v03"></a>

## V03　必要な情報からアングルを選ぶ

高さを見せる、奥の物を隠す、位置関係を整理するなど、必要な情報から視点を決める。俯瞰やあおりに常に同じ心理効果があるとは決めない。

<a id="v04"></a>

## V04　見る人→対象→反応で認識を描く

視線の先と、その情報を得た後の反応をつなぐ。誰が何を知ったかが重要なら、対象だけのコマで済ませず人物側の変化も描く。

<a id="v05"></a>

## V05　話し手より聞き手を描く

発言内容より受け止め方が重要な場面では、聞き手へ画面を割り当てる。話し手の位置やフキダシのしっぽから、発話者を迷わず特定できるようにする。

<a id="v06"></a>

## V06　切り返しは発言順より関係の変化で選ぶ

会話のたびに左右を切り替える必要はない。距離が縮む、主導権が移る、別の人物が参加する場面で構図を変え、関係の変化を示す。

<a id="v07"></a>

## V07　背中・歩き方・手の接触で人物を見せる

手の位置、重心、歩幅、接触の強さにも人物の状態を担わせる。顔を省く場合は、感情を判断できる別の手がかりを残す。

<a id="v08"></a>

## V08　遮蔽物を情報の制限に使う

前景や扉で情報を隠すときは、読者に見せないものを先に決める。単に人物が見づらくなる構図になっていないか、縮小表示でも確かめる。

<a id="v09"></a>

## V09　客観と主観を切り替えて体験を作る

全体の位置関係を示す画面と、人物が見ている範囲を示す画面を使い分ける。主観へ入る前後に視線や配置の手がかりを置き、視点の主を明確にする。

<a id="v10"></a>

## V10　空景を独立した意味のある画面にする

人物のいない背景を使うなら、時間経過、不在、状況の変化など役割を決める。背景だけで何も変わらない場合は、前後の接続に必要か見直す。

<a id="v11"></a>

## V11　同じ構図を反復し、差分を読ませる

同じ構図を使うときは、人物の位置や物の状態など、比較してほしい差を残す。最初の構図が覚えやすいか、反復の間隔も含めて確認する。

<a id="v12"></a>

## V12　前後の絵の組み合わせで意味を作る

前のコマが作る予想と、次のコマが渡す情報を対で考える。単独では魅力的な絵でも、並べたときに因果や視点が混乱しないか通読する。

<a id="v13"></a>

## V13　空間の連続性を字コンテに残す

人物の左右、向き、出入口、道具の持ち手を場面ごとに記録する。向きを反転する場合は、移動や別角度へ切り替わったことが分かる絵を挟む。

<a id="v14"></a>

## V14　重要なものが重要に見えるかを縮小して確認する

掲載を想定する大きさでPNGを表示し、重要な表情や小物を見つけられるか確認する。拡大すれば読める状態だけで作画完了としない。
