# 02 注目対象・画角・アングル・視点

更新：2026-09-17。漫画の制作とレビューに使う点検項目。以下は制作提案であり、作品に応じて選ぶ。映画・脚本の関連資料は[出典と参照範囲](../manga-sources.md)を参照。

<a id="v01"></a>

## V01　画面の主体を一言で言えるようにする

そのコマで最初に見てほしい対象を一つ決める。顔、手、小物、空間のどれが判断材料かを選び、文字や背景との競合を減らす。

<a id="v02"></a>

## V02　引きで状況、寄りで判断材料を渡す

位置や逃げ道を理解させたいコマは広く、細かな変化を読ませたいコマは近く描く。距離の変化が新しい情報を渡しているか確認する。

寄り・引きの順序は、今の画面から読者が次に見たくなるものに合わせて選ぶ。[前振りと欲求への応答](03-beat-pacing-timing.md#reader-anticipation)に沿い、人物の表情へ関心を向けるか、周囲の状況を知りたくさせるかを考える。

<a id="v03"></a>

## V03　必要な情報からアングルを選ぶ

高さを見せる、奥の物を隠す、位置関係を整理するなど、必要な情報から視点を決める。俯瞰やあおりに常に同じ心理効果があるとは決めない。

<a id="v04"></a>

## V04　見る人→対象→反応で認識を描く

視線の先と、その情報を得た後の反応をつなぐ。誰が何を知ったかが重要なら、対象だけのコマで済ませず人物側の変化も描く。

<a id="v05"></a>

## V05　話し手より聞き手を描く

発言者ではなく、聞き手が新しく何かを知る場面もある。次に見る人を「話している人」で自動決定しない。第三者を加えるなら、独自の知識・期待・負担・判断を持たせる。全員が同じ驚きを示すだけなら統合案を比較する。

話者の声を聞き手の反応に重ねる場合は、誰が話しているかを特定できるようにする。知っているはずの情報を、驚きを作るためだけに忘れさせない。

話し手の位置やフキダシのしっぽも、発話者を特定する手掛かりにする。

<a id="v06"></a>

## V06　切り返しは発言順より関係の変化で選ぶ

会話のたびに左右を切り替える必要はない。距離が縮む、主導権が移る、別の人物が参加する場面で構図を変え、関係の変化を示す。

<a id="v07"></a>

## V07　背中・歩き方・手の接触で人物を見せる

顔だけに説明を集めず、視線、手、姿勢、距離、向き、立ち去る／残る行動へ意味を分担する。視線を外す、背を向ける等は複数の感情に読めるため、次の行動で意味を絞る。顔と手で同じ事実を重複させる必要があるかも確かめる。

手の位置、重心、歩幅、接触の強さも候補にする。顔を省く場合は、感情を判断できる別の手掛かりを残す。

<a id="v08"></a>

## V08　遮蔽物を情報の制限に使う

前景や扉で情報を隠すときは、読者に見せないものを先に決める。単に人物が見づらくなる構図になっていないか、縮小表示でも確かめる。

<a id="v09"></a>

## V09　客観と主観を切り替えて体験を作る

全体の位置関係を示す画面と、人物が見ている範囲を示す画面を使い分ける。主観へ入る前後に視線や配置の手がかりを置き、視点の主を明確にする。

<a id="v10"></a>

## V10　空景を独立した意味のある画面にする

ページ全体で同じ距離・角度・主対象が続く箇所を見つけ、表情の変化や反復を読むために必要かを判断する。場所・時間・物の状態が伝わらない場合は、遠景、手元、背景の変化を使う案と現在の案を比較する。背景を増やすと緊迫や親密さが薄れる場面もあるため、「何コマごとに背景」「顔は何枚まで」という固定規則にはしない。

乗降や出入りなどの移動は、開始位置→動作→到達位置を追い、人物の向き・手・持ち物・扉との接続を確認する。説明文でつながるだけでなく、実画像でも追えるかを見る。

2026-09-19追加の制作提案。着想と適用範囲は [制作改善の出典](../manga-sources.md#web-workflow-20260919)。画面密度の調整による読者効果は未検証。

人物のいない背景を使うなら、時間経過、不在、状況の変化など役割を決める。背景だけで何も変わらない場合は、前後の接続に必要か見直す。

<a id="v11"></a>

## V11　同じ構図を反復し、差分を読ませる

同じ構図を使うときは、人物の位置や物の状態など、比較してほしい差を残す。最初の構図が覚えやすいか、反復の間隔も含めて確認する。

<a id="v12"></a>

## V12　前後の絵の組み合わせで意味を作る

前のコマが作る予想と、次のコマが渡す情報を対で考える。単独では魅力的な絵でも、並べたときに因果や視点が混乱しないか通読する。

[前振りで生んだ疑問や期待](03-beat-pacing-timing.md#reader-anticipation)に、後の絵や台詞が応えているかも確認する。前後を入れ替えた場合に、知りたくなる理由や発見が失われないか比較する。

<a id="v13"></a>

## V13　空間の連続性を字コンテに残す

人物の左右、向き、出入口、道具の持ち手を場面ごとに記録する。向きを反転する場合は、移動や別角度へ切り替わったことが分かる絵を挟む。

画像生成へ渡す場合は、注目対象、顔を見せる範囲、動作の前後、残す接点も対応させ、生成・切り抜き・仕上げ後のコマとページで照合する。目元だけの予定が顔全体へ戻る、隠す予定の顔が補完される、動作の先端が切れる等で意図が変わっていないかを見る。実行側の手順は [外部画像生成C1～C5](../external-panel-i2i.md#c1)。2026-09-26追加の制作提案で、[制作根拠E3](../image-generation/production-evidence.md#e3)の全体評価を個々の画角の効果へ分解したものではない。

<a id="v14"></a>

## V14　重要なものが重要に見えるかを縮小して確認する

掲載を想定する大きさでPNGを表示し、重要な表情や小物を見つけられるか確認する。拡大すれば読める状態だけで作画完了としない。

<a id="v15"></a>

## V15　描きにくい動作は、意図を保つ別の見え方へ置き換える

画像生成で接触・同時動作・操作の途中が繰り返し崩れるときは、語を足し続ける前に見せ方を変える候補を出す。まずコマの仕事（誰が何をしたか、何の結果か、人物像・関係）を一文にし、外せない条件を三つ程度に絞る。人物や道具が残っていても、支える・教える・共有するといった行為が消えれば意図は保てていない。

| 置き換え | 例 | 失いやすいもの |
| --- | --- | --- |
| 表情へ寄せる | 光を見る姿→両手でマグを包み目を閉じる | 場所・食卓の説明。感情の対象を示す手や物は残す |
| 完了した状態を描く | 鞄を掛ける途中→フックに掛かった持ち手 | 本人が行う実演。支点・閉じた口など完了を区別する形が要る |
| 残す接点を一つにする | 両手で書く→右手と鉛筆の先 | 押さえる側の手の役割 |
| 時点をずらす | 腕と球の衝突→球が離れた直後 | 瞬間そのもの。別の行為（投げ渡し）に見えたら不可 |
| 前後のコマへ分担する | 全景・挨拶・準備を別のコマにする | 分担先のコマが実際にその情報を持つこと |

記録は「意図→代わりに見せる状態→失う効果→前後のコマとの接続」の組で残す。置き換えは万能ではない。寄ると楽器・手・道具の構造の破綻が大きく見え、画角を変えると手の数が増えることもある。対象のコマだけを変えると次のコマの状態と矛盾することがあるため、切り抜きや台詞の位置を含めてページで確かめる。新案が描けても、原版が場面の意味を十分に伝えていれば原版を残してよい。置き換え自体を目的にしない。
