# 01 漫画の字コンテからコマとネームへ

更新：2026-09-13。漫画の制作とレビューに使う点検項目。以下は制作提案であり、作品に応じて選ぶ。映画・脚本の関連資料は[出典と参照範囲](../manga-sources.md)を参照。

<a id="c01"></a>

## C01　字コンテを「読者が体験する順番」で書く

読者が最初に目にする物、次に気づく変化、最後に理解する結果を順に書く。設定の説明と、コマに描く絵・文字は欄を分ける。

<a id="c02"></a>

## C02　漫画のコマ候補を作る。既存カットは必要時だけ対応させる

各コマに描く瞬間を決めてから番号を付ける。映像の資料がある場合だけ対応するカット番号も添え、コマ数はページ上で必要な情報量から決める。

<a id="c03"></a>

## C03　カットと変化の単位とコマを別々に数える

場面は出来事のまとまり、変化は関係や判断が動く単位、コマは読者へ提示する枠として管理する。これらを一対一に対応させず、行動と反応を読める配分を選ぶ。

<a id="c04"></a>

## C04　長いカットは「意味が変わる瞬間」で分割する

動作が続いていても、期待が外れる、事情が分かる、方針を変える瞬間は別コマの候補にする。移動の全過程より、理解に必要な始点と結果を優先する。

<a id="c05"></a>

## C05　統合は「同時に見ても意味が保たれるか」で決める

複数の情報を同じコマへ置く場合は、同時に見えても狙いが保たれるか確認する。原因より結果が先に目へ入ると困る箇所は分ける。

<a id="c06"></a>

## C06　字コンテの演出指定は「目的＋見える内容」にする

構図の指定には「何を理解させるか」と「何を画面に入れるか」を書く。角度や距離だけの指定より、作画時に代案を比較しやすい。

<a id="c07"></a>

## C07　沈黙を画面のある指示にする

無言のコマにも見る対象と直前からの変化を置く。表情、姿勢、物の状態などから、その人物が待つ・迷う・受け止める時間を読めるようにする。

<a id="c08"></a>

## C08　音・動き・内面を漫画の情報へ変換する

動きは前後の姿勢や効果線、音は擬音や人物の反応、内面は行動や必要な内語へ置き換える。すべてを文字にせず、理解に必要な情報を選ぶ。

<a id="c09"></a>

## C09　「カメラ指示を避ける」の適用範囲を分ける

作画へ渡す字コンテでは、主対象、距離、人物配置を具体化してよい。映画脚本の提出書式をそのまま漫画の制約へ移さず、ネームを作る用途で判断する。

<a id="c10"></a>

## C10　ページ上で初めてわかる問題を確認する

本番に近い文字量を小さなネームへ置き、読順、フキダシ面積、細部の大きさを確認する。ページをめくる前に見えてしまう結論がないかも点検する。
