# 漫画のネーム・紙面・作画の基礎

更新・公式資料確認日：2026-09-13。対象は日本語の右開きページ漫画。縦スクロールは別の表示単位として設計する。

## 公式資料で確認した事実

## 本テンプレートでの制作判断

以下は上記を踏まえた制作提案。効果の大きさを実測した法則ではない。

1. **ページ配分から考える。** 冒頭で追う対象を渡し、選択・発見・反応に必要な場所を取る。全ページを同じコマ数へ揃えない。
2. **本番量の文字をネームに入れる。** 縦書きのセリフとモノローグを置いてから、顔・手・小道具を隠さない構図を探す。文字のないラフだけで収まりを確定しない。
3. **コマ間を読ませる。** 階段を上る全動作は省けるが、誰がどこへ移ったかを失わない。重要な判断の前後を飛ばすときは、読者が補える手掛かりを残す。
4. **大ゴマの仕事を決める。** 景色を理解する、登場を印象付ける、感情を受け止めるなど、面積を使う理由を書く。大きさだけで読む秒数は決まらない。
5. **見開きの先読みを確かめる。** 綴じ、開始位置、単ページ表示か見開き表示かを記録する。奇数・偶数だけでめくりの成功を判定しない。
6. **線・ベタ・トーンで主対象を見分けやすくする。** 人物と背景が同じ密度なら、背景の省略や白い余白も比較する。トーンを増やすことを完成度の代用にしない。
7. **擬音と効果線を情報として配置する。** 音源、方向、強さ、誰の感覚かを確認する。効果文字がフキダシより先に読まれてよいかも見る。
8. **同一人物・小物・空間を保つ。** 顔、髪、衣装、持ち手、傷、左右位置を前後で照合する。変化が物語の意図なら、そのコマを記録する。
9. **最終寸法で見る。** 拡大時の描き込みだけでなく、実際の読書サイズで文字・線・重要な証拠が読めるか確かめる。仕上がり寸法、塗り足し、解像度は作品の引き渡し仕様で決める。
10. **縦スクロールは画面ごとに再設計する。** 見開きの同時視認やページめくりをそのまま移さず、画面外の情報が現れる位置を実機で確認する。

詳しい文字組みは [日本語漫画の読みやすさ](../japanese-manga-readability.md)、編集用原稿の条件は [PSD引き渡し](../psd-handoff.md)、工程は [ネームからPSDまで](08-workflow-review.md) を参照する。
