# 05 物語・人物・テーマ

更新：2026-09-17。漫画の制作とレビューに使う点検項目。以下は制作提案であり、作品に応じて選ぶ。映画・脚本の関連資料は[出典と参照範囲](../manga-sources.md)を参照。

<a id="s01"></a>

## S01　一文で主役・目的・抵抗・代償を言う

誰が何を求め、何に妨げられ、失敗すると何を失うかを一文にする。設定の珍しさだけでなく、人物を追いたくなる課題があるか確認する。

<a id="s02"></a>

## S02　テーマを選択と結果で示す

作品で考えたい問いに対して、人物が取る行動とその結果を設計する。結論を台詞だけで述べる前に、最後の選択から読み取れるかを見る。

<a id="s03"></a>

## S03　欲しいものと、それを妨げる信念を決める

人物の欲求と、その行動を狭める思い込みを分ける。思い込みが変わる話では、新しい判断に至る経験を途中の場面へ置く。

- 用件と本人が優先する欲求を分ける。周囲には奇妙でも、本人の信じる前提からは筋が通る選択を作る。
- 長所が不便を生むなら、その長所の適用範囲や程度を変える。単に能力を消して弱くしない。

<a id="s04"></a>

## S04　人物資料を行動の差にする

人物設定は、困ったときに何をするかの差へ変換する。年齢や経歴の一覧を増やすより、同じ問題に対する選択の違いを作る。

相手を助ける技能が高くても、自分の願いを頼む場面ではためらうことがある。能力・知識・対人上の自信を同じ強弱へそろえない。逆に、得意だから生じた失敗なら、得意だった事実を保ち、本人が同時に求めた別の目的を確かめる。

相手が以前の小さな行為を覚え、現在の対応を変えることは、関心を伝える証拠の候補になる。ただし、その一行為から感情の種類まで確定しない。

<a id="s05"></a>

## S05　圧力のある選択で人物の本質を見せる

簡単に選べる状況だけでなく、得たいものが両立しない状況を用意する。その人物が優先したものと、失ったものを結果まで描く。

<a id="s06"></a>

## S06　対抗する側にも筋の通った目的を持たせる

対立する人物にも求める結果と理由を持たせる。主役を困らせる役割だけにせず、両者の目的がどこで両立しないかを明確にする。

<a id="s07"></a>

## S07　変化の途中を飛ばさない

大きく態度が変わる前に、迷い、小さな試み、失敗など必要な過程を置く。すべてを描くのではなく、最終的な選択を理解する材料を残す。

- 人物の考えが変わるときは、得た事実、再評価、選択をつなぐ。気持ちの宣言だけで行動を変えない。
- 相手の状態に気付き、予定していた行動を止める／変えることも認識の証拠になる。

<a id="s08"></a>

## S08　前の行動が次の難題を生むようにする

事件を並べるだけでなく、前の判断が次の状況を作るつながりを点検する。偶然が続く箇所は、人物自身の行動へ置き換えられるか考える。

<a id="s09"></a>

## S09　冒頭は動く状況と見る理由を渡す

冒頭では、追う人物、現在の状況、先を知りたい疑問を渡す。世界の説明を先にすべて済ませようとせず、理解に必要な分だけ提示する。

<a id="s10"></a>

## S10　伏線は初回にも自然な役目を与える

後で重要になる情報にも、初めて出る場面で自然な役割を持たせる。見落とされすぎる案と、結論が分かりすぎる案をネームで比較する。

先に示した事実は変えず、後の情報で目的・原因・価値・関係の読み方を更新する。最後だけで新しい規則を作り、以前の結果を正当化しない。

結果を先に見せる場合は、読者が追う疑問と、後で渡す説明を対応させる。証拠を隠しすぎて理解できない状態を、意外性と呼ばない。

事実の説明、行為の完了、意味の反転、関係の更新、主題の具体化を分ける。小道具や台詞が戻るだけで回収済みとしない。以前の情報を思い出す手掛かりと、新しく分かる意味を示す。

解決手段の性質は、結果を理解するために必要な時点で読者へ渡す。作者や分析者が知っている前提を、読者にも渡したことにしない。

<a id="s11"></a>

## S11　クライマックスを一つの行為や絵へ集める

決着の場面では、人物の選択と関係の変化を代表する行為を決める。説明を足す前に、その絵と反応だけで何が伝わるかを確認する。

### 三つの状態を別々に見る

| 軸 | 問い |
| --- | --- |
| 外的な事態 | 何が止まり、何を達成し、何が未解決か |
| 本人の認識 | 何を知り、何を考え直し、次に何を選ぶか |
| 相手との関係 | 誰の応答・同意・自主的参加で、何が成立したか |

一つの決着を全員の納得に置き換えない。全軸を解決する義務もない。解決済み、必要だが未解決、意図して残す未来を区別する。

### 選択と受容の根拠を残す

対立を続ける条件が変わったなら、誰が何を根拠に続行・中断・協力を選んだかをつなぐ。周囲の人が手を出す／控える選択にも理由を持たせる。

相手の動機を理解することと、行動を許すことは別。損害や責任を説明で消さない。一方の願望だけで関係を成立させず、相手が拒否・条件提示・応答する機会を残す。全員が同時に納得する必要はない。

結果を受け取った後の行動で、以前できなかった対応や、関係の距離・分担が見えるかを確認する。教訓の台詞を削った版でも、人物の変化が読めるかを試す。

### 笑い・日常・補足を使う場合

笑いを添える場合も、核心の願いや感情、出来事の結果を取り消さない。当事者の外側の反応や小さな用件で受ける案もある。笑いの具体的な作り方はジャンル監修で扱う。

日常へ戻る場面を選ぶなら、態度・分担・距離の変化を確認する。希望を示すために喪失を消さず、悲しみだけで未来を閉じていないかも読む。余韻の長さや終幕の画面構成は標準化しない。

補足を設けるなら、本編だけで主要な理解が成立するかを先に確かめる。補足が追加する感情・関係・選択を明らかにする。後日談を自動で追加する指示にはしない。

### 成立したことと、その後も残る条件を確かめる

達成、能力や身体に残る効果、周囲からの扱い、本人の次の目的を別々に確認する。行動が成功しても不便は残り得るし、失敗しても情報や関係は更新され得る。成果の価値を後で読み替えるときにも、実際に起きた出来事は保持する。

結果を受けた人物が何をできる／できなくなるかを前後で比較する。大きな結果ほど、次の場面で以前と全く同じ行動に戻っていないかを確認する。

<a id="s12"></a>

## S12　構成法を作品の読み味に合わせる

構成法は問題を発見する補助として使い、ページ数を一定比率へ機械的に割り当てない。短編、連載、日常ものなど、狙う読み味に合わせて配分する。
