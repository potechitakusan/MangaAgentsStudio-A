# 05 物語・人物・テーマ

更新：2026-09-13。漫画の制作とレビューに使う点検項目。以下は制作提案であり、作品に応じて選ぶ。映画・脚本の関連資料は[出典と参照範囲](../manga-sources.md)を参照。

<a id="s01"></a>

## S01　一文で主役・目的・抵抗・代償を言う

誰が何を求め、何に妨げられ、失敗すると何を失うかを一文にする。設定の珍しさだけでなく、人物を追いたくなる課題があるか確認する。

<a id="s02"></a>

## S02　テーマを選択と結果で示す

作品で考えたい問いに対して、人物が取る行動とその結果を設計する。結論を台詞だけで述べる前に、最後の選択から読み取れるかを見る。

<a id="s03"></a>

## S03　欲しいものと、それを妨げる信念を決める

人物の欲求と、その行動を狭める思い込みを分ける。思い込みが変わる話では、新しい判断に至る経験を途中の場面へ置く。

<a id="s04"></a>

## S04　人物資料を行動の差にする

人物設定は、困ったときに何をするかの差へ変換する。年齢や経歴の一覧を増やすより、同じ問題に対する選択の違いを作る。

<a id="s05"></a>

## S05　圧力のある選択で人物の本質を見せる

簡単に選べる状況だけでなく、得たいものが両立しない状況を用意する。その人物が優先したものと、失ったものを結果まで描く。

<a id="s06"></a>

## S06　対抗する側にも筋の通った目的を持たせる

対立する人物にも求める結果と理由を持たせる。主役を困らせる役割だけにせず、両者の目的がどこで両立しないかを明確にする。

<a id="s07"></a>

## S07　変化の途中を飛ばさない

大きく態度が変わる前に、迷い、小さな試み、失敗など必要な過程を置く。すべてを描くのではなく、最終的な選択を理解する材料を残す。

<a id="s08"></a>

## S08　前の行動が次の難題を生むようにする

事件を並べるだけでなく、前の判断が次の状況を作るつながりを点検する。偶然が続く箇所は、人物自身の行動へ置き換えられるか考える。

<a id="s09"></a>

## S09　冒頭は動く状況と見る理由を渡す

冒頭では、追う人物、現在の状況、先を知りたい疑問を渡す。世界の説明を先にすべて済ませようとせず、理解に必要な分だけ提示する。

<a id="s10"></a>

## S10　伏線は初回にも自然な役目を与える

後で重要になる情報にも、初めて出る場面で自然な役割を持たせる。見落とされすぎる案と、結論が分かりすぎる案をネームで比較する。

<a id="s11"></a>

## S11　クライマックスを一つの行為や絵へ集める

決着の場面では、人物の選択と関係の変化を代表する行為を決める。説明を足す前に、その絵と反応だけで何が伝わるかを確認する。

<a id="s12"></a>

## S12　構成法を作品の読み味に合わせる

構成法は問題を発見する補助として使い、ページ数を一定比率へ機械的に割り当てない。短編、連載、日常ものなど、狙う読み味に合わせて配分する。
