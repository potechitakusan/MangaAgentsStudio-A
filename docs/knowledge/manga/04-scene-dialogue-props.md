# 04 場面・台詞・小道具

更新：2026-09-17。漫画の制作とレビューに使う点検項目。以下は制作提案であり、作品に応じて選ぶ。映画・脚本の関連資料は[出典と参照範囲](../manga-sources.md)を参照。

<a id="d01"></a>

## D01　場面の始まりと終わりの差を書く

場面の前後を一文ずつ書き、目的・知識・関係の変化を確かめる。変化が少ない単位には導入・休息・余韻などの役割があるかを検討する。笑い以外の仕事を担う単位も認める。続きへの問いを残す場面と、中心の問いを閉じる終幕を区別する。

<a id="d02"></a>

## D02　各人物の「欲しいもの」と「やり方」を分ける

欲しい結果と、相手からそれを得る方法を分ける。頼む、試す、隠すなど方法が変わる位置を、会話や構図の切れ目の候補にする。

<a id="d03"></a>

## D03　台詞に相手を動かす動詞を付ける

台詞が相手にどんな反応を求めているかを考える。説明だけが続くときは、話す人物の目的と、聞いた側の行動への影響を確かめる。

<a id="d04"></a>

## D04　言葉・隠した本音・本人も言えない欲求を分ける

口にする内容、意識して隠す事情、自分でも整理できない気持ちを分けて設計する。全部を内語で明かさず、絵から分かる範囲も決める。

人物の欠点だけでなく、譲らない関係や価値を残す。感情が混じる場面を一語に整理しすぎず、同意・ためらい・次の行動を別々に見る。

<a id="d05"></a>

## D05　説明を人物が使う情報に変える

説明は、質問・要求・拒否など、人物が情報を必要とする用件に結び付ける。聞いた後に何ができるようになるかを示す。復唱だけで理解したことにしない。

物語の理解にまだ不要な知識は、必要になる場所まで後へ回す。読者にもその理由を知りたくなる足場があるか、[前振りと欲求への応答](03-beat-pacing-timing.md#reader-anticipation)を確認する。

<a id="d06"></a>

## D06　長台詞を反応で区切る

長い台詞を分けるときは、聞き手の理解や反応が変わる位置を使う。同じ内容を機械的に短く分割してフキダシだけを増やさない。

<a id="d07"></a>

## D07　第三の物事に本当の争点を預ける

直接話しにくい争点を、共同作業や持ち物の扱いに表せるか試す。小物を見ただけでは事情が分からない場合は、前後に手がかりを足す。

<a id="d08"></a>

## D08　台詞と行動を反対方向へ向ける

言葉で守りたい自己像と、身体や実行に出る本音を分ける。発言と動作が食い違うときは、どちらを本音の手掛かりにするか決め、反応や反復で意味を支える。意味のある不一致と作画・設定上の矛盾を混同しない。

<a id="d09"></a>

## D09　短い返事や言い淀みに仕事を与える

短い返事にも承諾、保留、拒否、探りなど役割を持たせる。省略記号だけに頼らず、姿勢や返事の前後の行動も使う。

<a id="d10"></a>

## D10　人物ごとの言葉と身振りを決める

語尾を変えるだけでなく、説明の長さ、避ける話題、触る物、視線の使い方を人物ごとに考える。毎回同じ癖を強調して情報を圧迫しない。

平常の態度と出来事後の態度を比較する。常に最大の表情にすると、小さな変化を区別しにくい。強度の大小を標準設定にせず、どこが変わったかを具体化する。

<a id="d11"></a>

## D11　日常動作を感情と結び付ける

日常の作業が止まる、速くなる、やり直される変化を感情の手がかりにする。作業の内容を知らなくても、変化が読み取れる描写を選ぶ。

生活場面を重ねるなら、それぞれで違う関係の変化を示す。同じ楽しさを並べるだけで関係が深まったことにしない。空景や日常動作にも、時間・場所・状態のどの変化を渡すかを持たせる。

<a id="d12"></a>

## D12　小道具に複数の役目を持たせる

小道具は場所の説明、行動の目的、関係の変化など複数の働きを持てる。再登場が重要なら、初出で見分けられる特徴と役割を与える。

<a id="d13"></a>

## D13　場所に行動を生ませる

場所が人物の距離、動き、会話のしやすさへ影響するよう設計する。同じ台詞でも、広い場所と狭い場所でどちらが場面の目的に合うか比較する。

<a id="d14"></a>

## D14　人の出入り・音・中断で場面を曲げる

人の出入りや物音で中断するときは、それによって誰の選択が変わるかを描く。単なる会話の飾りなら省略した案も検討する。

割込みで当面の用件が変わっても、元の問題がどう残るかを把握する。会話が中断されたことを解決したことに置き換えない。区切りごとに今回渡した理解や報酬を確かめ、次へ残す疑問がそれを無効にしていないかを見る。
