# 03 変化の単位・緩急・提示のタイミングと間

更新：2026-09-13。漫画の制作とレビューに使う点検項目。以下は制作提案であり、作品に応じて選ぶ。映画・脚本の関連資料は[出典と参照範囲](../manga-sources.md)を参照。

<a id="r01"></a>

## R01　変化の単位・構成の節目・短い間を区別する

作品全体の節目、場面内の方針変更、返事までの短い間を別の尺度として扱う。同じ用語で説明している場合は、どの尺度の話か記録する。

<a id="r02"></a>

## R02　緩急と提示のタイミングを別々に設計する

緩急は情報や行為の密度、提示のタイミングは何をどの時点で知らせるかとして検討する。コマを増やす前に、どちらを変えたいのか決める。

<a id="r03"></a>

## R03　出来事・描写・読了の三つの時間を分ける

物語内で経過した時間と、描写に割いた量と、実際に読む時間は一致しない。時刻の省略は絵の変化で示し、読了時間は試読して確かめる。

<a id="r04"></a>

## R04　変化を動詞で書き、反復を見つける

各コマの働きを「探す」「気づく」「隠す」などの動詞で並べる。同じ働きが続く箇所は、強調として必要か、情報が重複しているかを判断する。

<a id="r05"></a>

## R05　刺激→認識→選択→応答を見える形にする

出来事を見た人物がどう理解し、何を選び、その結果どう動くかを追う。反応が唐突な箇所は、理解や判断の手がかりが抜けていないか確認する。

<a id="r06"></a>

## R06　転換の前は予期、後は吸収の間を作る

大きな変化の前には予想する材料を、後には変化を受け取る反応を置く。両方を長くする必要はなく、その場面で読者に味わってほしい側へ配分する。

<a id="r07"></a>

## R07　延ばすほど、期待か危険を変化させる

待つ時間を延ばすときは、危険の接近、期待の増加、迷いの深まりなどを描く。同じ状態を繰り返すだけなら、短くした案と比較する。

<a id="r08"></a>

## R08　反応の順番で場面の重心を作る

一つの出来事への反応を並べる順序で、誰の感情を追うかが変わる。主役へ戻る位置を決め、群像でも感情の軸を見失わないようにする。

<a id="r09"></a>

## R09　場面の長短と密度を組み合わせる

会話の多い場面、動作中心の場面、状況を見せる場面を並べて密度を確認する。長さの差だけでなく、文字と絵の負荷の偏りを見る。

<a id="r10"></a>

## R10　遅く入り、必要な余韻を残して出る

場面の目的に関わる変化が始まる位置から描く。終わりは出来事の決着に加え、読者が結果を理解する反応が必要かを判断する。

<a id="r11"></a>

## R11　読者の知識を三通りに配置する

読者だけが知る情報、人物だけが知る情報、同時に分かる情報を分ける。隠すこと自体を目的にせず、心配・疑問・驚きのどれを作るか決める。

<a id="r12"></a>

## R12　核心語と核心の絵を、反応が始まる位置へ置く

重要語と決定的な絵は、読者がどちらから受け取るかを設計する。フキダシが結論を先に知らせてしまう場合は、位置やコマの分け方を変える。

<a id="r13"></a>

## R13　ページめくりを情報の境界に使う

ページめくりで情報を隠す場合は、実際のページ開始位置と見開きを確認する。同じ画面で次ページまで見える閲覧方式では、同じ効果を前提にしない。

<a id="r14"></a>

## R14　間を測るときは「読者の状態」を記録する

試読では「遅い・速い」だけでなく、何を待ち、どこで理解し、どこを戻って読んだかを記録する。感想と作者の意図を別にして修正へ使う。
