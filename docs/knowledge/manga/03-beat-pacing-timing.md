# 03 変化の単位・緩急・提示のタイミングと間

更新：2026-09-17。漫画の制作とレビューに使う点検項目。以下は制作提案であり、作品に応じて選ぶ。映画・脚本の関連資料は[出典と参照範囲](../manga-sources.md)を参照。

<a id="r01"></a>

## R01　変化の単位・構成の節目・短い間を区別する

作品全体の節目、場面内の方針変更、返事までの短い間を別の尺度として扱う。同じ用語で説明している場合は、どの尺度の話か記録する。

<a id="r02"></a>

## R02　緩急と提示のタイミングを別々に設計する

緩急は情報や行為の密度、提示のタイミングは何をどの時点で知らせるかとして検討する。コマを増やす前に、どちらを変えたいのか決める。

<a id="r03"></a>

## R03　出来事・描写・読了の三つの時間を分ける

物語内で経過した時間と、描写に割いた量と、実際に読む時間は一致しない。時刻の省略は絵の変化で示し、読了時間は試読して確かめる。

<a id="r04"></a>

## R04　変化を動詞で書き、反復を見つける

各コマの働きを「探す」「気づく」「隠す」などの動詞で並べる。同じ働きが続く箇所は、強調として必要か、情報が重複しているかを判断する。

同じ場所・物・行為を使うときは、比較の基準として保つものと、今回変わるものを分ける。再登場のたびに情報か関係が更新されるかを見る。以前はした行動をしないことも、人物の変化になり得る。

<a id="r05"></a>

## R05　刺激→認識→選択→応答を見える形にする

`刺激 → 何を知ったか → どう解釈したか → 何を求めるか → 次の行為` を確認する。気付く・意味を理解する・返事をする段階を、伝わる範囲でまとめる。各段階を別のコマへ割り当てる義務はない。

「悲しい顔」「大声」だけでは目的は分からない。同じ強い発話にも拒む・頼む・支えるなどの目的がある。笑顔を好意や解決の確定記号、涙を悲しみの確定記号にせず、前後の選択と組み合わせる。

反応が唐突な箇所は、理解や判断の手掛かりが抜けていないか確認する。

対象の前後を実際に見て、何が刺激で、どの動作が変わり、次の行為へどうつながったかを示す。「もっと表情豊かに」だけでは修正箇所が決まらない。目的が伝わるなら、表情の誇張を増やさない案も成立する。

<a id="r06"></a>

## R06　転換の前は予期、後は吸収の間を作る

大きな変化の前には予想する材料を、後には変化を受け取る反応を置く。両方を長くする必要はなく、その場面で読者に味わってほしい側へ配分する。

<a id="reader-anticipation"></a>

### 次を知りたくなる前振りを作り、その欲求に応える

次のコマを決めるときは、読者が今何を知り、次に何を確かめたくなるかを見る。前振りで疑問や期待を生み、後の絵や説明でそれに応える。ここでの「報酬」は笑いに限らず、正体が分かる、結果を目撃する、意味がつながることも含む。

| 見せたい内容 | 先に生む関心・期待 | 応える情報 |
| --- | --- | --- |
| 衝撃や大きな動作の結果 | 動作の起点や迫る変化から「どうなるか」を予感させる | 実際の動作・接触・結果を見せる |
| 人物や物の正体 | 存在や特徴の一部を示し「誰か・何か」を気にさせる | 正体を特定できる姿や手掛かりを示す |
| 人物の表情や反応 | 引きで人物のいる状況を示し「どんな顔をしているか」へ関心を向ける | 寄りで表情や細かな行為を見せる |
| 周囲の状況や位置関係 | 寄りで反応や細部を示し「何を見ているか・どこにいるか」を気にさせる | 引きで対象や周囲との関係を明かす |
| 理由や事情の説明 | 気になる結果・発言・反応を先に置き「なぜか」を生む | その疑問に関係する説明を渡す |

長い説明は、人物が話したい都合だけでなく、読者がその理由を知りたくなる足場があるかを確認する。前振りを置いても不要な説明まで読みやすくなるとは限らないため、疑問に答える内容へ絞る。

寄りと引きを交互に置く規則や、必ず二つのコマに分ける指示にはしない。既に関心が生まれていれば、そのまま答えを渡せる。状況が分からないだけの状態と、分かっている状況の先が気になる状態を区別する。驚きを優先する場面や余韻を残す場面では、前振りの有無と答えを渡す時点を選ぶ。

字コンテとPNGでは「前の絵から何を知りたくなるか」「後の絵や台詞が何に答えるか」「答えが先に見えていないか」を確認する。狙った疑問や満足が実際に生じたかは、エージェントの見立てと読者の反応を分けて扱う。

<a id="r07"></a>

## R07　延ばすほど、期待か危険を変化させる

待つ時間を延ばすときは、危険の接近、期待の増加、迷いの深まりなどを描く。同じ状態を繰り返すだけなら、短くした案と比較する。

<a id="r08"></a>

## R08　反応の順番で場面の重心を作る

一つの出来事への反応を並べる順序で、誰の感情を追うかが変わる。主役へ戻る位置を決め、群像でも感情の軸を見失わないようにする。

<a id="r09"></a>

## R09　場面の長短と密度を組み合わせる

会話の多い場面、動作中心の場面、状況を見せる場面を並べて密度を確認する。長さの差だけでなく、文字と絵の負荷の偏りを見る。

| 見る軸 | 確認すること |
| --- | --- |
| 文字 | 読む語、文、話者、改行と順序 |
| 新情報 | 新しい事実、目標、因果、関係 |
| 推論 | 読者が補う動作、本音、時間、理由 |
| 切替 | 人物、場所、時刻、視点を取り直す負担 |
| 感情を受け取る時間 | 理解済みの出来事を人物とともに受け止める必要 |

コマ数・文字数を上の全ての代用にしない。少ない画面でも説明や推論が重い場合があり、言葉がなくても多くのことを受け取る場合がある。

### 回想・時間省略・同時進行を使うページの点検

時間が切り替わるコマだけ、字コンテへ「場面・時点」「出来事の前後と提示順」「語る時点と描く時点」「切替・戻りの手掛かり」を付記する。切替がなければ追加の表は不要。時系列順への統一や入れ子回想の禁止はしない。

台詞、人物の姿、場所、物の状態などを組み合わせ、どの時点を描いているかを絵で追う。黒いコマ間だけで伝わったと判定しない。ネーム・PNGを説明なしで読む際に、作者の意図と読み手が受け取った時間関係を分けて確認する。意図的に時点を伏せる場合は、後のどこで理解できる設計かを確かめる。

<a id="r10"></a>

## R10　遅く入り、必要な余韻を残して出る

場面の目的に関わる変化が始まる位置から描く。終わりは出来事の決着に加え、読者が結果を理解する反応が必要かを判断する。

<a id="r11"></a>

## R11　読者の知識を三通りに配置する

人物ごとに、知っている事実、信じている解釈、欲しい結果を分ける。読者が先に知る、人物が先に知る、同時に気付くという関係を選ぶ。人物が気付かない理由まで含めて設計する。

隠すこと自体を目的にせず、心配・疑問・驚きのどれを作るか決める。

### 説明者の主張・観測結果・仮説を分ける

説明者の主張、実際に観測できた結果、人物の仮説を分ける。予測と違う結果が出たときは、以前の事実を消さず、どの仮説が変わり次の行動がどう変わったかをつなぐ。噂・能力の説明・商品の価値などでも同じ点検を使える。

重要な条件は、発動・効果・費用・持続・終了のどれに関わるかを整理する。これは記入欄を増やす指示ではなく、結果の説明に足りない条件を見つける補助である。

<a id="r12"></a>

## R12　核心語と核心の絵を、反応が始まる位置へ置く

重要語と決定的な絵は、読者がどちらから受け取るかを設計する。フキダシが結論を先に知らせてしまう場合は、位置やコマの分け方を変える。

<a id="r13"></a>

## R13　ページめくりを情報の境界に使う

ページめくりで情報を隠す場合は、実際のページ開始位置と見開きを確認する。同じ画面で次ページまで見える閲覧方式では、同じ効果を前提にしない。

<a id="r14"></a>

## R14　間を測るときは「読者の状態」を記録する

試読では「遅い・速い」だけでなく、何を待ち、どこで理解し、どこを戻って読んだかを記録する。感想と作者の意図を別にして修正へ使う。

<a id="r15"></a>

## R15　無言の種類と働きを確かめる

「発話なし」は声の台詞がない状態。「言語記述なし」は台詞・内語・地の文・理解に必要な書かれた語がない状態。音、息、記号は別に確認する。「文字が一切ない」と同じにしない。

無言では、動作、気付き、ためらい、待機、理解の共有、時間経過、関係、余韻の何が変わるかを確認する。同じ反応を増やすことを、感じる時間が増えた証拠にしない。長い無言を好む方針や数値比率は採用しない。
