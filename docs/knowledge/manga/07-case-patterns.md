# 07 漫画で試す演出パターン

更新：2026-09-13。狙う効果から漫画の表現を選ぶための制作提案。映画やドラマの場面の再現ではなく、作品ごとにネームで比較して使う。読者効果の測定は未実施。[関連資料と参照範囲](../manga-sources.md)。

| 狙い | 漫画で描く候補 | 比較・点検すること |
| --- | --- | --- |
| 別れを残された側から描く | 出発前の玄関→無人の道→減った靴 | 出来事の省略が理解できるか。出発そのものを描く方が合うか |
| 感情の余韻を置く | 会話後の廊下、空席、洗い残した食器 | 背景が誰の不在や何の変化を示すか |
| 本音を言えない二人を描く | カップを返す／受け取らない口論 | 小物の争いから本当の争点を読めるか |
| 同じ関係の変化を見せる | 同じ食卓で人物・距離・視線だけ変える | 初回を覚えられる構図か。反復に新しい意味があるか |
| 群像の利害を分ける | 発表→計算する人→隣を見る人→退出する人 | 同じ驚き顔の繰り返しにならないか |
| 言葉の強さを反転する | 初回は冗談の語句、再登場は無表情の聞き手 | 語句を思い出せるか。絵や反応で意味が変わるか |
| 関係を身体で決着させる | 差し出された手を握る、添える、握り返さない | 手の位置と力の違いを掲載寸法で読めるか |
| 届かない報せの緊張を描く | 聞き返す→誰に知らせるか迷う→伝える | 未確定の情報と確定した事実を混同しないか |
| 仲のよさを後の喪失につなげる | 一時的な協力や同じ作業の楽しさを置く | 休息を削ると後半との落差も失わないか |
| 過去の濃さを描く | 関係の始まりを細かく、その後を同じ物の変化で省略 | 年月を誤読しないか。配分を固定比率にしない |
| 自分の未来を他人に見る | 別の二人を見つめた主役が、自分の相手へ向き直る | 見る対象と主役の決断のつながりがあるか |
| 絵と語りを食い違わせる | 実際の行動の後に、本人の体面を保つ語り | 語り手の誤認と作品側の事実を区別できるか |
| 大げさな言葉を日常で中断する | 告白の横で家事が続き、手が一度だけ止まる | 中断が感情や情報を変えるか |
| 起こらなかったことを結末にする | 告白の準備→機会が閉じる→日課に戻る | 読者が期待していた出来事を認識できるか |
| 複数の時間・記憶を読ませる | 同じ場所の物や枠の扱いを変え、現在へ戻る | 誰の記憶か、現在の感情の軸が追えるか |
| 読者への語りかけを変化させる | 話しかける→避ける→最後に向き直る | 通常の内語と読者への呼びかけを区別する |

構図の心理効果、出来事を省く比率、内語の回数を普遍的な決まりにはしない。参照は [視覚演出](02-visual-direction.md)、[間と緩急](03-beat-pacing-timing.md)、[場面と台詞](04-scene-dialogue-props.md) の必要箇所から行う。
