# 09 コマ配分の違うネームを比較する

更新：2026-09-13。漫画の制作提案。完成作品のサンプルではなく、同じ場面で複数案を比べるための手順。

## 比較前に固定すること

- 場面の始まりと終わり、人物の目的と結果。
- 読者へ渡す情報と、先に見せたくない情報。
- 確定した台詞と、最後に残したい感情。

## コマ配分を変える

まず必要な情報を一通り読める案を作る。次に、行動と反応を分ける案、同時に見せられる情報をまとめる案を作る。コマ数の目標がある場合も、数字に合わせる前にどの働きを残すか決める。

| 比較する点 | 分ける案で確認すること | まとめる案で確認すること |
| --- | --- | --- |
| 状況と行動 | 状況説明が長すぎないか | 人物の位置と行動を同時に読めるか |
| 発言と反応 | 反応を読む時間に意味があるか | 話者と聞き手の取り違えがないか |
| 発見と判断 | 気づいて考える過程が必要か | 次の行動が唐突に見えないか |
| 結果と余韻 | 変化を受け取る絵があるか | 結果を理解する前に終わらないか |

## ページで確かめる

本番に近い文字量を置き、掲載を想定するサイズで両案を通読する。読順、戻り読み、先読み、細部の大きさ、前後ページとの接続を比べる。コマが少ないほど速く読めるとは決めつけず、文字と絵の密度も見る。

採用理由と失う効果をネーム点検に残す。フィードバックへの整理は記録依頼がある場合だけ行う。
