# レビューの重点設定と役割分担

更新: 2026-09-12。以下は本プロジェクトの運用設計であり、評価効果を実証した尺度ではない。

## 1～5の意味

重点は「その観点の品質点」ではなく、レビューで割く注意と修正優先度。1=軽い確認、2=必要箇所、3=標準、4=詳しく、5=中心課題として複数案を比較する。1でも読み順破綻や設定矛盾を見逃してよい意味にはしない。

| キー | 観点 | 初期重点 |
| --- | --- | --- |
| immersion | 世界への没入、感情、間、情報密度 | 5 |
| cinema | 画角、視点、空間、カットの接続 | 4 |
| story | 欲求、障害、因果、変化、結末 | 4 |
| readability | 日本語、フキダシ、コマ順、視線誘導 | 5 |
| characterConsistency | 顔、髪、衣装、小物、体格の継続性 | 4 |
| terminology | 設定用語と制作指示の呼称 | 3 |

設定は `config/review-profiles.json`。解決順は defaults → シーンのpreset（なければコマンドのPreset）→ シーンのweights。指定シーンが存在しない場合は誤記とみなしエラー。Preset省略時はbase相当。プリセットは漫画ジャンルを決めつけるものではなく初期候補とする。

```powershell
.\scripts\Resolve-ReviewProfile.ps1 -ConfigPath '.\config\review-profiles.json' -Preset 'confession'
.\scripts\Resolve-ReviewProfile.ps1 -ConfigPath '.\config\review-profiles.json' -SceneId 'scene-001'
```

シーン設定例（scenesの中へ追加）:

```json
"scene-001": {
  "preset": "confession",
  "weights": { "cinema": 5, "terminology": 2 },
  "reason": "言えない気持ちを手と距離で見せる"
}
```

## 制作と相談の流れ

メインエージェントが作品の狙いとシーンの「前→後の変化」を把握し、字コンテ/ネームを作る。必要な観点のSkillに相談して案を比較し、レビュー指摘を統合する。Skillを呼ぶだけで別エージェントが起動するわけではない。委任可能な環境では、目的・対象ページ・実効重点・該当Skillのパスをサブエージェントに渡す。

| Skill | 主に見る対象 | 通常の使用場面 |
| --- | --- | --- |
| manga-immersion-review | 感情、間、説明過多 | 字コンテ・ネームの読後感レビュー |
| manga-cinema-review | 距離、方向、ショット接続 | シーンのカット設計への相談・レビュー |
| manga-story-review | 役割、欲求、因果、変化 | あらすじ・1話・シーンの構成相談 |
| manga-readability-review | 縦書き、読み順、文字配置 | ネーム・文字入れの相談とレビュー |
| manga-ai-production | キャラ一貫性、モデル選択、実験 | 参照絵からコマを制作する段階 |
| manga-terminology-review | 用語と設定の表記ゆれ | レビュー時のみ。初稿執筆には辞書を読ませない |

レビュー依頼は「scene-003、p4～5、告白直前の緊張を残したい。無言コマの要否と画角を検討。本文は…」のように対象と効果を指定する。制作中に全Skillを毎回呼ぶ必要はない。

## レビュー記録

`docs/reviews/` に次を残す。

| 対象 | 観点/重点 | 観察した事実 | 読者への影響の仮説 | 重大度1～3 | 改善案 | 失う効果/残す例外 |
| --- | --- | --- | --- | --- | --- | --- |

重大度は1=軽微、2=理解や感情を阻害、3=読む順や物語が成立しない。修正順の補助値は重点×重大度だが、読めない/設定破綻は先に解消する。数値だけで機械的に合否判定しない。指摘のない観点は「確認済み」とするか対象外理由を残し、無理に問題を作らない。

メインエージェントは指摘ごとの採否と理由を記録する。修正後は影響するページと前後接続を確認し、フィードバックへの整理は、記録を依頼された場合だけ行い、記録するかの確認はしない。

## 漫画の制作と引き渡し

収録内容は作品の `docs/MANGA-KNOWHOW.md` から選ぶ。[ネームからPSDまで](manga/08-workflow-review.md)に従い、漫画の企画・字コンテ・ネームを主軸に、必要な場面の複数案、通読、レビューの統合改稿を行う。映画・ドラマや脚本スキルは必要箇所の補助参照とする。

まずPNGプレビューで確認・修正し、ユーザーに修正がないことを確認する。PSD作成の指示がなければ作るか聞いて回答を待ち、既に指示があれば再確認しない。依頼されたPSDは[作成・検証・引き渡し](psd-handoff.md)まで行う。PNG確認待ち・PSD作成回答待ちは正規の待機段階とする。原則、人間がCLIP STUDIO PAINTで仕上げてから外部公開する。CBZは明示指定時だけ作成する。画像制作スキルはこの確認手順を含めて参照し、各レビュースキルは依頼された観点の検証を担う。
