# 漫画制作・映画・脚本資料の出典と参照範囲

資料取得日：2026-09-13。公開リポジトリと利用表記の再確認日：2026-09-13。

映画・脚本の主な参照先は [jtydhr88/screenwriting-skills](https://github.com/jtydhr88/screenwriting-skills)。物語、人物の目的と対立、台詞、場面の変化、視覚的な情報提示、連載の構成を考えるために参照した。

漫画向けの本文は、静止画・文字・コマ・ページの配置を判断するための制作提案として整理している。脚本スキル一式、書籍や台本の抜粋、逐語訳は同梱しない。元資料が挙げる書籍や映像をすべて直接照合したわけではなく、各著者の主張を一次資料で確認済みとは扱わない。

普段は同梱の漫画ノウハウを使い、語義や適用範囲の確認が必要な場合だけ下記の該当資料へ進む。映画の尺や脚本ページ比率を漫画のコマ数へ固定換算しない。契約・提出書式・業界規制を漫画制作の標準手順にしない。

参照元には個人学習向けの利用表記がある。[参照元の利用条件](https://github.com/jtydhr88/screenwriting-skills#conventions)（確認2026-09-13）。本キットのMIT Licenseを参照元資料へ適用しない。

## Web制作の工程改善（2026-09-19）

| 出典 | 取得・確認日 | 確認範囲と取り込み先 |
| --- | --- | --- |
| [余白とインク・制作記事](https://note.com/fine_curlew3317/n/n9fe6fe1ff10c) | 2026-09-19 | 無料本文、公開コメント2件（返信を含む）、初期・掲載版4画像を先行調査で確認。時間関係、画面密度、文字設定、修正の次ページへの引き継ぎを検討する着想。記事は当該作品の経験であり、一般的な効果の証明には使わない |
| [CLIP STUDIO公式・基本的なコマ枠の作り方](https://tips.clip-studio.com/ja-jp/articles/610) | 2026-09-19 | 基本枠の余白・サイズとコマ枠配置を確認。[Web用基本枠](page-layout.md)の役割の説明に使用 |
| [CLIP STUDIO公式・テキスト設定](https://tips.clip-studio.com/ja-jp/articles/851) | 2026-09-19 | サイズ・行間・ルビ等の設定を確認。[文字の読みやすさ](japanese-manga-readability.md)と作品別設定へ接続。印刷用の数値をWebの固定値にしない |

追加した点検手順は本キットの独自の制作提案。回想の階層、背景量、文字の強弱を一律に固定しない。記事本文・コメント・漫画画像は配布に含めず、作品固有の台詞・人物設定・筋書きを取り込まない。読者への効果、修正回数の減少、印刷適合は未検証。公式資料の機能説明と、キットが選んだ初期値・運用を区別する。
