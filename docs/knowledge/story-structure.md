# 物語構造と場面設計

出典確認日：2026-09-12。対象はプロット、一話の構成、人物の役割、場面の目的と結果を整理する工程。

## この文書の使い方

出典で確認した理論と、漫画へ応用する制作提案を区別する。すべての物語を同じ型へ変形させる採点基準にはしない。日常もの、余韻を残す話、失敗や喪失を描く話では、未達成や価値観の変化も結果として扱う。

## 変化の型を使って場面を考える

プロップの英訳原典の公開抜粋では、禁止と違反、悪役の欺きと被害者の追従などを確認できる。[原典の公開抜粋](https://www.perlego.com/book/3273841/morphology-of-the-folk-tale-pdf)。小方孝の論文は、機能対とその再構成を扱う。[小方孝の論文](https://www.jstage.jst.go.jp/article/jcss/14/4/14_4_532/_pdf/-char/ja)。原典と研究者による整理は分けて読む。

以下は場面を作るための制作上の候補であり、特定の理論がこの五つだけを分類したという主張ではない。

| 変化の候補 | 設計すること | 点検すること |
| --- | --- | --- |
| 足りないものを得る・失ったものを取り戻す | 欲求、手段、得た後の変化 | 獲得と回復を同じ結果にしていないか |
| 禁止されている行動を選ぶ | 禁止の理由、誘惑、選んだ代償 | 違反だけで人物の目的が消えていないか |
| 作戦を立てて試す | 予想、工夫、相手の反応 | 成功・失敗の理由を読者が理解できるか |
| 難しい課題に取り組む | 障害、試行、協力、到達点 | 努力・幸運・援助の働きを混同していないか |
| 危険を避ける・被害から立ち直る | 危険の予告、選択、結果 | 予防と回復に必要な情報を分けているか |

## 人物を役割で整理する

Louis Hébertの解説は、グレマスの行為項を主体・対象、援助者・対立者、送り手・受け手として整理し、兼任や人物以外の要素も扱う。[The Actantial Model](https://www.signosemio.com/pages/greimas/actantial-model.php)。次の表は漫画の設計に使うための問いへ置き換えたもの。

| 役割 | 制作時の問い |
| --- | --- |
| 行動する主体 | 誰の選択を読者が追うか |
| 求める対象 | 何を得たい、守りたい、変えたいのか |
| 行動を促すもの | なぜ今動く必要があるのか |
| 結果を受け取るもの | 成功や失敗が誰に影響するか |
| 助けるもの | 人、技能、道具、偶然のどれが支えるか |
| 妨げるもの | 他者、環境、制度、本人の思い込みのどれが障害か |

一人が複数の役割を持ってもよい。登場人物を増やす前に、その人物が場面の選択や結果へどう影響するかを確認する。

## 一話からコマへ具体化する

1. 読者に残したい感情と、追う人物を決める。
2. 場面ごとに「開始時の状態→行動→障害→選択→結果」を書く。
3. 前の選択が次の状況を作るかを確認する。
4. 人物の知識と読者へ知らせる順序を分ける。
5. 字コンテでは見える行動と文字を指定し、ネームで読順と密度を確認する。
6. 通読し、動機や反応が抜ける箇所、同じ働きが続く箇所を直す。

読者確認では、何を求めていたか、なぜ選んだか、何が変わったかを尋ねる。理解と好みを分けて扱う。通常の制作判断はレビューへ残し、フィードバックへの整理は記録依頼がある場合だけ行う。
