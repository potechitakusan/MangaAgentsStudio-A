# 悲しみ・喪失・余韻の監修

状態：試行版。更新・資料確認：2026-09-19。不在になった人や場所、失われた関係・機会と、その後を生きる人物を扱う。以下は**制作提案**であり、悲嘆の医学的な段階や回復の手順を定めるものではない。

主な資料は [S14](../sources.md#s14)・[S15](../sources.md#s15)。自分の体験を描く作者と、取材した土地や不在を描く作者の方法を比較する。間、小道具、終幕は [緩急・提示](../../manga/03-beat-pacing-timing.md)、[場面・台詞・小道具](../../manga/04-scene-dialogue-props.md)、[物語・人物](../../manga/05-story-character.md) の共通知識へ戻す。

<a id="g01"></a>

## G01　何が失われ、その人に何ができなくなったかを見る

- 見ること：人・場所・未来のどれを失ったのか。関係の中で、もうできないこと、なお続けたいことは何か。
- 使う条件：「悲しい」という説明はあるが、その人物に固有の喪失が読めない場面。
- 比較案：以前の役割を短く渡す／現在できない行為で示す／まだ伝えたい用件を残す。
- 代償・例外：関係の全履歴を回想する必要はない。行方不明や別離を死亡確定へ変更せず、人物が知る範囲と読者が知る範囲を保つ。
- 根拠の範囲：S14・S15と共通知識の欲求・知識差を組み合わせた提案。

<a id="g02"></a>

## G02　続く習慣と変わった手順で、不在を感じさせる

- 見ること：いつもの物や動作が、以前と同じ意味で使えなくなっているか。その物と失った相手の関係を読めるか。
- 使う条件：空席や形見を置いただけで、不在の意味が伝わらない場面。
- 比較案：同じ作業で手が止まる／一人分の手順が変わる／片付ける・残す選択を見せる。
- 代償・例外：象徴の意味を説明しすぎると余韻が狭まる。初出の物にも現在の行為や短い言葉で役割を示せる。物の由来が不明なら、その不明さや人物の想像を示せる。過去の親密さを勝手に作らず、想像と確認事実を分ける。必ず先に長い回想を足す規則にはしない。
- 根拠の範囲：S15の現地の物から時間を感じ取る制作観と、S14の日常描写からの応用。

<a id="g03"></a>

## G03　その人物の反応と、混じる感情を保つ

- 見ること：涙、怒り、笑い、空腹、仕事への集中、反応の遅れなどが、その人とその時点の行動につながるか。
- 使う条件：泣かない人物を「悲しさ不足」と判断したり、全員の反応をそろえたりする場面。
- 比較案：泣く／泣けない／用件をこなす／一瞬笑う。その後の選択と合わせて比較する。
- 代償・例外：静かな描写を常に上位にしない。大きく泣く人物も成立する。笑う・食べることだけで悲しみが消えたと扱わない。
- 根拠の範囲：S14の体験と制作方針。作者個人の経験を万人の反応や回復段階へ一般化しない。

<a id="g04"></a>

## G04　理解する時点と、感情が表れる時点を選ぶ

- 見ること：知らせを受けた時、身近な物に触れた時、誰もいなくなった時など、何が反応を変えたか。
- 使う条件：説明直後に泣き顔を足す以外の案がない、または無言のコマが同じ状態を反復している場面。
- 比較案：その場で受け止める／用件の後に立ち止まる／時間を省略し、変わった行為で示す。
- 代償・例外：遅れた涙が常に深いわけではない。繰り返しや停滞自体が狙いなら残す。間の長さはページ・掲載形式・試読で確かめる。
- 根拠の範囲：S14・S15と共通知識の反応・時間の扱いを踏まえた提案。

<a id="g05"></a>

## G05　場面の終わりと、悲しみの終わりを分ける

- 見ること：この場面の用件や選択はどこまで閉じ、何を未解決に残すのか。小さな行動の再開を、完全な回復や赦しに置き換えていないか。
- 使う条件：明るい台詞を加えるだけで喪失を解決したことになる、または余韻のために必要な結末まで欠ける場面。
- 比較案：今日の用件だけを終える／習慣を一つ変える／答えを出さず次の行動を選ぶ／回復を描くなら途中の手掛かりを残す。
- 代償・例外：希望や救いを消すことも目標ではない。別れが解放になる人物、相反する感情が残る人物も、作品の設定に従う。
- 根拠の範囲：S14の時間を経た捉え直し、S15の安易な完了判断への問いと、共通知識の終幕からの応用。

## 比較・画像・試読

同じ喪失・時間経過・人物関係を保ち、涙／行動、回想／現在の痕跡、語る／残す等を比較する。PNGでは不在と結び付いた物、動作の止まる位置、前後の時間差が分かるかを確認する。象徴だけを大きくしても意味が伝わるとは限らない。

試読では「何を失ったと読んだか」「最後に何が変わり、何が残ったか」を聞き、泣けたかどうかだけで合否を決めない。[共通の監修手順](../routing.md) に従い、採否と代償を残す。実作品PNGと読者による比較検証は未実施。
