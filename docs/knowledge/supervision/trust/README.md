# 親密さ・信頼の監修

状態：試行版。更新・資料確認：2026-09-19。任せる・頼る・一緒にいられる関係を扱う。[S17](../sources.md#s17)・[S16](../sources.md#s16)を踏まえた**制作提案**。友情、家族、仕事、恋愛のいずれにも使えるが、関係の種類を変更しない。

恋心は [好意](../romance/README.md)、壊れた関係の選び直しは [和解](../reconciliation/README.md)。共通の役割・行動は [人物](../../manga/05-story-character.md)、習慣・所作は [場面](../../manga/04-scene-dialogue-props.md) を参照する。

<a id="f01"></a>

## F01　何を信頼し、どこまで任せるかを決める

- 見ること：技能、約束、秘密、判断のどれを信じているか。好感や親しさと一致するか。
- 使う条件：一度の協力から、相手の全てを信用した扱いになる場面。
- 比較案：仕事だけ任せる／秘密だけ預ける／得意な領域を頼る。
- 代償・例外：敵や苦手な人物も特定の約束では信用できる。範囲を全部台詞で説明する必要はない。
- 根拠の範囲：S17の信用できる敵という制作観からの応用。

<a id="f02"></a>

## F02　任せた行為と、その受け止めをつなぐ

- 見ること：誰が何を委ね、相手がどう応じたか。自分で任せた選択か、規程・義務・強制による行為か。賞賛の言葉だけで関係を代用していないか。
- 使う条件：仲間と言うだけで、互いを必要とする理由が見えない場面。
- 比較案：役割を渡す／失敗を報告する／助けを求める／頼まれた範囲を確実に行う。
- 代償・例外：規程どおりの受け渡しだけで個人的な信用を確定しない。相手を無能にして助ける機会を作らない。初対面で信じる選択も、人物の判断として描ける。
- 根拠の範囲：S17と共通の選択・因果を使った提案。

<a id="f03"></a>

## F03　共有する習慣に、小さな応答を残す

- 見ること：手順、呼び方、物の受け渡し、沈黙が二人にとってどういう状態か。
- 使う条件：距離の近さや無言だけで、親密さを示そうとする場面。
- 比較案：相手の手順に自然に合わせる／いつもと違う調子に気づく／無理に話題を埋めず作業を続ける。
- 代償・例外：習慣を共有しない信頼もある。沈黙だけなら緊張・拒否等の読みも残るので、前後を確かめる。
- 根拠の範囲：S16の日常的な交流を非恋愛へ応用する部分は本キットの仮説。

<a id="f04"></a>

## F04　違いと断れる範囲を保つ

- 見ること：意見が違う時や頼みを断った時、相手の限界をどう扱うか。
- 使う条件：信頼を示すために全て賛成する、秘密を全て話す描写になる場面。
- 比較案：理由を伝えて別案を出す／知らない領域は任せる／今は話さなくてよいと応じる。
- 代償・例外：依存や一方通行が作品の狙いなら矯正しない。相手の負担を描いたまま、関係の読みを比較する。
- 根拠の範囲：S17のできる範囲と距離についての発言を、作中の関係へ応用した提案。

<a id="f05"></a>

## F05　変わった信頼と残る距離を分ける

- 見ること：一緒に成功・失敗した後、何を新たに任せられ、何はまだ任せられないか。
- 使う条件：一回の救助や共闘で、それまでの不信や傷が全てなくなる場面。
- 比較案：小さな依頼を増やす／役割だけ継続する／感謝しつつ距離を置く。
- 代償・例外：大きく関係が変わる話も成立する。必要なのは変化の程度を作品の出来事で支えること。
- 根拠の範囲：S17と先行の怒り・人物の共通知識を踏まえた提案。

## 比較・画像・試読

関係の種類と頼みの内容を保ち、説明／受け渡し、同意／違いを言える応答を比較する。PNGでは行為の受け手、反応、役割の継続を見る。試読では「何を任せられる関係か」「どこに距離が残るか」を聞く。実作品PNGと読者による比較検証は未実施。[共通手順](../routing.md)に従う。
