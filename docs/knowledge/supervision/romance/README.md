# 好意・照れ・恋の予感の監修

状態：試行版。更新・資料確認：2026-09-19。誰かを特別に思う気持ちや、その自覚・伝わり方を扱う。[S16](../sources.md#s16)・[S04](../sources.md#s04)を踏まえた**制作提案**であり、恋愛感情の診断や読者効果の実証ではない。

魅力に一瞬目を奪われる演出は [非露骨な色気](../allure/README.md)、任せ合う関係は [信頼](../trust/README.md)。恋愛を望む場面で必要な項目だけ使い、一般の人物・視点は [共通知識](../../manga/05-story-character.md) を参照する。

<a id="l01"></a>

## L01　好意の主体と、自覚・伝達の段階を分ける

- 見ること：誰が誰を気にしているか。本人の自覚、相手の理解、読者に渡す情報が一致しているか。
- 使う条件：視線や赤面だけで両思い・交際成立まで飛躍している場面。
- 比較案：片方の内心を渡す／行動だけで予感を残す／相手の受け取りを別の反応で示す。
- 代償・例外：内心を明かすと曖昧さが減る。照れは失敗や注目への反応でもあり、単独では恋愛の証拠にしない。
- 根拠の範囲：S16の片方の恋心を保つ制作観を、情報の段階に整理した提案。

<a id="l02"></a>

## L02　その相手だから変わる選択を見せる

- 見ること：会話を続ける、覚えている、予定を少し変える等に、その人物固有の理由があるか。
- 使う条件：誰にでもする親切を、特別な好意として読ませたい場面。
- 比較案：他の相手への通常対応と比べる／前の会話を行動へつなぐ／小さく迷って選び直す。
- 代償・例外：特別扱いを増やしすぎると仕事・約束・性格を崩す。明言する好意や、まだ差が出ない段階も成立する。
- 根拠の範囲：S16の日常のやり取りと、共通の欲求・行動からの応用。

<a id="l03"></a>

## L03　照れ方を人物の声に合わせる

- 見ること：隠したい気持ちと、普段の振る舞いとの差。怒鳴る・黙る・丁寧になる等の反応が本人らしいか。
- 使う条件：全員に赤面・否定・視線逸らしを足している場面。
- 比較案：言い直す／いつもの作業に戻る／素直に喜ぶ／冗談で逃がす。
- 代償・例外：照れ隠しの攻撃が相手を傷つけたなら、その影響を消さない。赤面を省くことも必須ではない。
- 根拠の範囲：S04の反応差を既存人物へ適用する提案。反応から本心を断定しない。

<a id="l04"></a>

## L04　やり取りの前後で変わったものを絞る

- 見ること：名前の呼び方、話題、次に会う理由など、今回の一歩が何か。
- 使う条件：恋愛イベントはあるが関係の違いが残らない、または急に進みすぎる場面。
- 比較案：次の会話のきっかけを残す／一つだけ知る／好意を伝えるが返事は保留にする。
- 代償・例外：毎回進展させる必要はない。安心して繰り返す会話や片思いの停滞も狙いとして残せる。
- 根拠の範囲：S16の会話を重ねる方法からの応用。交際前だけを正解にしない。

<a id="l05"></a>

## L05　相手の返答と選択を残す

- 見ること：好意を受けた側が、喜ぶ・戸惑う・断る・考える等を選べているか。
- 使う条件：告白や接近の演出で、相手の意思や既存の関係が抜ける場面。
- 比較案：返事を一つ置く／距離を自分で選ぶ／受け取りの違いを次のやり取りへつなぐ。
- 代償・例外：返答を説明しすぎると余韻が減る。保留や拒否を、内心の承諾と補完しない。
- 根拠の範囲：S16と人物の共通知識を踏まえた本キットの提案。

## 比較・画像・試読

気持ちの主体と関係段階を保ち、内心／所作、素直／隠す等を比べる。PNGでは誰の視点・反応か、接近と返答の順序を見る。試読では「誰が誰をどう思っていると読んだか」「今回何が変わったか」を聞く。実作品PNGと読者による比較検証は未実施。[共通手順](../routing.md)に従う。
