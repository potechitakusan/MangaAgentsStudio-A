## W01　事実・知識・解釈の食い違いを分ける

- 見ること：実際の出来事、各人物が知ること、そうだと思い込むこと、期待した返答。
- 使う条件：すれ違っているはずなのに、どこで違ったか追えない場面。
- 比較案：片方だけの受信情報を示す／同じ言葉の別の意味を渡す／期待した行為との差を置く。
- 代償・例外：全ての内心を説明すると揺れが減る。確認済みの加害や嘘を、双方の誤解へ置き換えない。
- 根拠の範囲：S18の表情と内面の不一致を、共通知識の情報差で整理した提案。

<a id="w02"></a>

## W02　すぐに聞けない理由を、その場に置く

- 見ること：人目、時間、立場、過去の返答など、確認をためらう具体的な理由。
- 使う条件：一言聞けば解けるのに、展開の都合だけで誰も聞かない場面。
- 比較案：聞きかけて言い換える／別の用件が先になる／聞くこと自体の負担を見せる。
- 代償・例外：障害を次々に追加して長引かせない。聞けたなら解ける、聞いても価値観の差が残る、両方を選べる。
- 根拠の範囲：S18と人物の目的・制約からの応用。

<a id="w03"></a>

## W03　沈黙の中で変わる行為を選ぶ

- 見ること：返事を待つ、片付けを続ける、話題を戻す等、無言の前後の違い。
- 使う条件：無言の顔を並べても、安心・退屈・気まずさを区別しにくい場面。
- 比較案：やりかけの動作を止める／いつもの応答を外す／距離は同じまま視線の宛先を変える。
- 代償・例外：全ての沈黙に汗や黒背景を加えない。小道具を意味深にしすぎると別の謎が立つ。
- 根拠の範囲：S23の所作・情報量の制作法を、沈黙の差へ応用する提案。

<a id="w04"></a>

## W04　読者にだけ分かる範囲を選ぶ

- 見ること：読者はどちらの意図を知るか。笑えるすれ違い、痛い沈黙、判断できない状態のどれが狙いか。
- 使う条件：人物の勘違いと、読者の情報不足が混同される場面。
- 比較案：両方の事情を見せる／片方の視点を守る／訂正可能な手掛かりだけ渡す。
- 代償・例外：読み手に全てを教えると謎は減る。伏せる場合も、誰が何に反応したかは追えるようにする。
- 根拠の範囲：S18の内面を伏せる方法と、共通知識からの提案。

<a id="w05"></a>

## W05　誤解が解けた後の感情まで消さない

- 見ること：情報を訂正したことで解ける問題と、傷ついた気持ち・異なる望み。
- 使う条件：事情説明の直後に全員が笑顔になり、関係の変化が飛ぶ場面。
- 比較案：一言謝る／用件だけ進める／まだ話せないことを残す／別の距離でやり直す。
- 代償・例外：軽い誤解なら即座に笑って終えてよい。深刻化も完全解決も一律に強制しない。
- 根拠の範囲：S18と先行の怒り・関係の監修を踏まえた提案。
