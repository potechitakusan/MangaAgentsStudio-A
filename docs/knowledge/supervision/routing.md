# 監修を使う場面と進め方

版0.3.2では、今回の場面で何を伝えたいかを先に決め、次から必要なテーマを選ぶ。作品全体のジャンル名だけで監修を起動しない。

| おかしな行動への受け方を選ぶ | [ツッコミ](tsukkomi/README.md) | 試行版。笑い以外の人物・関係の表現にも使える |
| ヌードや性行為なしに相手を意識させる | [非露骨な色気](allure/README.md) | 試行版。読者への魅力提示と人物間の変化を区別 |

親密な関係や近い距離があるだけで、色気の監修を選ばない。家族の習慣や友情なら信頼、特別に思う気持ちなら好意、技能や覚悟への尊敬なら格好よさを、場面の狙いに応じて選ぶ。対象となる効果がない場合は、専用監修を対象外にできる。

1. 中心にする効果、併用する要素、保ちたい人物像・感情・設定を確認する。
2. 選んだテーマから必要な項目だけ読む。資料の主張を確認するときは [出典](sources.md) を参照し、適用条件・別案・例外を比較する。
3. 人物の一貫性、因果、知識差、読順、終幕は [汎用知識](../review-workflow.md#common-knowledge) へ戻す。
4. 字コンテでは表現案と代償を比較する。PNG作成後は対象画像を実際に開き、狙いが伝わるかを確かめる。
5. メインエージェントが採否を判断し、採用した変更を再提示・再確認する。

## テーマを併用する

戦闘中なら攻防の因果と勝敗の緊張、恋愛場面なら双方の願いと選択など、作品が必要とする効果を保つ。笑いのために能力の条件を消したり、真剣な申し出への返答を省いたりしない。笑いが主でない場面では、笑いを増やすこと自体を目標にしない。

例えば相手を意識する瞬間を主効果にするなら、ツッコミは照れ隠しや人物の声として必要な範囲で比べる。読者への魅力提示を、作中の恋愛成立へ自動で置き換えない。各テーマの効果を一律に最大化せず、主効果に照らして変更しない案も残す。

強者の登場でも、憧れを主にするなら格上感、逃れられない脅威を主にするなら恐怖から読む。怒った顔があっても笑いの受けが中心ならツッコミを選び、怒りが残るなら争点や関係の変化を確認する。悲しむ人物に怒りが混じっても、一方へ整理せず主効果と必要な応答を保つ。色気・格好よさ・親密さを一つの魅力の尺度にまとめない。

危機は今後の結果や選択の切迫、種明かしは情報による読みの更新、逆転は局面と得たものの変化から選ぶ。気まずさは意図と受け取りの差、駆け引きは相手を動かそうとする一手、和解は対立後に選ぶ関係から読む。同じ表情・沈黙だけでテーマを決めず、一覧の全テーマを自動で適用しない。

監修結果には、使ったテーマ・項目と実際に確認した範囲を明記する。追加15テーマの知識は試行版で、一般的な読者効果は未検証。作品ごとのPNG・試読で確かめ、文章だけでの判断を画像レビュー済みにしない。

## 返す内容

- 対象の版・箇所・実際に確認した範囲。
- 字コンテ・画像で確認できた事実と、読者の受け取り方の仮説。
- 変更案、渡す手掛かり、期待する効果と失う可能性のある効果。
- 確認に使ったキット内の文書・項目、未確認事項、メインが判断する採否。

エージェントの見立てを実読者の反応として記録しない。新しい評価点・重みは追加せず、必要なら作品内の `docs/reviews/SUPERVISION.md` を使う。
