# 非露骨な色気・相手を意識する瞬間の監修

追加：2026-09-19。試行版。ヌードや性行為を用いず、視線・所作・距離・人物関係から、相手を意識する瞬間を設計する。対象人物の年齢、関係、作品の表現範囲を既存設定から確認する。年齢不明の人物に成人向けの含意を補わない。

主な直接資料は一枚絵の制作解説。漫画の連続した場面への応用は、[出典台帳](../sources.md)と [共通知識](../../review-workflow.md#common-knowledge) を踏まえた本キットの制作提案であり、読者が色気を感じることを保証しない。以下のA01～A06は、人物像と場面の狙いに応じて選ぶ。

## 最初に決めること

「読者に人物を魅力的に見せる」「登場人物が相手を意識する」「双方の関係が変わる」のどれが今回の狙いかを分ける。本人が魅力を見せようとしているか、無自覚かも確認する。恋愛、尊敬、安心、緊張を自動で同一視しない。

<a id="a01"></a>

## A01　誰が、何に目を留めるか

- 見ること：見る人、視線の先、気づいた瞬間が特定できるか。読者向けの構図と、作中人物の視点が混ざっていないか。
- 見られる側の意図と、見る側の解釈を分ける。片方が見入ったことだけで、相手も誘っている・好意があると確定しない。
- 使う条件：魅力的な絵はあるが、誰が相手を意識したのか分からない場面。
- 比較案：見る側の行動を一つ変える／視線の対象を明確にする／人物単体の見せ場として扱う。
- 代償・例外：反応を足すと、読者の解釈を狭めることがある。人物単体の魅力を見せる場面には、作中の見物人を必須にしない。
- 根拠の範囲：[S06](../sources.md#s06)は一枚絵の視線の参考。見る側との接続は共通の視点知識からの応用。

<a id="a02"></a>

## A02　普段と違う一瞬を、用件の中に置く

- 見ること：普段の態度と今回の変化、変化の理由が分かるか。真剣さ、ためらい、気遣いなどがその人物の目的から生じているか。
- 使う条件：赤面や寄りの絵だけが追加され、人物の見え方がどう変わったか分からない場面。
- 比較案：普段は止めない作業が止まる／いつもの軽口を言いかけて別の返事にする／相手の仕事ぶりへ目を留める。
- 代償・例外：無理なギャップは人物の一貫性を崩す。普段から魅力を意識して見せる人物には、変化より持続する余裕が合う場合もある。
- 根拠の範囲：[S04](../sources.md#s04)・[S07](../sources.md#s07)・[S08](../sources.md#s08)からの応用。これらが色気の効果を実証したとは扱わない。

<a id="a03"></a>

## A03　所作と距離に、その場の理由を持たせる

- 見ること：手を動かす理由、近づく理由、相手がその動きをどう受け取るか。衣服・道具・空間の使い方が普段の人物像と合うか。
- 使う条件：見せ場のためだけに不自然な接近やポーズが入る場面。
- 比較案：共同作業の手渡しに注目する／離れたまま視線が合う／近づきかけて相手の反応を待つ。
- 代償・例外：日常動作を細かく増やしすぎると、用件が進まなくなる。近さを強めても、親密さではなく圧迫に読まれる場合がある。相手の選択を手掛かりにする。
- 根拠の範囲：[S05](../sources.md#s05)・[S06](../sources.md#s06)の所作を参照。相互作用は本キットの提案。

<a id="a04"></a>

## A04　気づきの後の、小さな選択を描く

- 見ること：相手を見た後に返事、手、視線、姿勢、用件の扱いのどれが変わるか。反応の原因を特定できるか。
- 使う条件：心情の説明はあるが、相手を意識したことが行動に表れない場面。
- 比較案：返事を言い直す／手渡し後も一瞬相手を見てしまう／平静を装って用件を続ける。内語を残す案とも比べる。
- 代償・例外：無言や赤面を増やすだけでは好意は確定しない。驚き、疲れ、不快さなど別の読みがある。曖昧さを残す狙いなら、それを欠陥にしない。
- 根拠の範囲：[S04](../sources.md#s04)・[S07](../sources.md#s07)と既存の演技の応用。

<a id="a05"></a>

## A05　注目点を選び、身体の記号へ固定しない

- 見ること：表情・手つき・衣服・姿勢のうち、今回見る側が意識する対象は何か。性別や身体部位だけで魅力を説明していないか。
- 使う条件：細部を増やしたのに、何を見ればよいか分からない画面。
- 比較案：行動の分かる画面から細部へ寄る／対象の細部を一つ選ぶ／寄らずに距離と視線で伝える。
- 代償・例外：細部への寄りは空間や主体を見失わせる場合がある。人体の描写を減らすこと自体は目標にしない。資料の服装・髪型・身体的特徴をそのまま必須条件にしない。
- 根拠の範囲：[S05](../sources.md#s05)・[S06](../sources.md#s06)を参照した注目点の検討。

<a id="a06"></a>

## A06　余韻と、場面が果たす用件を両立させる

- 見ること：相手を意識した後に、返答や選択がどう変わるか。ギャグ、危機、別れなどの主効果と競合していないか。
- 使う条件：見つめ合いを加えた結果、必要な話が止まる、真剣さが消える場面。
- 比較案：用件への返答を保った小さな変化にする／魅力を見せる箇所を移す／今回は強めない。
- 代償・例外：関係の進展を早めると、まだ気づかない段階の面白さを失う。人物の真剣な反応を、機械的に照れや笑いへ変えない。
- 根拠の範囲：[S08](../sources.md#s08)と既存の主効果・場面変化の応用。

## 表現を比較するときの問い

| 比較 | 揃える条件 | 確かめる差 |
| --- | --- | --- |
| 読者への見せ場／作中人物が見入る | 人物と動作 | 誰の感情として読めるか |
| 自覚的／無自覚 | 同じ用件・同じ関係 | 誘う意図があるように見えるか |
| 接近／距離を保つ | 相手への関心 | 親密さ、ためらい、圧迫のどれに読めるか |
| 反応を示す／解釈を残す | 渡す出来事と設定 | 意識したことの明確さと余韻 |

比較対象の差以外まで一度に変えない。性的な露出や行為を足して強度を上げる監修には使わない。好意がない設定を、監修の都合で恋愛へ変更しない。

## 返す指摘と確認

対象箇所／見えた事実／読みの仮説／A番号／変更案／期待する効果と代償を返す。台詞や字コンテから、完成画像の微妙な表情・距離感を確認済みにしない。

PNGでは視線の先、人物間の空間、所作の意味が掲載寸法で読めるかを見る。試読では、まず「誰が何を意識したと読んだか」「そう読んだ箇所」を聞き、その後で魅力・好みを聞く。観察者の憧れや尊敬として読まれた場合も記録し、色気に読み替えない。[共通レビュー](../../review-workflow.md)へ戻す。
