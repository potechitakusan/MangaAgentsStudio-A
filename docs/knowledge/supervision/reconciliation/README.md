# 和解・赦し・救いの監修

状態：試行版。更新・資料確認：2026-09-19。対立や傷の後、人物がどんな関係・生き方を選ぶかを扱う。[S18](../sources.md#s18)・[S17](../sources.md#s17)と、先行の [怒り](../conflict/README.md)・[喪失](../grief/README.md)・[信頼](../trust/README.md)を踏まえた**制作提案**。以下の区分は本キットの整理であり、出典の作者が提示した和解の手順ではない。

対立する欲求、選択、場面の閉じ方は [物語・人物](../../manga/05-story-character.md)へ戻す。全ての関係を仲直りで終える規則にしない。

<a id="q01"></a>

## Q01　今回どこまで変わるかを分ける

- 見ること：争いを止める、事情を知る、謝罪を受け取る、赦す、再び関わる、生活を続ける、のどれか。
- 使う条件：一度の謝罪や救助で、全部が同時に成立した扱いになる場面。
- 比較案：用件だけ協力する／謝罪は聞くが関係は戻さない／距離を置いて新しい生活へ進む。
- 代償・例外：全面的な和解も選べる。狙った変化が何かを場面の応答で支える。相手が不在・死亡している場合も救いを扱え、対面の謝罪や関係の再開を要件にしない。
- 根拠の範囲：S18の内面と外からの理解の差、先行テーマを踏まえた独自の整理。

<a id="q02"></a>

## Q02　事情の理解と、行為の責任を分ける

- 見ること：何をしたと認め、どの影響に向き合うか。動機の説明が行為の取り消しになっていないか。
- 使う条件：過去や弱みを明かすだけで、相手の傷や拒否が消える場面。
- 比較案：行為を具体的に認める／実害に対応する／相手の受け取りを聞く。
- 代償・例外：説明を法廷のように網羅する必要はない。一方的な加害の責任を機械的に折半しない。
- 根拠の範囲：S18と怒りの争点・人物の共通知識からの提案。

<a id="q03"></a>

## Q03　謝罪後の選択を、できる行動へつなぐ

- 見ること：次に何を変え、何を続けるか。言葉だけで信用が回復したことにしていないか。
- 使う条件：謝罪はあるが、その後の関係を支える変化が見えない場面。
- 比較案：約束を小さくして守る／返せるものを返す／相手の望む距離を保つ。
- 代償・例外：償いの大きさと赦される権利を交換しない。すぐに行動できない場合も、制約と選んだ方針を示せる。
- 根拠の範囲：S17のできる範囲・信用を、関係の再構築へ応用する提案。

<a id="q04"></a>

## Q04　受け手にも、選ぶ時間と返答を置く

- 見ること：相手は何を受け取り、まだ何を受け取れないか。表情から赦しを補完していないか。
- 使う条件：謝る側の見せ場だけで、受けた側が結末のために応じる場面。
- 比較案：条件を付ける／今は決めない／断る／自分から手を伸ばす。
- 代償・例外：無言の受容も成立するが、前後の行動でどこまで読めるかを点検する。急いで応じないことを未熟さと決めない。
- 根拠の範囲：S18の表情と内面を分ける制作観からの応用。

<a id="q05"></a>

## Q05　救いを、その人物が再開できる行為で確かめる

- 見ること：今日の用件、他者への相談、新しい関係等、最後に何を自分で選べるか。
- 使う条件：明るい台詞や抱擁を加えるだけで、解決した印象にまとめる場面。
- 比較案：日常を一つ再開する／同じ場に別の距離でいる／相手と会わずに次へ進む。
- 代償・例外：未解決の感情を残してもよい。喪失・決裂を取り消すことだけを救いにしない。
- 根拠の範囲：S18と喪失・終幕の共通知識からの提案。心理的回復の指針ではない。
