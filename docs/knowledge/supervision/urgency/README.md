# 危機・焦燥・切迫感の監修

状態：試行版。更新・資料確認：2026-09-19。失敗の可能性が迫り、今の選択が重要になる場面を扱う。[S19](../sources.md#s19)・[S22](../sources.md#s22)・[S23](../sources.md#s23)を踏まえた**制作提案**。期限・資源・残る機会への整理は本キットの応用であり、資料の直接の法則ではない。

脅威の正体や気配は [不穏・恐怖](../horror/README.md)、解決による解放は [逆転](../payoff/README.md)。行動の因果と時間は [場面](../../manga/04-scene-dialogue-props.md)・[緩急](../../manga/03-beat-pacing-timing.md)を参照する。

<a id="u01"></a>

## U01　失敗したら何が失われるかを具体化する

- 見ること：守りたいもの、達成すべき用件、失敗の結果。人物自身にとってなぜ大切か。結末が既知なら、そこに至る選択・経過・代償のどこが切迫しているか。
- 使う条件：急いでいる台詞だけで、間に合わない意味が読めない場面。
- 比較案：閉まる窓口／壊れる約束／残り一回の機会など、作品にある損失を一つ渡す。
- 代償・例外：切迫感のために死亡や巨大な被害を加えない。小さな用件でも人物にとって重大なら成立する。
- 根拠の範囲：S19の失敗があり得る制作観を、日常も含む危機へ応用。

<a id="u02"></a>

## U02　残り時間・手段・機会の変化を見せる

- 見ること：何が減り、どの選択肢が使えなくなったか。前後の数値や位置は整合するか。
- 使う条件：カウントダウンしても状況が変わらない、制限が後から伸びる場面。
- 比較案：使える道を一つ失う／一工程進むが資源を使う／他者の行動で期限が変わる。
- 代償・例外：時計の表示は必須ではない。制限を厳しくするだけでは人物の工夫が消える。
- 根拠の範囲：S22の要所と選択、共通知識の因果からの制作提案。

<a id="u03"></a>

## U03　試みと結果をつないで焦りを生む

- 見ること：人物が何を試し、結果をどう読んで次に動くか。焦りのために知識や技能を忘れていないか。
- 使う条件：叫び・走る絵だけが続き、行動の進展が見えない場面。
- 比較案：最善の手が部分的に失敗する／協力を頼む／目的を絞って何かを諦める。
- 代償・例外：動けない焦りも成立する。その場合は動けない条件と、それでも待つ意味を示す。
- 根拠の範囲：S22の人物自身の考えから選択肢を出す制作法の応用。

<a id="u04"></a>

## U04　待つコマにも、何を待つかを残す

- 見ること：返答、移動、作業の完了など、結果を待つ対象と進行状況。
- 使う条件：コマを細かくすれば速く読めると決めつけ、肝心の判断が飛ぶ場面。
- 比較案：短い行為を連ねる／一瞬の判断を大きく取る／静かな待機と外の進行を対比する。
- 代償・例外：細分化は時間を長く感じさせることもある。紙・単ページ・スクロールの実表示で確認する。
- 根拠の範囲：S23の緩急と共通知識からの提案。読書速度の実測ではない。

<a id="u05"></a>

## U05　一息ついた後にも残る条件を確認する

- 見ること：何が解決し、何がまだ危ないか。小さな成功を全問題の解決にしていないか。
- 使う条件：危機が続きすぎる、または冗談一つで制限まで消える場面。
- 比較案：一つの工程を終える／次の手段を確保する／今だけ安堵して再開する。
- 代償・例外：休止で緊張は弱まるが、次の変化を読める余地も作れる。常時最大の焦りにしない。
- 根拠の範囲：S19の日常の明るさと受け止めへの配慮からの応用。

## 比較・画像・試読

期限・資源・能力・結末を保ち、制限の提示時点や行動の粒度を比較する。PNGでは位置、残りの量、結果が来る順番を確認する。試読では「何が間に合わないのか」「どの行動で選択肢が変わったか」を聞く。実作品PNGと読者による比較検証は未実施。[共通手順](../routing.md)に従う。
