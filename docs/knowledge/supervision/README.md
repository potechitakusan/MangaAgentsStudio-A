# 漫画の監修知識

版0.3.2では、既存のギャグ監修に、以下の15テーマの試行版を追加する。場面で狙う効果から必要な知識を選び、字コンテ・ネームの表現案とPNGプレビューの改善案を考える。

- [ギャグのノウハウ](gag/README.md)：笑いの仕組み、期待と証拠、発想と点検。
- [ツッコミ・異常への反応](tsukkomi/README.md)：訂正・無言・受け流し、人物の声、関係への影響。
- [非露骨な色気](allure/README.md)：見る側、所作、距離、普段との差、相手を意識する瞬間。
- [格好よさ・格上感](stature/README.md)：実力の証拠、判断、覚悟、周囲の反応、弱さとの両立。
- [不穏・恐怖](horror/README.md)：日常との差、情報の提示、待つ間の変化、陰影・音、人物の行動。
- [怒り・口論・決裂](conflict/README.md)：争点、食い違い、怒り方、越えた一線、その後の関係。
- [悲しみ・喪失・余韻](grief/README.md)：不在、変わる習慣、混じる感情、反応の時点、残るもの。
- [好意・照れ・恋の予感](romance/README.md)：好意の主体、自覚、特別な選択、返答。
- [親密さ・信頼](trust/README.md)：任せる範囲、役割、習慣、違いを保つ応答。
- [気まずさ・すれ違い](awkwardness/README.md)：事実と解釈、聞けない理由、沈黙、訂正後の感情。
- [危機・焦燥・切迫感](urgency/README.md)：失うもの、残る機会、試みと結果、待つ時間。
- [驚き・発覚・種明かし](revelation/README.md)：解釈の更新、手掛かり、開示の位置と反応。
- [爽快感・逆転・解放](payoff/README.md)：制約、局面が変わる理由、報われるものと代償。
- [可愛げ・愛着](endearment/README.md)：こだわり、反応差、立て直し、能力・責任との両立。
- [駆け引き・探り合い](bargaining/README.md)：各人物の目的と情報、一手への応答、変わる条件。
- [和解・赦し・救い](reconciliation/README.md)：謝罪、受け取り、選ぶ距離、再開する行為。
- [監修を使う場面と進め方](routing.md)：必要な観点と主効果の選び方。
- [出典と適用範囲](sources.md)：追加15テーマの一次資料、応用した範囲、未検証事項。
- [汎用知識](../review-workflow.md#common-knowledge)：人物・因果・情報・読順・終幕。

手順は `manga-supervision` にまとめ、メインエージェントが制作判断と採否を統合する。キットでは `skills/manga-supervision/SKILL.md`、作品では `.agents/skills/manga-supervision/SKILL.md` を使う。

作品ジャンルにかかわらず、対象場面に必要なテーマだけを使う。専用知識のない効果は既存の制作知識とレビューで扱い、対応済みの専用監修として説明しない。

追加15テーマは資料調査と文章上の予備点検を行った試行版。一般的な読者効果は未検証であり、作品ごとのPNGと試読で確かめる。公開資料の図版確認、独自課題の自己点検、読者の実反応を区別する。監修文書の配布ファイル一覧は `distribution.json` に記載する。
