# 格好よさ・格上感の監修

状態：試行版。更新・資料確認：2026-09-19。人物の実力、判断、覚悟、存在感を場面で伝えたいときに使う。戦闘以外の仕事・競技・日常にも応用する。以下は作者の制作観と共通知識を踏まえた**制作提案**であり、読者効果の実証ではない。

主な資料は [S09](../sources.md#s09)・[S10](../sources.md#s10)。真島ヒロ氏の強さに関する制作観と、水上悟志氏の生活感・脇役・勝敗に関する制作観を比較する。圧力下の選択や人物の能力差は [人物の共通知識](../../manga/05-story-character.md) を参照する。

<a id="k01"></a>

## K01　何の格好よさを見せるかを決める

- 見ること：技能、判断、信念、引き受ける責任、見た目の存在感のどれが狙いか。作中人物の憧れと、読者への見せ場を分ける。
- 使う条件：「もっと強そうに」だけでは修正箇所が決まらない場面。
- 比較案：結果で技能を示す／難しい判断を見せる／登場時の姿を見せる。同じ人物でも今回の軸を絞る。
- 代償・例外：外見の見せ場に毎回実力の証明を足すと流れが止まる。強者としての威圧と、人としての好感は一致しなくてよい。
- 根拠の範囲：S09・S10を踏まえた魅力の軸の整理。

<a id="k02"></a>

## K02　比較の基準と、差が出た理由を渡す

- 見ること：課題や相手の難しさ、成功の条件、本人が変えた点が分かるか。周囲の賞賛だけで実力を代用していないか。評判の発信者と、作中で実際に確かめられた範囲を分ける。
- 使う条件：勝利や解決は描かれているが、どこが優れていたか読めない場面。
- 比較案：先に難しさを一つ示す／相手の有効な手を残す／同じ制約に対する判断の差を見せる。
- 代償・例外：解説が増えると速さや圧倒感を失う。相手を急に無能にしたり、既出の能力制限を消したりしない。噂や他者の反応だけで格を予告する導入も成立するが、未証明の評判と実力の確認は区別する。
- 根拠の範囲：S09の対戦相手の描写、S10の脇役の扱いと勝敗観からの応用。

<a id="k03"></a>

## K03　選んだものと引き受けたものを見せる

- 見ること：何を守り、何を諦め、どの行動を選んだか。決め台詞と実際の判断がつながるか。
- 使う条件：覚悟を語っているが、行動の違いが見えない場面。
- 比較案：危険を引き受ける／助けを求めて責任を果たす／無益な勝負から退く。場面の目的に合う選択を比べる。
- 代償・例外：自己犠牲を増やすこと自体は目標にしない。軽快さや余裕が狙いなら、苦悩を追加しない案も残す。
- 根拠の範囲：S09・S10と共通知識の「圧力のある選択」を、この効果に適用した提案。

<a id="k04"></a>

## K04　見せ場と周囲の反応を配分する

- 見ること：本人の行為と、それを見た人物の対応が読めるか。驚く、構え直す、任せるなど、反応が能力の説明と重複していないか。
- 使う条件：大ゴマや賞賛を増やしたのに、人物の印象が強まらない場面。
- 比較案：行為を大きく見せる／小さな所作に周囲の変化を添える／本人の登場前に影響を見せる。
- 代償・例外：全員に感嘆させると、他の人物の経験や対抗心を消す。大ゴマ・見開き・煽り構図は選択肢。掲載形式や見せたい動作に合わなければ採らない。
- 根拠の範囲：S09の見せ場の配分と、共通の視点・反応順の応用。

<a id="k05"></a>

## K05　弱さ・生活・勝敗との関係を保つ

- 見ること：今回の見せ場のために、既存の不得意や生活上の役割を消していないか。勝敗をそのまま人格や信念の正しさに置き換えていないか。
- 使う条件：格上に見せる改稿で万能化し、人物らしさや後の難題が失われる場面。
- 比較案：不得意を仲間に任せる／敗北しても守ったものを示す／戦闘後の責任まで描く／ここでは余裕を保つ。
- 代償・例外：弱点や生活描写の挿入も必須ではない。神秘性を保つ登場場面や、完璧さ自体を楽しむ作風なら、説明を先へ送れる。
- 根拠の範囲：S10の制作観を比較案に使う。全作品の主人公像として強制しない。

## 比較・画像・試読

同じ課題・能力・結果を保ち、「行為の証拠／周囲の反応」「余裕／迷い」「勝利／守ったもの」のうち必要な差だけを比べる。PNGでは動作の起点と結果、相手の有効な行動、見せ場の読順を確認する。姿の良さから実力まで確認済みとしない。

試読では、先に「この人物は何に優れていると読んだか」「そう読んだ箇所」を聞き、次に格好よさ・好みを聞く。項目番号、観察、仮説、採否、代償は [共通の監修手順](../routing.md) に従う。実作品PNGと読者による比較検証は未実施。
