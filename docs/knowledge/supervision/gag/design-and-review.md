# ギャグの発想と監修

整理日：2026-09-17。字コンテとプレビューに使う制作提案。[仕組みの索引](mechanisms.md)と併用する。コマ数・コマ割りの処方は含めない。

## 字コンテで案を出す

1. 今回の主効果と、笑いを加えても残す感情・関係を決める。笑いが主でない場面では、それを強めること自体を目標にしない。
2. 読者がまず信じる前提と、普通なら予想する答えを書く。予想の根拠が作中にあるか確認する。
3. 目的・評価・解釈・条件・程度・役割など、ずらす軸を選ぶ。ずれのためだけに新設定や性格変更を足さない。
4. 実際の答えが前の事実と両立し、人物の欲求から生じるかを見る。必要な証拠を絵・台詞・行動のどれで渡すか決める。
5. 受け手は、この人物ならどう反応するかで選ぶ。常識の基準を置く、別の評価をする、増幅する、自分も偏る、受け入れる、無言で反応する、省略するという選択がある。
6. 答えが分かった後の説明を整理し、笑いの対象、人物への印象、主効果への影響を比較する。

人物の欲求・誤認・長所と弱点・知識差は [人物](../../manga/05-story-character.md)・[演技](../../manga/04-scene-dialogue-props.md) と [情報と間](../../manga/03-beat-pacing-timing.md) を使う。

## 人物と反復を使う

ボケ・ツッコミはその場の働きで、固定した人格ではない。普段訂正する人が、自分の関心事で偏るなら、交代の理由を読者が拾えるようにする。第三者を足す場合は別の知識・関心・利害を持たせ、同じ訂正の言い直しを増やさない。

反復は「同じことをまたする」だけでなく、対象、立場、受け手、程度、結果、本人の自覚のどれが変わるかを見る。予想どおりの行動でも、その実行の仕方や新しい帰結が楽しみになる案を考える。既存の関係を知らないと成立しない部分は明示し、初見向けの手掛かりを残す。

## プレビューで見る

実際の対象画像を開き、版・ページ・該当箇所を特定する。以下から不成立の疑いがあるところを選ぶ。全項目を機械的に埋めない。

- 前提と通常の期待が読めるか。単に状況が分からない状態を意外性と扱っていないか。
- ずれを確定させる証拠が見えるか。必要な対象や条件が欠けていないか。
- 題・表情・台詞などから答えが早く分かる場合、その後にも楽しみがあるか。
- 受け手の反応は新しい意味を足すか。すでに読めることを説明し直していないか。
- 真剣な感情、解決の価値、相手の選択がオチで取り消されていないか。
- 原因の説明なしに人物が急に無能・冷淡に見える変更になっていないか。

「理解できた」と「笑える」は別。監修者の仮説を読者の実反応として記録しない。修正は「該当箇所／見えた事実／読みの仮説／変更案／残す効果と失う効果」で返す。[共通レビュー](../../review-workflow.md)を必要時に使う。
