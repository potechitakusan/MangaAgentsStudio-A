# ギャグのノウハウ

版0.3.1に収録。更新日：2026-09-17。字コンテ・ネームの発想と、PNGプレビューの点検に使う。

| 必要なこと | 読む資料 |
| --- | --- |
| 人物や状況に合うずらし方を選ぶ | [笑いの仕組み23項目](mechanisms.md) |
| 言葉・物・行動からずれを確定する | [期待と証拠の合わせ方](know-how.md) |
| 案を作り、反復や受け手の反応を点検する | [発想と監修](design-and-review.md) |
| 人物・因果・読順・情報・終幕を確認する | [汎用知識](../../review-workflow.md#common-knowledge) |

基本は **前提 → 予想 → ずれ → 理解の証拠と受け方**。情報の関係を点検する順序であり、特定のコマ数・コマ割りを指定するものではない。必要な項目だけを選び、人物の欲求や既に示した設定から笑いを作る。

本文の構造と制作提案は、どの作品でも笑えることを保証する規則ではない。理解できることと面白いことを分け、画像で確認できた事実、読みの仮説、未確認の反応を区別する。
