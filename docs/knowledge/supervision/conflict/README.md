# 怒り・口論・決裂の監修

状態：試行版。更新・資料確認：2026-09-19。怒る人物が何を求め、その言葉や行動で関係がどう変わるかを扱う。以下は**制作提案**。現実の怒りを診断・指導する資料ではなく、作中人物の感情と選択を読める形にするために使う。

主な資料は [S10](../sources.md#s10)・[S13](../sources.md#s13)、人物ごとの表情は [S09](../sources.md#s09)。対立する信念、怖さだけではない怒り、人物固有の表情を比較する。[場面・台詞の共通知識](../../manga/04-scene-dialogue-props.md) と [ツッコミ](../tsukkomi/README.md) を必要時に参照する。

<a id="r01"></a>

## R01　怒りの対象と、求める変化を分ける

- 見ること：誰の何に反応し、相手に何をやめさせる・認めさせる・守らせるのか。本人の言い分と、実際に起きた事実を分ける。
- 使う条件：怒鳴っていることは分かるが、争点が見えない場面。
- 比較案：引き金になった行為を見せる／同じ言葉が人物ごとに違う意味を持つと示す／返答への反応で本当の争点を絞る。
- 代償・例外：怒りを常に正当化する過去や事情を足さない。八つ当たり、誤解、嫉妬も描ける。理由の理解と、その行為への賛同は別。
- 根拠の範囲：S13の価値観と感情をつなぐ方法、共通知識の欲求・働きかけからの応用。

<a id="r02"></a>

## R02　言い合いが続く理由を作る

- 見ること：知っている事実の差、期待の差、譲れない価値の差のどこで噛み合わないか。人物の主張と作中で確認済みの事実を分け、虚偽を単なる価値観の違いへ置き換えない。返答を受けても同じ主張を反復しているだけではないか。
- 使う条件：話せばすぐ解ける誤解なのに、理由なく長い口論になる場面。
- 比較案：事実が分かっても価値が合わない／信頼を失って説明が届かない／相手が欲しい返答と別の返答をする。
- 代償・例外：両者に事情があっても責任まで対称にしない。単純な敵意や一方的な拒絶が狙いなら、無理に双方の正義を追加しない。
- 根拠の範囲：S10の人物ごとの信念と対比を、会話の進行へ応用する。

<a id="r03"></a>

## R03　怒り方に、その人の声と段階を残す

- 見ること：語尾、呼び方、返事の長さ、手元、立ち位置が普段からどう変わったか。強い表情だけが先行していないか。
- 使う条件：全員同じ怒鳴り顔になる、または「静かな怒り」に統一されて人物が薄れる場面。
- 比較案：声を荒らげる／敬語へ戻る／言い直す／作業を止める。前後の応答と組にして選ぶ。
- 代償・例外：叫びや涙がその人に合うなら残す。小さな変化はPNGで見分けられる必要があり、字コンテに書いただけでは成立しない。
- 根拠の範囲：S09・S13の人物別の感情表現と、共通の演技・反応の応用。

<a id="r04"></a>

## R04　越えた一線を、その後の行動で示す

- 見ること：その言葉・行為によって、任せる、触れる、連絡する、一緒にいる等の関係がどう変わるか。
- 使う条件：決裂したはずなのに次のコマから元通り、または口論を強めるだけの場面。
- 比較案：会話を打ち切る／共有していた役割をやめる／別行動へ移る／決裂を避けるため言い直す。
- 代償・例外：関係を切る結末も認める。怒りを和らげることや謝罪・和解を成立させることは監修の目標ではない。戻れない傷を増やすと、その後の展開の条件も変わる。
- 根拠の範囲：共通知識の場面前後の差と人物の選択を、怒り・決裂に適用した提案。

<a id="r05"></a>

## R05　受けた側の選択と、笑いとの境界を確かめる

- 見ること：怒りを受けた側は、拒む、聞く、言い返す、去るなど何をしたか。笑いを加えて本来の争点が消えていないか。
- 使う条件：ツッコミや照れへ寄せた結果、深刻な拒絶が軽く読まれる場面。
- 比較案：応答の後に小さな笑いを置く／笑いを別の箇所へ移す／痛みや不一致を残す。
- 代償・例外：無反応も選択になり得るが、同意や解決と決めつけない。普段から激しく言い合う関係では、強い言葉だけを決裂の証拠にしない。
- 根拠の範囲：S10・S13と既存のツッコミ監修からの応用。怒りが必ず愛情に由来するという根拠にはしない。

## 比較・画像・試読

人物の争点と結末を保ち、叫ぶ／抑える、返答する／打ち切る等の表現を比較する。PNGでは誰が誰へ発話し、何を聞いて態度を変えたかを確認する。自分が好む穏やかな言い方へ一律に直さない。

試読では「何をめぐって争っていたか」「最後に関係がどう変わったか」「そう読んだ箇所」を先に聞く。共感できたか、怖かったか、納得できたかは別に聞く。[共通の監修手順](../routing.md) に従い、観察と仮説、採否と代償を分ける。実作品PNGと読者による比較検証は未実施。
