# 驚き・発覚・種明かしの監修

状態：試行版。更新・資料確認：2026-09-19。新しい情報によって出来事や人物の読みが変わる場面を扱う。[S20](../sources.md#s20)・[S23](../sources.md#s23)を踏まえた**制作提案**。伏線の量で驚きが保証されるとは扱わない。

有利不利の変化は [逆転](../payoff/README.md)、次に何が起こるかの緊張は [危機](../urgency/README.md)。視点と前提は [人物・情報](../../manga/05-story-character.md)、提示順は [緩急](../../manga/03-beat-pacing-timing.md)へ戻す。

<a id="v01"></a>

## V01　明かす前後で、何の解釈が変わるかを決める

- 見ること：読者が考えられる状況と、新情報を得た後の状況。驚くのは読者か作中人物か。
- 使う条件：大きな表情はあるが、何が意外なのか分からない場面。
- 比較案：前の行為の理由が変わる／物の用途が分かる／人物の認識だけが追いつく。
- 代償・例外：読者が先に知っていても人物の発覚は成立する。毎回読者の予測を覆す必要はない。
- 根拠の範囲：S20の仕込みを、情報差の共通知識で整理した提案。

<a id="v02"></a>

## V02　渡した手掛かりと、後の説明を照合する

- 見ること：前の絵・台詞・物の配置が、種明かし後も成立するか。人物が知る情報を不自然に隠していないか。
- 使う条件：後出しの設定だけで、それまでの出来事を説明し直す場面。
- 比較案：先に自然な役割のある手掛かりを置く／既出の物を違う意味で見る／後の説明を限定する。
- 代償・例外：全ての驚きに推理可能な伏線は不要。謎解きの納得を狙う時は、再読で矛盾しないかを確かめる。
- 根拠の範囲：S20を踏まえた点検方法。公正さの基準は作品の狙いに合わせる。

<a id="v03"></a>

## V03　答えが最初に見える位置を確認する

- 見ること：台詞、背景、見開き、サムネイルなどで、答えが想定より早く目に入らないか。
- 使う条件：めくりや画面外を使って明かす場面。
- 比較案：前の問いを整える／答えを見せる範囲を調整する／先に見えるなら予感として構成する。
- 代償・例外：隠すために必要な行動まで見えなくしない。同時表示では紙と同じめくりを再現できないことがある。
- 根拠の範囲：S23のめくりを掲載形式に合わせて点検する提案。

<a id="v04"></a>

## V04　情報を理解する瞬間と、反応を配分する

- 見ること：何を見て意味が分かり、その後どう動くか。説明と驚き顔が同じことを繰り返していないか。
- 使う条件：説明が長くて勢いを失う、または省略しすぎて理解できない場面。
- 比較案：証拠を一つ見せて反応へ進む／短い確認を挟む／行動の変化で理解を示す。
- 代償・例外：無言が常に優れるわけではない。推理の筋道自体を楽しむ作品なら説明を残す。
- 根拠の範囲：S23と共通の反応順からの応用。

<a id="v05"></a>

## V05　驚きが、次の選択や読み直しへ何を残すかを見る

- 見ること：明かした情報で行動・関係・目標が変わるか。既存の人物像と矛盾しないか。
- 使う条件：予想外の事実を足すことだけが目的になった場面。
- 比較案：過去の選択の意味を変える／今の手段を変える／知っても選択が同じだと見せる。
- 代償・例外：一瞬の意外さだけを狙う小ネタも成立する。先読みされた事実だけで失敗と決めない。
- 根拠の範囲：S20と人物・終幕の共通知識からの提案。
