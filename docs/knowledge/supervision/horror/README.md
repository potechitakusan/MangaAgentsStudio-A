# 不穏・恐怖の監修

状態：試行版。更新・資料確認：2026-09-19。何かがおかしい予感、近づく脅威、理解しきれない出来事を扱う。以下は**制作提案**であり、作者が狙った恐怖と読者が実際に感じた恐怖を分ける。

主な資料は [S11](../sources.md#s11)・[S12](../sources.md#s12)。陰影や描線の使い方と、音・不確かさを漫画へ置き換える作者の方法を比較する。情報差と提示順は [緩急・提示の共通知識](../../manga/03-beat-pacing-timing.md) を参照する。

<a id="h01"></a>

## H01　何が普段と違うかを読めるようにする

- 見ること：その世界・その人にとっての通常と、今回外れた点が分かるか。読者だけが異常に気づくのか、人物も気づくのか。
- 使う条件：不気味な物を置いたが、設定上の日常との違いが伝わらない場面。
- 比較案：同じ場所の変化／いつもの手順の不成立／周囲が反応しない異変など、比較できる手掛かりを選ぶ。
- 代償・例外：平常場面を長く足すと導入が鈍る。冒頭から異常な世界でも、局所の規則や人物の対応を足場にできる。
- 根拠の範囲：S11・S12の違和感に関する制作観からの応用。

<a id="h02"></a>

## H02　伏せるものと、追うために必要な情報を分ける

- 見ること：場所、追う人物、起きたこと、危険の手掛かりのどこまでを渡したか。正体の不明さと、画面が読めないことを混同していないか。
- 使う条件：隠しすぎて状況が不明、または説明しすぎて想像の余地がなくなった場面。
- 比較案：結果だけを示す／一部の姿を見せる／全貌を見せても理由や次の行動を伏せる。
- 代償・例外：正体を見せる恐怖もある。隠す方が常に怖いとはしない。謎解きが狙いなら、後で理解するための証拠を消さない。
- 根拠の範囲：S12の漫画化による具体化の課題と、共通知識の情報提示を組み合わせた提案。

<a id="h03"></a>

## H03　待つ間に、予想か危険を動かす

- 見ること：静かなコマの前後で、音の位置、残された選択肢、人物の認識などが変わるか。
- 使う条件：同じ暗い景色が続き、待つ理由が分からなくなった場面。
- 比較案：兆候を繰り返しながら一箇所変える／人物の確認行動を挟む／急に結果へ飛ぶ。
- 代償・例外：予告を足すと突然の驚きを失う。ページめくりを使う場合は、見開き・単ページ・縦スクロールで後の情報が先に見えないか確かめる。
- 根拠の範囲：共通知識の「延ばすほど、期待か危険を変化させる」を恐怖へ応用したもの。特定コマ数や読了時間の実証値はない。

<a id="h04"></a>

## H04　陰影・描線・音を、異変の手掛かりへ結び付ける

- 見ること：黒、白、線の密度、描き文字の有無が、何を感じさせるための選択か。見つけてほしい手掛かりが埋もれていないか。
- 使う条件：背景を暗くするだけの改稿や、怖さと無関係な描き込みが増えた場面。
- 比較案：黒のまとまり／明るい中の一箇所の違和感／音を言葉・反応・画面の密度で示す。場面に必要な情報量を比べる。
- 代償・例外：抽象表現だけでは何が起きたか分からないことがある。陰影、無音、細線のどれも必須ではない。資料の図柄や描線を再現する指示にはしない。
- 根拠の範囲：S11・S12の制作方法。S12の音の場面の図版1点を目視したが、前後全編と一般読者の反応は未確認。

<a id="h05"></a>

## H05　人物が恐れる理由と行動を保つ

- 見ること：本人の知識、失いたくないもの、逃げる・確かめる・留まる理由がつながるか。
- 使う条件：恐怖を増やすために人物が既知の危険へ理由なく近づく、または全員が同じ反応になる場面。
- 比較案：合理的な確認でも解消しない異変／行動した結果の予想外／平静な人と動揺する人の違い。
- 代償・例外：人物の不合理さ自体が狙いなら直さない。危機の時間制限が主なら共通知識で扱い、超常的な不気味さを自動追加しない。残酷描写を強めることは恐怖監修の前提にしない。
- 根拠の範囲：S12の人物像と恐怖の接続、および共通の人物・因果からの提案。

## 比較・画像・試読

同じ出来事を保って、全貌の提示時点、音の表し方、異変に気づく人物の範囲など一つの差を比べる。PNGでは掲載寸法で手掛かり、位置関係、変化の順番を確認する。画像を実際に見ず、黒量や表情の効果を断定しない。

試読では「何がおかしいと思ったか」「いつ気づいたか」を先に聞き、不明なだけだった箇所と怖かった箇所を分ける。驚愕、嫌悪、不穏は同じ反応として集計しない。[共通の監修手順](../routing.md) に従って採否と代償を残す。実作品PNGと読者による比較検証は未実施。
