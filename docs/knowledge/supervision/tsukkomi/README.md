# ツッコミ・異常への反応の監修

追加：2026-09-19。試行版。対象は、おかしな行動・発言への受け方を選ぶ字コンテ相談と画像レビュー。笑いが主でない場面でも、反応で人物や関係を伝える場合に使う。

作者・編集者の見解は [出典台帳](../sources.md)、笑いの前提やずれは [ギャグ](../gag/README.md)、人物・演技・情報順は [共通知識](../../review-workflow.md#common-knowledge) を参照する。以下のT01～T06は本キットの条件付き制作提案であり、笑いや好感度を保証する規則ではない。

## 最初に決めること

今回の主効果、反応する人の目的、二人の関係、読者に既に分かることを確認する。既存の台詞や演技から、語彙・長さ・反応の強さ・直接言うかを読み取る。大声、短文、毎回の訂正を標準にしない。

<a id="t01"></a>

## T01　誰の基準で何をおかしいとするか

- 見ること：作中の常識、本人のこだわり、読者の期待のどれから外れた行為か。反応する人物が、それを知り、気にする理由があるか。
- 使う条件：行動は見えるのに、誰がどこを問題にしているか分からない場面。
- 比較案：訂正する／困る／別の点を気にする。知識と利害の違いで選ぶ。
- 代償・例外：常識的な指摘にそろえると人物固有の偏りが消える。設定上は普通の行為を、作者都合で急に異常扱いしない。
- 根拠の範囲：[S01](../sources.md#s01)の人物の立場と、既存の人物・知識差の応用。反応の分類は制作提案。

<a id="t02"></a>

## T02　理解を助ける反応と、新しい意味を足す反応

- 見ること：絵・前の台詞で既に分かる事実と、ツッコミで初めて分かる評価・感情・たとえを分ける。
- 使う条件：同じ説明が続く、または反応を削ると何が起きたか分からなくなる場面。
- 比較案：同じ事実の言い直しを縮める／その人物ならではの評価を残す／対象や結果を絵で補う。
- 文字を減らす案では、代わりの手掛かりが掲載寸法で読めるかを確認する。画像がなければ未確認事項に残す。
- 代償・例外：長い言い回しや畳みかけ自体が見せ場なら残す。短さを目的に、理解に必要な訂正や人物の声を削らない。
- 根拠の範囲：[S02](../sources.md#s02)の台詞を選ぶ方針を参照。重複と演技の区別は制作提案。

<a id="t03"></a>

## T03　言う・黙る・受け流すを比べる

| 選択 | 向く条件の仮説 | 渡す手掛かり | 失う可能性のある効果 |
| --- | --- | --- | --- |
| 言葉で指摘 | 何がずれたかを絞る必要がある | 指摘対象と人物固有の言葉 | 読者が自分で気づく楽しみ |
| 無言の反応 | 対象が分かり、表情や動作で受け方が読める | 視線、止まる動作、次の選択 | 人物の言葉の魅力、意味の明確さ |
| 慣れた受け流し | 同じ奇行との付き合いが分かる | 先回りした対処、平常の作業 | 驚きの大きさ、初見の理解 |
| 便乗・増幅 | 次の人物にも欲求や偏りがある | 元のずれと新しいずれの関係 | 常識との比較点 |
| 読者に委ねる | 人物が反応しなくても異常を拾える | 前提と結果の見える差 | 読みの確実さ、人物間の掛け合い |

反応の不在だけでは「読者への委ね」が成立したとはしない。[S02](../sources.md#s02)は形式を選び直す参考であり、上の対応表を作者の発言として扱わない。

<a id="t04"></a>

## T04　人物の声と反応の順番を保つ

- 見ること：出来事のどこで気づき、何を守ろうとして発言するか。口調以外に、関心・知識・言い淀み・行動が人物を分けているか。
- 使う条件：全員の反応が同じ、急に別人のような強い訂正になる、複数人が同じ驚きを繰り返す場面。
- 比較案：語彙や反応先を本人の関心へ戻す／後から気づく／言葉の代わりに用件を続ける。普段との差を出すときは理由を残す。
- 代償・例外：反応を自然に整えると、意図した過剰さが失われることがある。順序や間のコマ数を固定しない。
- 根拠の範囲：[S04](../sources.md#s04)と共通の演技・情報順の応用。

<a id="t05"></a>

## T05　反応が人物と関係に与える印象を見る

- 見ること：行動のずれを指摘しているのか、相手全体を否定しているのか。言われた側の次の行動から、親しさ・反発・傷つきのどれを狙うか。
- 使う条件：仲のよい掛け合いのはずが、一方的な攻撃に読める疑いがある場面。
- 比較案：指摘対象を具体化する／言われた側が返せる展開にする／用件を手伝う行動を添える。
- 代償・例外：険悪さや毒のある笑いが主効果なら、柔らかくすることを目標にしない。関係が既知の読者と初見の読者で読みが違う可能性を残す。
- 根拠の範囲：[S01](../sources.md#s01)を参照した印象の仮説。好感度の測定ではない。

<a id="t06"></a>

## T06　他の感情を受け止める位置を選ぶ

- 見ること：告白、謝罪、喪失、危機の要点に返事をする前に、笑いで用件を打ち切っていないか。
- 使う条件：笑いを加えた結果、人物の願いや場面の決着が読めなくなる場面。
- 比較案：必要な返答を先に置く／緊張が残る小さな反応へ変える／笑いを省く。
- 代償・例外：照れ隠しや回避を描くなら、返事をしないこと自体が意味になる。その未解決を読み取れるか確認する。
- 根拠の範囲：[S03](../sources.md#s03)と既存の主効果・終幕の判断を参照。

## 返す指摘と確認

対象箇所／観察／読みの仮説／T番号／変更案／残る効果と失う効果を結び付ける。問題がなければ変更しない案を返す。根拠が弱い場合は、好みの違いとして複数案を並べる。

PNGでは指摘対象・反応の向き・台詞の読順を実画像で確かめる。字コンテだけなら視覚面は未確認。試読では「何がおかしいと思ったか」「二人をどんな関係と読んだか」を先に聞き、理解と面白さを別に扱う。[共通レビュー](../../review-workflow.md)へ戻す。
