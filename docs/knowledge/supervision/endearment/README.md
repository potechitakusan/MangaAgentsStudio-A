# 可愛げ・愛着の監修

状態：試行版。更新・資料確認：2026-09-19。その人物を気にかけたくなる所作や反応を扱う。[S04](../sources.md#s04)・[S23](../sources.md#s23)を踏まえた**制作提案**。容姿の可愛さ、作中人物の好意、読者の愛着を同一視しない。

恋心は [好意](../romance/README.md)、技能や覚悟の魅力は [格好よさ](../stature/README.md)。声・欲求・役割は [人物](../../manga/05-story-character.md)、小道具は [場面](../../manga/04-scene-dialogue-props.md)へ戻す。

<a id="e01"></a>

## E01　その人が気にするものを具体化する

- 見ること：好物、手順、こだわり、ささやかな目標など、行動が生まれる対象。
- 使う条件：見た目の装飾だけで人物への愛着を強めようとする場面。
- 比較案：小さな準備を見せる／大切に扱う物を選ぶ／目的を果たして喜ぶ。
- 代償・例外：可愛い趣味を後付けする必要はない。既存の人物が大切にするものから選ぶ。
- 根拠の範囲：S04の人物固有の反応と共通知識の欲求を組み合わせた提案。

<a id="e02"></a>

## E02　普段との差か、いつもの良さかを選ぶ

- 見ること：落ち着いた人物の動揺、厳しい人物の小さな喜び等が、既存の性格につながるか。
- 使う条件：ギャップを作るために直前だけ冷淡・無能な人物へ変えている場面。
- 比較案：普段との差を一つ見せる／いつもの律儀さを反復する／相手による反応の違いを見せる。
- 代償・例外：ギャップは必須ではない。一貫して穏やかな人物や、外見を楽しむ場面も成立する。
- 根拠の範囲：S04の反応差という方法を、既存人物の制約の中で使う提案。

<a id="e03"></a>

## E03　失敗そのものと、失敗後の応答を分ける

- 見ること：取り繕う、やり直す、助けを求めるなど、本人の選択が見えるか。
- 使う条件：可愛げを出すために失敗や困窮だけを増やしている場面。
- 比較案：小さく立て直す／照れながら頼む／真面目に続ける／成功して素直に喜ぶ。
- 代償・例外：技能を落としたり、周囲へ実害を与えた責任を消したりしない。困る姿が好まれるという一般則にはしない。
- 根拠の範囲：S04と人物の選択からの応用。失敗後の点検は本キットの提案。

<a id="e04"></a>

## E04　読者に見せる所作と、他者の評価を配分する

- 見ること：本人の行為が読めるか。「可愛い」という周囲の台詞に全て任せていないか。
- 使う条件：賞賛やアップを増やしても、人物らしさが伝わらない場面。
- 比較案：手元の工夫を見せる／小さな反応を拾う／見守る人物を一人だけ置く。
- 代償・例外：頭身・口調の幼児化や全員の好意を自動追加しない。カメラ目線や大きい顔も、場面に合う選択肢の一つ。
- 根拠の範囲：S23の注目点・所作とS04からの応用。

<a id="e05"></a>

## E05　愛着と、その人物への評価を両立させる

- 見ること：弱みや可愛げを見せた後も、能力、対立、責任が残っているか。
- 使う条件：敵の人間味を加えた途端に、他の人物が赦した扱いになる場面。
- 比較案：気にかけるが止める／好ましい一面だけ見せる／行動への批判を保つ。
- 代償・例外：全人物を好かせる必要はない。読者の好みも実際に確かめるまで断定しない。
- 根拠の範囲：S04と先行の格上感・怒りの監修を踏まえた提案。

## 比較・画像・試読

性格・技能・責任を保ち、失敗／立て直し、反応差／反復を比べる。PNGでは所作の見え方と反応の宛先を確認。試読では「どの行為がその人らしいか」「気にかけたくなった箇所はあるか」を聞く。実作品PNGと読者による比較検証は未実施。[共通手順](../routing.md)に従う。
