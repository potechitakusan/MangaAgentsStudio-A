# 爽快感・逆転・解放の監修

状態：試行版。更新・資料確認：2026-09-19。積み重なった制約や期待に対し、局面が変わる見せ場を扱う。[S21](../sources.md#s21)・[S22](../sources.md#s22)を踏まえた**制作提案**。爽快さを勝利・報復の量で測らない。

制約の提示は [危機](../urgency/README.md)、情報の読み替えは [種明かし](../revelation/README.md)、強者の印象は [格上感](../stature/README.md)。共通の決着・余韻は [物語](../../manga/05-story-character.md)へ戻す。

## P01　何から解放されるのかを決める

- 見ること：勝敗、行動の制限、言えない気持ち、待ち続けた用件のどれが変わるか。
- 使う条件：派手な成功はあるが、それまでの困難との結び付きが弱い場面。
- 比較案：できなかった一動作を可能にする／望んだ返答を得る／守るものだけ確保する。
- 代償・例外：敗北や撤退でも解放を描ける。全ての困難を解決する必要はない。
- 根拠の範囲：S21の出来事による意味の変化と、共通知識からの提案。

<a id="p02"></a>

## P02　局面が変わる理由を、既出の条件で支える

- 見ること：人物の工夫・選択・連携と結果がつながるか。相手の能力やルールが突然変わっていないか。
- 使う条件：逆転の瞬間だけ未知の能力や都合のよい救援が現れる場面。
- 比較案：既出の性質を使い直す／残していた手段を選ぶ／別の人物が自分の理由で応じる。
- 代償・例外：偶然の助けも作品の狙いなら残すが、人物自身の達成とは分ける。
- 根拠の範囲：S22の要所と人物の選択を、逆転の因果へ応用。

<a id="p03"></a>

## P03　積み重ねた言葉や動作に、変わった意味を載せる

- 見ること：以前の失敗、口癖、約束が、今回の行為を経て違って受け取れるか。
- 使う条件：決め台詞だけが強く、場面の出来事と結び付かない場合。
- 比較案：同じ言葉を別の相手へ返す／同じ作業を違う選択で終える／台詞なしで以前の約束を果たす。
- 代償・例外：回想や反復が増えると勢いが落ちる。新しい台詞も成立し、反復を必須にしない。
- 根拠の範囲：S21の言葉の反復と意味の変化からの応用。

<a id="p04"></a>

## P04　変化の瞬間と、結果を受け止める時間を配分する

- 見ること：逆転の行為、成否の証拠、周囲の対応を順に追えるか。
- 使う条件：大ゴマや絶叫はあるのに、何が変わったか読めない場面。
- 比較案：決定的な一手を大きくする／結果を先に見せる／小さな安堵を置く。
- 代償・例外：全員の賞賛を増やす必要はない。静かな達成、次の危機へ直結する構成も選べる。
- 根拠の範囲：S22と共通の行為・反応順を使った制作提案。

<a id="p05"></a>

## P05　得たものと代償を、それぞれ残す

- 見ること：結果で解けた問題と、損傷・喪失・責任など残るもの。
- 使う条件：爽快に終えるために、前の被害や他者の選択が消える場面。
- 比較案：勝利を喜びつつ次の責任を示す／用件を終えて休む／一人の救いだけ確かめる。
- 代償・例外：余韻のために全費用を説明する必要もない。敗者の屈辱や残酷さを自動的に増やさない。
- 根拠の範囲：S21と先行の喪失・格上感・共通知識からの提案。
