# 駆け引き・探り合いの監修

状態：試行版。更新・資料確認：2026-09-19。相手の出方を読み、言葉や行動を選ぶ**フィクションの場面**を扱う。[S22](../sources.md#s22)・[S17](../sources.md#s17)を踏まえた制作提案。現実の人物を操る方法や、ゲームの必勝法ではない。

意図せず認識がずれる場合は [すれ違い](../awkwardness/README.md)、明かす順序は [種明かし](../revelation/README.md)。本音と知識差は [人物](../../manga/05-story-character.md)、台詞の目的は [場面](../../manga/04-scene-dialogue-props.md)へ戻す。

<a id="d01"></a>

## D01　各人物が得たいものと、表に出す目的を分ける

- 見ること：何を確かめ、何を守り、相手に何をしてほしいか。表の提案と本音は同じか。
- 使う条件：含みのある台詞は多いが、成功・失敗の意味が読めない場面。
- 比較案：本音を読者だけに渡す／目的は公開して手段を伏せる／一つの反応だけ確かめる。
- 代償・例外：全員に秘密を作らない。利害が見えていても、譲れる範囲や選ぶ時点で駆け引きは成立する。
- 根拠の範囲：S22の人物自身の目的とS17の情報整理からの提案。

<a id="d02"></a>

## D02　知っていること・推測・はったりを区別する

- 見ること：その人物はどこで情報を得たか。確信の台詞が事実なのか、相手にそう思わせたいのか。
- 使う条件：作者だけが知る情報で登場人物が先回りする場面。
- 比較案：観察した手掛かりを置く／推測として賭ける／誤った読みから立て直す。
- 代償・例外：はったりを作中の確定事実にしない。一つの仕草を観察できても、その意味は推測であり、特別な設定なしに内心を確定しない。後で根拠を明かす場合も、入手できる機会は整合させる。
- 根拠の範囲：S17・S22と共通知識の情報差からの応用。

<a id="d03"></a>

## D03　一手ごとに、相手が変えた行動を追う

- 見ること：問いや提案に対し、相手が何を受け取り、どう判断して返したか。
- 使う条件：「全部計画通り」の説明だけで心理戦を成立させようとする場面。
- 比較案：譲歩を引き出す／相手が条件を足す／探りに気づいて応答を変える。
- 代償・例外：全てを解説すると緊張が減る。肝となる一手を追えるだけの証拠に絞る。
- 根拠の範囲：S22の選択肢と要所を、行為・反応の連鎖へ整理した提案。

<a id="d04"></a>

## D04　通じなかった時の余地を残す

- 見ること：相手が断る、誤解する、別の目的で動く可能性と、その結果。
- 使う条件：一人を賢く見せるために、全員が予定通りに動く場面。
- 比較案：第二案を使う／条件を下げる／撤退する／思いがけない協力を受ける。
- 代償・例外：最初から成功が決まった見せ場も選べるが、その場合は不確かな勝負と同じ緊張を約束しない。
- 根拠の範囲：S22の人物が自分の考えで動く制作観からの応用。

<a id="d05"></a>

## D05　駆け引きの後に変わった条件を示す

- 見ること：何を得て、何を明かし、どの約束や不信が残ったか。
- 使う条件：意外な種明かしの後、交渉や関係の結果が分からない場面。
- 比較案：合意した範囲を短く示す／秘密を一つ失う／相手が次は応じない理由を残す。
- 代償・例外：騙した側への賞賛を自動追加しない。読者への説明と相手への説明は別々に選べる。
- 根拠の範囲：S17の信用とS22の要所からの応用。

## 比較・画像・試読

各人物の知識・目的・権限・結果を保ち、一手の根拠と返答の見せ方を比べる。PNGでは誰がどの反応を観察できる位置にいるかを確認。試読では「誰が何を狙い、何を得たか」「どこから推測したか」を聞く。実作品PNGと読者による比較検証は未実施。[共通手順](../routing.md)に従う。
