# PSDで人間へ引き渡すための制作ルール

更新・公式資料確認日：2026-09-13。対象はCodexが漫画原稿を作成し、人間がCLIP STUDIO PAINTで仕上げる工程。

## 制作範囲と開始条件

漫画は**PNGプレビューで確認・修正してから、指示のあるPSDを作成する**。PSD作成に時間がかかるため、作成の指示がない段階ではいったん作らず、ユーザーに作るか聞く。「漫画を完成させて」という依頼だけではPSD作成の指示とみなさない。PSDを依頼された場合のCodexの完成範囲は、PSDファイルの作成・検証・引き渡しまでとする。原則、人間がCLIP STUDIO PAINTで仕上げてから外部公開する。CBZはユーザーが明示的に指定した場合だけ作る。PSDの完成やCBZの指定から外部公開の依頼を推定しない。

## PNG確認からPSD作成へ進む条件

作品の `OPTION.md` で採用した「作成する」は作成指示として扱う。「作成しない」「保留」が採用されている場合は、その状態を維持し、別の指示があるまで作成の質問を繰り返さない。開始後のファイル変更は [オプションの適用手順](project-options.md) で意図を確認してから採用する。

1. 対象ページのPNGプレビューを作成・点検し、ユーザーが確認できる形で提示する。PSDを先に作ってプレビューを得るのではなく、制作素材からPNGを書き出す。後でPSDにできるよう、分離して制作した絵・文字・フキダシなどの素材とセリフ原文は保持する。
2. ユーザーの修正を反映してPNGを再提示し、最新のプレビューについて修正がないことを確認する。返答がないことや時間の経過を「修正なし」とみなさない。
3. PSD作成の指示がなければ、確認済みのPNGと対象ページを示して「この内容でPSDを作成しますか」と聞き、回答までPSDを作らない。PNGへの「修正なし」だけをPSD作成指示とみなさない。既にPSD作成の指示がある場合は再確認せず、PNGの修正確認後に進める。
4. 修正がなく、PSD作成指示がある対象だけをPSDにして、以下の検証と引き渡しを行う。作成不要・保留という回答ならPNGと制作素材を保持し、その時点の依頼範囲と状態を記録する。

作品の `docs/production/PSD-HANDOFF.md` と進捗に、PNGのパス・版・対象ページ、修正確認の回答、PSD作成指示の有無と対象を残す。「PNG確認待ち」「PNG修正中」「PSD作成回答待ち」「PSD作成不要・保留」「PSD作成・検証中」「PSD引き渡し完了」を区別する。確認待ちは正規の待機段階であり、未依頼のPSDを自動作成して解消しない。PNGだけの依頼は、その対象の完了で終える。

## 制作中に保持し、PSD作成前に確認する仕様

作品の `docs/production/PSD-HANDOFF.md` に、対象ページ、仕上がり寸法、原稿全体の寸法、塗り足し、文字の安全範囲、解像度、色の扱い、ページ順、CLIP STUDIO PAINTの版、レイヤー方針を書く。未指定の数値は用途に合わせた仮設定と明示し、印刷先の正式仕様と扱わない。確認済みの仕様がある場合は再質問せず使う。

## 編集しやすい構成の初期案

| 内容 | レイヤー名の例 | 引き継ぐもの |
| --- | --- | --- |
| 文字 | セリフ仮配置、モノローグ仮配置 | ページ・コマ・話者別の確定文字原文。文字が画像なら明記 |
| フキダシと枠 | フキダシ、コマ枠 | 可能なら文字と分け、移動・差し替えをしやすくする |
| 絵 | コマ01絵、コマ02絵、背景 | 実際に分離して作れた単位。線画・人物・背景の分離は制作時に保持できた場合のみ |
| 効果 | 擬音、効果線、ベタ、トーン | 別に作成した素材は別層にする。統合済みならその範囲を記載 |
| 用紙と補助 | 用紙、下描き、ガイド | 下描き・ガイドは通常非表示。確認用画像へ混入させない |

ページごとに `output/psd/page-001.psd` のような順序を判別できる名前を使う。レイヤー名と説明は日本語にする。レイヤー構成は一律の必須枚数にせず、制作済み素材の分離状態を正直に引き継ぐ。統合画像をPSDに入れただけなら「統合絵1枚のPSD」と記し、各要素を独立編集できるとは言わない。修正しやすさが必要な箇所は制作時から別素材として持つ。

## 形式互換性で確認できたこと

CLIP STUDIO公式は、PSDへ文字レイヤーを保持して書き出す選択肢を説明している。一方、同じ資料はPSDをCLIP STUDIO PAINTで開いた際の文字の画像化や、保持されない文字効果も説明している。**PSDに文字層があることから、CLIP STUDIO PAINTで縦書き・ルビまで再編集できると判断しない。** [公式のPSD文字出力解説](https://tips.clip-studio.com/ja-jp/articles/6549)。適用範囲は同記事のPSD入出力仕様。使用する版と実ファイルで確認する。

したがって、確定セリフと話者・ページ・コマの対応を `docs/production/DIALOGUE.md` に保存し、文字は絵から分けた仮配置を基本候補とする。人間がCLIP STUDIO PAINTで文字を入れ直せるようにする。これは本プロジェクトの制作提案。元の絵に文字が焼き込まれている場合は、その箇所と差し替えの必要性を記す。

## Codex側の検証と完了判定

1. 対象の全ページのPSDが実在し、ページ順、ファイル名、寸法、解像度、色設定が記録した仕様と合っていることを確認する。拡張子だけの変更をPSD作成とみなさない。
2. PSD対応の読み取り手段で再度開き、レイヤー一覧、表示状態、透明度、合成結果を確認する。保存時の成功表示だけで終わらない。
3. 合成結果を画像として確認し、ユーザーが確認した最新のPNG、ネーム、セリフ原文に照合する。文字欠け、話者の違い、層の欠落、ガイドの混入、コマ順と前後接続を通読する。
4. 確認用画像、ファイル一覧、再編集可能な範囲、統合済みの箇所、人間に残す仕上げ作業、検証に使った手段と結果を記録する。
5. CLIP STUDIO PAINTで開いて確認できる環境なら実施する。確認できなければ「CLIP STUDIO PAINTでの実読込は未確認」と残す。PSD自体の構造・再読込・見た目の確認まで済んだ状態をCodex側の完了とし、実機での互換性を確認済みとは言わない。

PSD作成指示とPNGの修正確認がそろって着手した後に、PSDが作れない、再読込できない、依頼されたページが不足する場合は制作途中。利用できる作成手段を調べて作業を続け、生成できない条件が残るならその理由と途中成果を記録する。人間に残す通常の仕上げ、確認待ち・作成保留、依頼範囲の未作成を混同しない。
