# 用語辞書（レビュー時のみ参照）

更新: 2026-09-12。以下は制作指示の表記を揃えるための本プロジェクト内定義。一般用語の唯一の定義ではない。執筆時に参照を強制しない。

| 推奨表記 | このプロジェクトでの意味 | 区別するもの |
| --- | --- | --- |
| 字コンテ | コマごとの絵・セリフ・目的を文章で指定する設計 | あらすじ |
| ネーム | コマ割りと人物/文字の配置を含む漫画の設計 | 完成原稿 |
| コマ | ページ内の一つの画面単位 | 映画のショットと一対一ではない |
| ショット | カメラ位置・画角による見せ方 | 連続した動きを静止画へどう割るかは別途判断 |
| シーン | 時間・場所・劇的目的でまとまる単位 | ページ区切り |
| ビート | 感情や行動が一段階変化する単位 | 一定秒数 |
| 引き／ロングショット | 人物と周囲の空間関係を見せる画角 | 背景だけを描くコマ |
| 寄り／クローズアップ | 表情や身体の一部を大きく見せる画角 | 必ず顔を映すとは限らない |
| 無言コマ | セリフ・モノローグのないコマ | 擬音や環境音の有無は個別記載 |
| 間 | 読者が感情・時間・ためらいを感じ取る余地 | 空白の量だけでは決まらない |
| 視線誘導 | コマ/文字/人物の順に読者を導く配置 | 作中人物の視線方向そのもの |
| フキダシ | 発話や内語を収める形 | 絵に直接置く擬音 |
| ウニフラッシュ | 集中線状の輪郭を持つ表現 | 本作品での内語/衝撃など用途は設定する |
| モノローグ | 登場人物の内的な語り | 客観ナレーション |
| めくり | 次ページを開く動作で生まれる情報の開示 | 縦スクロールとは別設計 |
| 断ち切り | 仕上がりの端まで絵を置く | コマ枠から人物がはみ出す表現 |
| 外連味 | 誇張、構図、見得など演出的な華やかさ | 単なる作画ミス |
| 設定の一貫性 | 人物・世界の約束が意図なく変わらないこと | 感情や成長による意図的な変化 |
| キャラクターシート | 同一人物の外見と変化しない特徴の参照資料 | 表情を全部固定する指示 |
| seed | 生成に使う乱数の初期条件 | キャラクターIDや完全再現保証 |
| LoRA | 学習済みモデルへ追加する軽量な調整データ | あらゆるモデルに共通利用できるものではない |

画面設計上の根拠は `immersion-and-cinema.md`、文字の扱いは `japanese-manga-readability.md`、生成用語の出典は `ai-production.md` で確認する。新語は使用例・別名・混同例を一緒に追記する。作品固有語は `docs/story/TERMS.md` に定義し、キャラクターの口調による言い換えまで機械的に統一しない。
