# NovelAI V5のコマ素材生成で観察した知見

## 対象のモデルと入力

対象は `nai-diffusion-5-full`、23 steps、`k_euler_ancestral`、scale 5、1回1枚の通常t2i。参照画像・初期画像は使っていない。画風は `year 2025` と品質語 `masterpiece, best quality, highly detailed, anime style, very aesthetic` を固定したカラー日常漫画。根拠は [E4](production-evidence.md#e4)・[E5](production-evidence.md#e5)。整理日：2026-09-30。

要求の書き方・一括生成・照合の手順は [NovelAIでの制作手順](../novelai-composed-production.md)、接続・費用は [NovelAI API](../novelai-api.md) を正本にする。以下はV5 Fullのこの条件での症状・操作・限界であり、V4.5以前・Curated・画像入力へ確認済みの事実として移さない。

<a id="n1"></a>

## N1：名称が残っても関係を削ると行為が変わる

人物・物の名称が残っていても、手と物の接触、操作する手、袋の内側、左右の手の分担、互いを見る視線、背面からの視点、地面との距離を削ると、E4では3Seedとも対象の表現が弱まった。水筒は手で持たずに座面へ置かれ、しゃがむ語が残っても球は地面から離れた。

関係の語を削っても同点だった例では、人物別の座標・視点・否定文が同じ意味を支えていた。短くするときは本文・人物別本文・座標・否定文をまとめて読み、最後に残る一か所まで消さない。[要求プロンプトの組み立て](../novelai-composed-production.md#prompt-writing)の10番に対応する。

<a id="n2"></a>

## N2：寄ると楽器・手の破綻が目立つ

鍵盤の手元へ寄せた案では、黒鍵がほぼ一つおきに並ぶ、同じ人物の左右の手の大きさ・肌色が揺れる、といった不備が大きく見えた。四手の連弾を斜めの画角へ変えると、腕と手が5・6・5本へ増えた。一本の指で一つの鍵を押す、力を抜いた指は、片手化・真上・横寄りのどれでも3Seedで成立しなかった。

楽器・手の細部が主題でない場面は、引きの原版で二人の位置・共有する道具を見せる方が損失が少ない場合がある。運指・奏法が依頼の中心なら、このモデル・条件での未解決事項として扱い、別の方法を検討する。

<a id="n3"></a>

## N3：形状の説明を足しても目的の形にならない物がある

アップライトピアノの形を説明する語を増やすほど、細い箱や板状の楽器になる例があった。作品では、依頼の条件ではなかった楽器の形式をグランドへ変えた。これは制作設定の変更であり、アップライトを生成できたことにはならない。物の形式が依頼の中心なら、設定の変更で成功扱いにしない。

設定を変えたら、古い設定を排除する否定文（例：グランドを避ける語）が要求に残っていないかも確認する。E5では4コマの要求に古い否定文が残っていた。

<a id="n4"></a>

## N4：容器・道具の構造が別物へ変わる

弁当箱の仕切り・蓋・蝶番、球かごの格子の高さと色は、見せ方を変えると別の構造へ変わりやすかった。食べ進んだ、片付いた、という意図が読めても、前後のコマと同じ物か比べる。同じ物として読めない場合は、状態を見せるコマを減らすか原版を使う。

<a id="n5"></a>

## N5：品質語・画風の語の効果は分離していない

E4・E5は品質語と `year 2025` を固定しており、各語の効果や優劣は分からない。E4の前に同じ作品で行った探索（資料NAI-R03、各条件1枚）で `high complexity` の有無だけを変えた例では、髪・服の陰影が増えた一方、顔の傾き・手の位置・ボタンの数まで変わった。一般則ではなく、一貫性が必要なコマで試す前に比較する候補とする。公式に説明された専用タグと、自然言語として加えた語（`highly detailed`、`anime style` 等）も区別する。

## 次の検証

重要な少数例でのSeedの追加、別の人物・場面・画角への移植、2か所を同時に削る条件、品質語だけを変える比較、人間の独立した評価、前後のコマを読んだときの理解の評価は未実施。画像入力を使う方式の確認はNAI-VERIFY-01に残す。
