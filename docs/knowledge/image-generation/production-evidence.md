# コマ別画像生成の制作根拠

## 出典と適用範囲

既存Qwenスキルの `references/qwen-prompts.md` と `references/evidence.md` も照合し、入力例と検証範囲を本資料群へ統合した。後の整理で訂正された実入力を優先する。提供元への対応はキットの非公開作業記録に残す。

<a id="e1"></a>

## E1：水中動作の比較

- 条件：imagegenの場面見本1回とQwen18回。有効な条件比較9件、人物説明の修正前で除外した3件、追加編集6件。
- 記録上の観察：キャラ参照で外見が揃う一方、立ち姿・浅い水位・弱い表情も残った。不要な参照を外して完成画像を編集すると改善した箇所があるが、視点・背景が変わった例や前傾が残った例もある。
- 限界：見本と寸法・構図・被写体の大きさが異なる。モデル単体の優劣や成功率の比較ではない。場面見本生成は、この後に作品で採用したimagegenの用途制限とは分ける。

## E2：静かな会話のコマ別制作

- 条件：カラー4ページ16コマ。人物入りBlenderの50mm撮影→Qwen→個別切り抜き→指定のAnima LoRA→文字組版。Qwen21件、Anima4件。imagegenは初期キャラ・小物参照2回と完成前編集1回。
- 記録上の観察：人物の左右逆転、顔の断片の補完、参照の立ち姿・穏やかな表情、本をカメラへ見せる姿勢、二重リボンを修正。62～94%の切り抜きを個別採用した。
- 限界：左右修正では参照順・位置の文章・撮影の遮蔽を同時に変更した。参照順だけの効果ではない。失敗・撮り直し・編集を含む実制作件数を一般的成功率へ換算しない。

## E3：動作のある4ページへの評価

- 条件：E2と同じ人物によるカラー4ページ16コマ、最終1024×1536px。人物入り50mm撮影→Qwen→切り抜き・組版→ANIMA_LORA。Qwen初稿16件と修正3件の計19件、ANIMA_LORA4件。imagegenは初期参照1回と完成前編集1回で、新規の場面・コマ・ページ作画は0回。
- 変更：シナリオ、舞台、衣装、運動量、一部コマ配置、画角と動作の見せ方。足元・指先・目元・全身動作・物の軌道・結果をつなぎ、手だけの接触、物で顔を隠す応答、後ろ姿を選び、感情が必要な顔は残した。
- ユーザー評価：前作の画角と動作の単調さへの指摘に対し、新作全体に改善を認める肯定評価と記録依頼が1件あった。角度だけを変えた対照実験でも、個々の設定の評価でもない。修正なしの明言・PSD作成指示とは区別する。
- 記録上の観察：不要な人物、目元指定から顔全体への復帰、隠した顔の衣装色、向きの不一致を修正。背面参照の採用例がある。投球の顔・手はimagegenで完成前編集しており、Qwen単独の能力として数えない。
- 実入力の訂正：顔を隠すコマは計画に正面参照の候補があったが、保存入力は初稿が撮影画像1枚、修正版が完成画像1枚。正面キャラ参照は投入していない。人物不在の俯瞰コマは撮影入力のSHA-256が同じでも、人物説明の削除とseed変更を同時に行っており、文章だけの効果とは断定しない。

## E4：NovelAI V5で要求の表現を削った比較

- 資料：NAI-R06・NAI-R07（作品内のローカル資料で公開URLはない）。整理日・読み取り日：2026-09-30。キット側では提供された要約と集計JSONの件数を照合した。原画は再確認していない。
- 条件：`nai-diffusion-5-full`、23 steps、`k_euler_ancestral`、scale 5、1回1枚の通常t2i。参照画像・i2iは使っていない。カラー日常漫画40ページ182コマから、接触・操作・位置関係が複雑な50コマを選んだ。各コマで独立した削減A・Bと、未変更の対照Cを同じ3Seedで生成した（計450枚）。Seed・寸法・品質語・人物別の記述と座標・否定文を固定し、失敗したSeedを差し替えていない。A・Bを同時に削る条件は実施していない。
- 採点：コマごとに事前に決めた2観点を、0（不在・別状態）／1（一部・曖昧）／2（明確）で、条件名を匿名にして採点した。100の削減パターンの分類は、3Seedとも低下29、2Seedで低下11、1Seedのみ低下8、差を検出せず29、削減で改善4（すべて1Seedのみ）、対照不足19（15コマ。未変更の対照が明確に成功したSeedが2未満）。
- 記録上の観察：人物・物の名称が残っていても、目をこする、手のくぼみ・合掌、結ぶ・直す・留める操作、袋の中へ入れる、左右の手の分担、互いを見る、背面からの視点、地面との近さ、手で持つ関係を削ると、3Seedとも対象の表現が弱まった。削っても同点だった条件には、同じ意味を座標・視点・否定文が支えていた例がある。主採点の外で、空の靴をそろえる行為が3Seedとも靴を履いた状態へ変わった例もある。
- 限界：意図して選んだ複雑なコマで、無作為標本ではない。1条件3Seedで、1パターンに複数の節の変更を含む場合があり、一語の効果へ分解できない。100条件は50コマを共有する。採点はAIの単独目視で、設計者と評価者が同じ。人間の複数評価者の一致率、統計的有意差、読者評価はない。一枚絵では時間（演奏の直後など）を判定できない項目があった。

## E5：NovelAI V5で描きにくい動作の見せ方を置き換えた比較

- 資料：NAI-R09・NAI-R10（同上）。整理日・読み取り日：2026-09-30。件数は集計JSONと照合した。原画・比較版は再確認していない。
- 条件：E4と同じ作品・生成設定。全182コマの制作記録を照合し、反復した失敗、構図・状態の変更で救済したコマ、妥協、E4の対照不足を根拠に54コマを選んだ。置換案Aを54コマ、追加案Bを14コマで各3Seed生成し、元の要求Cを含む366枚を実見した（新規303枚、E4からのC再利用63枚）。同じ3Seedを対応させ、失敗したSeedを差し替えていない。
- 採点：「指定した見える状態」「元の意図」「前後との接続」を各0/1/2で採点した。68の置換条件のうち、3軸すべて2のSeedが3枚の条件が19、2枚が7、1枚が10、0枚が32。非盲検でAIが分担して目視した。CとA・Bは見せる目標が違うため、点差を効果量として扱わない。
- 記録上の観察：表情へ寄せる（両手で包んだマグと目を閉じた顔）、完了状態を描く（フックに掛かった持ち手、閉じた袋、膝へ戻した両手）、残す接点を一つにする（右手と鉛筆の先）、時点をずらす（球が腕から離れた直後）、前後のコマへ情報を分担する、が成立した例がある。一本指で一つの鍵を押す、拍の合図、力を抜いた指、四手の連弾は、A・Bとも3軸すべて2が0/3だった。弁当箱・かごは意図が読めても容器の構造が別物に変わった。対象のコマだけを置き換えると次のコマの手と矛盾した例があり、比較版では隣のコマの切り抜きも調整した。
- 採否：代表36コマを21ページへ組み込み、残り19ページは原版のままの40ページ比較版を作った。36コマには、1Seedだけ成立した案や、切り抜き・前後の調整を伴う条件付き採用（原画の3軸が2未満の6枚）を含む。18コマは原採用を維持した。3Seedで成立した新案より、原版の空間情報や流れを優先した例もある。
- 限界：画角・時点・複数の表現を同時に変えた実用比較で、単語の因果実験ではない。読者試験はなく、「漫画の質が下がらない」ことの実証ではない。元の要求に古い楽器設定の否定文が残っていた4コマは送信前にA側だけ修正しており、画角だけの比較ではない。

## 採用する判断と残る限界

共通化したのは [入力の役割分担・修正・切り抜き・記録の判断](../external-panel-i2i.md)。[モデル文書](qwen-image-2.1.md) の操作は、この構成での観察に基づく候補とする。他モデル、Qwenの別版、静かな場面で同じ改善が得られるかは未検証。顔を隠すことで必要な感情が失われる反例も考慮する。

E4・E5から共通化したのは、[要求プロンプトの組み立て](../novelai-composed-production.md#prompt-writing)での関係の点検と短縮の判断、[同じSeedの対で比べる方法](../novelai-composed-production.md#batch)、作画後の照合での「別の行為になっていないか」、[描きにくい動作の見せ方の置き換え](../manga/02-visual-direction.md#v15)。モデル版に固有の症状は [NovelAI V5](novelai-v5.md) に置く。どれも1作品・1モデル版・通常t2iでの観察に基づく制作提案で、V4.5以前・Curated・他モデル・i2i・参照画像入力へ確認済みの事実として移さない。

NovelAIは、V5 Fullの通常t2iについてE4・E5の制作記録がある。画像入力（初期画像・参照）を含む実サービスでの確認はNAI-VERIFY-01として未実施のまま残す。接続・費用の正本は [NovelAI API](../novelai-api.md)。本取り込みは契約照会・生成・Anlas消費の許可を含まない。

キャラ名・作品名・衣装設定・原画・Blenderシーン・個人の必須工程・認証情報・未整理ログは取り込まない。50mm、切り抜き率、生成・仕上げ設定は観察条件で、全作品の推奨値ではない。E4・E5の要求一式・画像・API応答・アカウント状態・画風候補の調査一覧も取り込んでいない。
