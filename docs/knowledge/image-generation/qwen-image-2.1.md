# Qwen-Image 2.1のコマ作画で観察した知見

## 対象のモデルと入力

対象は記録上のQwen-Image 2.1、ComfyUIの `TextEncodeQwenImage21` を使った構成。E3の主モデルは `qwen_image_2.1_int8_convrot.safetensors`。この名称だけで配布元・同一重み・互換性が確定するとはしない。使用時にモデルの識別情報、ノードの版、入出力仕様を確認する。[Qwen-Image-Edit-2511](../ai-production.md#4-qwen-image-edit-2511の扱い)とは別に扱い、2511の公式資料を2.1の根拠へ読み替えない。

共通の制作判断は [コマ別i2i](../external-panel-i2i.md) を参照する。以下はQwenの全版で再現確認した仕様ではなく、使った構成の症状・操作・限界である。

## Q1：画像番号と役割

`TextEncodeQwenImage21` の `images.image_1`、`images.image_2` 等に個別の画像入力を接続し、実入力順と `<image1>` 等の指定をそろえた。最初を構図、その後を必要なキャラ・物体の参照にした。単独人物のコマへ別人物の説明を残したE1の3件は比較から除外した。

`resolution=0` を用いた記録では最初の画像の比率を基準にし、ノード側の丸めがあるため実寸を取得後に確認した。別のQwenノードやAPIへそのまま移す指定ではない。最初をキャラ参照に変えると、役割と寸法の基準が入れ替わる可能性を確認する。[C2](../external-panel-i2i.md#c2)・[C6](../external-panel-i2i.md#c6)に対応する。

### 入力指示の組み立て例

以下は元スキルの例から作品固有情報を除き、日本語で組み立て直した未試行の文章例。画像番号・人数・外見の記述は実入力と対象コマへ合わせる。英語版と同じ効果を検証したものではない。

```text
見える人物は2人。画面左の人物Aが右の人物Bへ小物を返す。Bは驚いてAを見ている
<image1>から画角、人物位置、動作、部屋の配置、小物と手の接点を取る
簡略化された顔・手・衣装の形は自然に描き直し、切り抜き用の余白を残す
<image2>は左の人物A、<image3>は右の人物Bの顔・髪・衣装を参照する
キャラ参照の立ち姿、表情、背景はコピーしない
<image4>は小物の形・配色・材質を参照し、大きさ・向き・接触は<image1>に合わせる
カラー漫画として描く。別組版のため、文字・吹き出し・枠・参照一覧を加えない
```

これは役割を伝える文章で、完全な制御の保証ではない。枠・文字を分ける指示も、この制作方式を採用した場合に限る。

## Q2：複数人物の左右の混同

E2では人物の左右が逆転した。参照を画面の左→右へ並べ、担当位置を明記し、遮蔽物を除いた撮影へ変更した結果で改善した。左右が混ざるときはこの3点を点検する候補にする。複数条件を変えており、「順番だけで必ず直る」とはしない。[C1](../external-panel-i2i.md#c1)・[C2](../external-panel-i2i.md#c2)・[C4](../external-panel-i2i.md#c4)に対応する。

## Q3：不要な顔・人物の補完

E2の小物アップでは、撮影に顔の断片があると人数0の文章でも顔を描き足す例があり、撮影調整と最終切り抜きで除いた。E3の人物不在の俯瞰では、共通の衣装・人体の説明を外した再生成を採用したが、seedも変わっており文章だけの効果ではない。

物だけのコマでは人物説明、キャラ参照、構図画像に人物が残っていないかを別々に確認する。「人数0」だけで抑えられるとは考えない。[C1～C4](../external-panel-i2i.md#c1)に対応する。

## Q4：キャラ参照の姿勢・表情まで引き継ぐ

E1では外見が揃いやすい一方、立ち姿・浅い水位・穏やかな表情が残った。上半身参照でも残ったため、参照範囲を狭めれば解決するとは言えない。

外見が揃った完成画像だけを次の入力にし、不要なキャラ参照を外して短い動作・表情指示を出す編集で改善した例がある。E2では本を見せる姿勢から読書姿勢へ直せた。一方、E1では視点・背景も変わった例や、前傾が残った例がある。外見の再指定が必要か、動作だけを直す段階かを分け、構図も保てたかを見る。[C2](../external-panel-i2i.md#c2)・[C4](../external-panel-i2i.md#c4)に対応する。

## Q5：背面・隠した顔・細部アップ

E3には背面参照で髪型・配色・背中の向きを保った採用例がある。物で顔を隠すコマでは正面キャラ参照を投入せず、衣装を文章で指定した。衣装が白へ寄った結果は完成画像だけの編集で修正し、目・鼻・口が隠れていることを確認した記録がある。正面参照の有無を単独比較した試験ではない。

目元だけの指定が顔全体へ戻ったコマは、原画の切り抜き幅40%で口・肩を外した。全身動作は96%、物の結果を見せるコマは94%の幅を残し、動作の端を守った。数値は当該画像の採用範囲。顔の可視性や注目部位に合う参照を選び、必要な画素数を残して切り抜く。[C1](../external-panel-i2i.md#c1)・[C3](../external-panel-i2i.md#c3)・[C5](../external-panel-i2i.md#c5)に対応する。

## Q6：Blenderの粗い形・質感が残る

E2では輪郭と配置の保持だけを求めると3Dの質感が残る例があった。位置・動作・部屋の配置は撮影から取り、顔・手・衣装・背景の表面は描き直す、と分けた指定で背景の手描き表現が改善した記録がある。保持したい空間関係と描き直す形・表面を区別し、全輪郭の保持と自然な再作画を同時に強く要求しない。[C2](../external-panel-i2i.md#c2)・[C4](../external-panel-i2i.md#c4)に対応する。

## Q7：修正範囲を具体的にする

E2の二重リボンは完成画像だけに、上端を残して下端だけ除去する短い指示で改善した。E1の水位では、水面を保って人物を肩まで沈める等、固定対象と変更対象を分ける案を試した。

局所編集の文章例は「`<image1>`の手元の重複部分だけを除く。上端、手の接触、画角、背景、衣装、他の人物は保つ」。この例自体は未試行。採用時は画角・背景・物の位置・別人物も見比べ、描写の改善と連続性の維持を分ける。[C4](../external-panel-i2i.md#c4)・[C5](../external-panel-i2i.md#c5)に対応する。

## 設定の記録と次の検証

E3は25 steps、CFG 1.0、euler / simple、denoise 1.0。推奨値の比較検証ではなく、初期画像を変形するi2iと、この構成の参照入力の効き方を同一視しない。ANIMA_LORAの12 steps・CFG 2.5・euler_ancestral / simple・denoise 0.12は別の仕上げ工程であり、Qwen自体の性質には含めない。

次は同一コマ・基本条件で参照順のみ、参照の有無のみ等を変えて比較し、別モデル・版でも確認する。現在の記録から一般成功率やモデル間の優劣は求めない。モデルを増やす際は固有知見の文書を追加し、共通工程・接続と料金の正本を複製しない。
