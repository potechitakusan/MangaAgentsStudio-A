# 印刷を選んだ場合のオプション

**既定は「使用しない」**。インターネット公開用PNGの制作では、このファイルへの記入や印刷設定への回答は不要。印刷も行うと指定した場合だけ読む。会話で明示された指定を優先し、制作開始後の変更は [設定の適用手順](docs/knowledge/project-options.md) に沿って扱う。

| 項目 | 現在の設定 | 選択・確認内容 |
| --- | --- | --- |
| 印刷用出力 | 使用しない | 「使用する」で以下を検討。ファイルの存在だけで有効にしない |
| 入稿先・商品 | 未指定 | 印刷所、判型、綴じ方、本文・表紙の区別 |
| 正式仕様の出典・確認日 | 未確認 | 入稿先の最新の公式URLと確認日 |
| 仕上がり寸法 | 未指定 | 単位を明記。Webのpxをそのまま用紙規格にしない |
| 塗り足し・原稿全体の寸法 | 未指定 | 入稿先の指定に従う |
| トンボ | 未指定 | 要否と位置を入稿先に合わせる |
| 基本枠・ノド・小口 | 未指定 | 綴じ側、左右ページ、必要な余白を確認 |
| 解像度・必要画素数 | 未指定 | 原寸・入稿先指定のdpi・元の絵の精細さを照合 |
| 色・プロファイル・階調 | 未指定 | RGB／CMYK／グレー／二値等を入稿先の指定で決める |
| 提出形式・ページ順 | 未指定 | 拡張子、表紙・本文の分け方、見開き・単ページの扱い |
| 印刷用データの確認 | 未実施 | 欠け、塗り足し、色、必要なら実寸校正の結果 |

有効化した場合だけ不足仕様を確認する。回答待ちでも独立して進められるWeb用の企画・字コンテは続ける。Web用の原本・PNGを保持し、印刷用は別の出力先と仕様で用意する。dpi情報の変更や単なる拡大だけを印刷品質の確保と扱わない。

基本枠は配置の基準、仕上がり枠は裁断の位置を表す。Web用の基本枠・文字安全範囲を、裁断や綴じで欠けない保証に置き換えない。PSDを依頼された場合は、PNGの修正確認後に作成・再読込を行う既存の条件を維持し、印刷設定を選んだだけでPSD作成や印刷所への送信まで指示されたとみなさない。
