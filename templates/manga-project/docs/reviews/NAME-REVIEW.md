# ネーム点検表・修正記録

画像がない場合は文章上の予備点検と記録する。人間の試読とエージェントの点検を区別する。

作品／版：　　　　　確認者：　　　　　日付：

## 物語と場面

- [ ] 誰が何を欲しがり、何が妨げるかが伝わる。
- [ ] 選択に必要な情報と動機を、前もって渡している。
- [ ] 場面の前後で関係・情報・期待が変わる。余韻の場面には意図がある。
- [ ] 同じ戦術を言い換えるだけの台詞やコマが続いていない。
- [ ] 重要な決断の途中を省いて、人物が急変していない。

## 視覚と読順

- [ ] ページ別の採用ID、または独自配置の演出意図・不使用の理由が記録され、ユーザーの必須・不使用指定に従っている。
- [ ] imagegenでページ作画を生成した場合、番号付きレイアウト画像と各コマの内容を実際に渡し、生成後のコマ数・配置・読み順・内容を計画と照合した。未生成ならこの項目は未確認とする。
- [ ] 各コマで最初に見せたい対象がわかる。
- [ ] 誰の視点から何を見ているかが追える。
- [ ] 顔、手、背中、小物、空景の選択に理由がある。
- [ ] 人物の左右・向き・視線・持ち物・出入口がつながる。
- [ ] 場所・時間を切り替えたことがわかる。
- [ ] 回想・省略・同時進行がある場合、提示順と出来事の前後、語る時点と描く時点、戻り先を追える。意図的に伏せる場合は理解できる位置がある。
- [ ] 同じ画角や顔の連続に狙いがある。不足する空間・時間・状態の情報を確認し、背景を入れる案と比較した。
- [ ] 乗降や出入りがある場合、開始位置→動作→到達位置が絵でつながる。
- [ ] １コマの主動作が読み取れ、複数の動作を同時に置いた場合はその関係に理由がある。
- [ ] 接点のある動作は接触前・接触中・接触後の段階と、誰のどの手が何に触れるかが前後のコマでつながる。
- [ ] フキダシの話者と順序を取り違えない。
- [ ] 必要な文字・小道具の細部が掲載サイズで読める。
- [ ] セリフは原則上詰めで、縦書きの各列の書き出しがそろい、吹き出し内側の余白もある。例外は対象と理由を文字設定へ記録した。
- [ ] 作品の基本枠・文字設定に照らして確認し、掲載PNGに補助線・コマ番号が混入していない。

## 間と緩急

- [ ] 刺激の後に、必要な認識・反応・選択がある。
- [ ] 沈黙のコマに、誰の何を待つ時間かという目的がある。
- [ ] 溜めている間に期待・危険・理解のいずれかが変化する。
- [ ] 核心の台詞や絵が、意図より先に見えていない。
- [ ] 強い場面の前後に必要な対比・呼吸がある。
- [ ] ページめくりの効果を、実際の見開きで確かめた。
- [ ] コマ数だけで読了時間を判断していない。

## 言葉・反復・結末

- [ ] セリフ・ナレーションの原文と配置に「。」がない。
- [ ] 「、」は、つながった吹き出し・ナレーション枠を１個として数えた本文が20文字以上で、長文を読みやすく区切るために必要な箇所だけにある。数え方は [句読点の方針](../knowledge/japanese-manga-readability.md#dialogue-typesetting)に従った。
- [ ] 台詞が絵と同じことを不必要に説明していない。
- [ ] 言葉と身体の一致／食い違いが人物の意図に合う。
- [ ] 同じ言葉・小道具・構図の再登場で意味が更新される。
- [ ] フリがオチを支え、オチの後に説明を重ねすぎていない。
- [ ] 終わりに必要な受け止め・余韻がある。
- [ ] 連載では今回の報酬と次回の問いがわかる。

## 場面の監修（必要なテーマのみ）

- [ ] [監修の一覧](../knowledge/supervision/routing.md)から、狙いに合うテーマと項目を選んだ。
- [ ] 字コンテの監修案と、実際のプレビューで伝わる効果を照合した。
- [ ] 中心効果と併用要素が両立し、保ちたい感情や人物像を打ち消していない。
- [ ] 確認事実・制作提案、画像を実際に確認した範囲、未確認事項を区別した。

改善案とメインによる採否は [監修記録](SUPERVISION.md) にまとめる。対象となる要素がなければ対象外とする。汎用の点検は [共通レビュー](../knowledge/review-workflow.md) を参照する。

## 修正記録

| 日付・版 | 箇所 | 問題の症状 | 根本原因の仮説 | 変更と採用理由 | 再確認の結果 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

構造→人物の動機→情報順→画面→間→文字の順に確認する。ただし、明確な局所の誤りはその場で直す。すべての項目を同じ強さの規則にせず、作品の意図に照らして判断する。

局所的な作画ミスは上の修正記録だけに残す。再利用する条件があるときだけこの表を使い、次ページで条件が合わなければ適用しない。文字設定の実値は [DIALOGUE.md](../production/DIALOGUE.md) に集約する。作品からキットへのフィードバックは記録依頼時のみ。
