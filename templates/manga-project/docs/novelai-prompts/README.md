# NovelAIのキャラクター・絵柄・背景を編集して再生成する

このREADMEは、**NovelAI用のプロンプトが組み立て済み、または漫画のPNGプレビューが完成している作品**で、人間が見た目を変更するための手順です。既存の作品フォルダで作業します。キャラクター・絵柄・背景を、作品フォルダの `.env` という設定ファイルで編集できます。NovelAI以外の画像生成には使いません。

この手順では、**Codexが編集環境を準備し、人間が本文を編集してコマンドを実行し、画像を選びます。** 人間がコマンド実行をCodexへ任せる場合は、各段階でその作業を依頼してください。準備依頼だけで画像生成や有料利用を許可したことにはなりません。

| 作業 | 通常の担当 |
| --- | --- |
| 既存プロンプトの変数化、要求JSONへの参照設定、編集用テキストの作成 | Codex |
| 変更する外見・絵柄・背景を決め、本文を編集する | 人間 |
| 特徴一覧の更新、展開後の要求と警告の内容確認 | 人間がCodexへ依頼する |
| 反映・送信なし確認・生成・採用・buildのコマンド実行 | 人間。各段階をCodexへ依頼することも可能 |
| 費用・利用枠の確認、生成の実行判断、画像の選択、PNGの修正確認 | 人間。Codexは確認と判断を支援する |

順番は **Codexによる準備 → 人間による本文編集・反映 → Codexによる内容点検 → 送信なし確認 → 生成 → 画像の採用 → ページの組み直し** です。設定の編集だけでは、既に作った画像は変わりません。

PNG完成後は、既存の要求・採用画像・ページ構成を使って再生成・組み直しを行います。画像生成前の場合は、編集後に初回生成と全コマの採用を行います。ページ構成・文字配置・組版環境が未準備なら、Codexがbuild前に用意します。

以下の変数名・ファイル名は説明用です。人間は、準備後にCodexから案内された自分の作品のファイル名とコマンドを使ってください。

## 1. 最初の準備はCodexに依頼する

人間は既存の作品フォルダでCodexを開き、次のように依頼してください。準備済みの場合、人間は編集ファイルとコマンドの場所をCodexへ確認してから手順3へ進みます。

> この作品はNovelAI用のプロンプト組み立てまで、またはPNGプレビューまでできています。既存のプロンプトを使って、キャラクター・絵柄・背景を.envから自分で編集できるようにしてください。変数名・現在の本文・影響するコマを私に示し、確認後に要求JSONへの参照設定と編集用UTF-8テキストの作成をお願いします。既存の画像・採用記録・ページ構成は保持してください。私が編集するファイルと実行するコマンドをdocs/production/NOVELAI-BATCH.mdに残し、案内してください。今回は画像を生成せず、準備だけしてください。

Codexは依頼された作品でだけ、既存の画風・キャラクター設定に合わせて準備します。Codexは変数名と本文を人間へ示し、人間の確認後に `.env`、編集用テキスト、要求JSONの参照を設定します。人間が以下の例をそのまま作品の採用設定にする必要はありません。

既存作品には更新が自動配布されません。古いスクリプトが絵柄・背景の変数に対応していない場合は、作品側の変更を保持して更新するようCodexへ依頼してください。

## 2. 何を変更できるか

「プロンプト」は、生成する絵を説明する文章です。「変数」は、その文章に付ける名前です。変数名は半角英大文字・数字・アンダースコアを使います。

| 用途 | 変数名の例 | 変更する内容 |
| --- | --- | --- |
| キャラクター | `NOVELAI_CHAR_MIO` | ミオの髪型、服、識別に必要な外見 |
| 絵柄 | `NOVELAI_STYLE_MAIN` | 線、色、塗りなどの画風 |
| 背景 | `NOVELAI_BACKGROUND_CLASSROOM` | 教室の机、窓、光など |

**要求JSONの設定はCodexの担当です。** Codexは絵柄と背景を場面共通の文章（Base）、キャラクターを対応する人物別の文章（Character）へ入れます。人物別入力を使わない要求では、Codexが本文へまとめます。Codexはポーズ・表情・動作をコマごとの要求に残し、外見だけを変更しやすい形にします。

Codexは背景の変数を場所ごとに分けます。人間が教室の変数を変更すると、教室の変数を使う要求だけが変わります。変数を参照していない要求は変わりません。

例えば、**Codexが**要求JSONに次のような参照を用意します。これは仕組みを説明する本文の抜粋です。人間がJSONへコピーする必要はありません。`v4_prompt` を使う場合、Codexは同じBaseを `input` と `caption.base_caption` に設定します。

```text
Base: 1girl, standing, ${NOVELAI_BACKGROUND_CLASSROOM}, ${NOVELAI_STYLE_MAIN}
Character: ${NOVELAI_CHAR_MIO}, smiling, on the left
```

## 3. 人間がコマンドの実行場所を確認する

人間はコマンドを **作品フォルダを作業場所にした端末** で実行します。Windowsでは、人間がエクスプローラーで作品フォルダを開き、アドレス欄に `powershell` と入力してEnterを押す方法があります。人間が各段階のコマンド実行をCodexへ任せる場合、この端末操作は不要です。

人間は以下を１行ずつコピーしてEnterを押してください。コード枠の囲み記号はコピーしません。後のコマンド例にある数字の `1` は「１ページ目」です。人間は自分の作品の対象ページに合わせて変えます。

```powershell
Get-Location
Test-Path project.json
Test-Path scripts/novelai_batch.py
```

人間は１つ目の表示が作品フォルダで、後の２つがどちらも `True` であることを確認します。`False` の場合、人間は作品フォルダで端末を開き直してください。Pythonが見つからない場合、人間は表示されたエラーをCodexへ伝えてください。

人間は方法Bの反映コマンドも、この端末で実行します。

## 4. 人間が編集方法を一つ選び、本文を変更する

### 方法A：.envを直接編集する

人間はCodexが設定した作品フォルダの `.env` をテキストエディターで開きます。ファイルが見つからない場合、人間はCodexに作成状況を確認してください。`.env.example` は見本で、人間が編集しても設定に反映されません。

変更前の例：

```dotenv
NOVELAI_CHAR_MIO="girl, short black hair, blue jacket"
NOVELAI_STYLE_MAIN="clean lineart, soft colors, anime style"
NOVELAI_BACKGROUND_CLASSROOM="classroom, desks, windows, daylight"
```

変更後の例：

```dotenv
NOVELAI_CHAR_MIO="girl, black twintails, blue jacket"
NOVELAI_STYLE_MAIN="bold lineart, vivid colors, cel shading"
NOVELAI_BACKGROUND_CLASSROOM="classroom, desks, windows, warm sunset light"
```

この例では、人間が髪型をツインテールに、画風を太い線と鮮やかな色に、教室の光を夕方に変えています。人間は `=` の左側の名前を変えず、右側の引用符の中だけを編集し、UTF-8で保存します。人間は各設定を１行に書き、APIキー等の別の設定は変更しません。この方法では反映コマンドは不要です。

### 方法B：テキストを編集して.envへ反映する

`.env` を直接触りたくない場合、人間は手順1で**Codexが作成したテキスト**を編集します。例えば人間は `input/novelai/prompts/mio.txt` に、次の本文だけを書きます。変数名・`=`・外側の引用符は不要です。

```text
girl, black twintails, blue jacket
```

人間は変更したい他のファイルも同じように編集します。

| テキストファイルの例 | 本文の例 |
| --- | --- |
| `input/novelai/prompts/style-main.txt` | `bold lineart, vivid colors, cel shading` |
| `input/novelai/prompts/background-classroom.txt` | `classroom, desks, windows, warm sunset light` |

人間は本文を１行にし、UTF-8で保存してください。コマンドを初めて使う場合、人間は手順3で端末を開きます。その後、人間が次のコマンドを１行ずつ実行すると、スクリプトが `.env` に反映します。人間は変更したファイルのコマンドだけ実行しても構いません。

```powershell
python -X utf8 scripts/novelai_batch.py env-set NOVELAI_CHAR_MIO --value-file input/novelai/prompts/mio.txt
python -X utf8 scripts/novelai_batch.py env-set NOVELAI_STYLE_MAIN --value-file input/novelai/prompts/style-main.txt
python -X utf8 scripts/novelai_batch.py env-set NOVELAI_BACKGROUND_CLASSROOM --value-file input/novelai/prompts/background-classroom.txt
```

人間は「更新しました」または「追加しました」の表示を確認します。スクリプトは該当する設定を更新し、画像は生成しません。スクリプトは他の設定値を保持しますが、`.env` の改行・文字コードは保存時に整えます。

**テキストは自動同期されません。** 人間はテキストを編集するたびに反映コマンドを実行してください。方法Aの後に方法Bを実行すると、スクリプトはテキストの内容で `.env` の値を置き換えます。

人間が反映をCodexへ任せる場合の依頼例：

> 編集用テキストを保存しました。変更したファイルを確認し、env-setで.envに反映してください。画像は生成しないでください。

### 日本語で書く場合

人間は右側の本文や編集用テキストに日本語も書けます。例えば次の１行です。

```text
女の子、黒髪のツインテール、青いジャケット
```

スクリプトは文章を翻訳せず、そのまま要求へ入れます。人間とCodexは生成画像で狙った外見になったかを確認します。英語から日本語へ変えた場合も、人間は手順5で特徴一覧の更新をCodexへ依頼してください。

## 5. 人間がCodexへ内容点検を依頼し、送信なしで確認する

まず人間は、変更した項目をCodexへ伝え、展開後の要求の点検を依頼してください。**特徴一覧と要求JSONの調整はCodexの担当です。**

> ミオの髪型をショートヘアから黒髪のツインテールに変更しました。絵柄と教室の光も変更しました。.envに合わせてcharacters.jsonの特徴一覧と各コマで見える特徴の指定を更新し、展開後の要求を点検してください。人物別入力への割り当てと場面のつながりも確認してください。今回は画像を生成しないでください。

Codexの点検後、人間は次のコマンドで登録済みの変数名を確認します。スクリプトは通常、本文を表示しません。

```powershell
python -X utf8 scripts/novelai_batch.py vars
```

人間がプロンプト本文も読みたい場合、次のコマンドを実行します。スクリプトはAPIキーを表示対象にしません。

```powershell
python -X utf8 scripts/novelai_batch.py vars --show-values
```

続いて人間は１ページ目の要求を、送信せず確認します。

```powershell
python -X utf8 scripts/novelai_batch.py generate --page 1
```

スクリプトは寸法・Seed・使用変数・警告を表示し、最後に「送信なし」と表示します。人間は警告やエラーが出たら、その内容をCodexへ伝えて修正を依頼してください。この表示は設定の準備確認で、画像生成や内容の正しさの保証ではありません。

人間がコマンド実行もCodexへ任せる場合の依頼例：

> varsとgenerate --page 1による送信なし確認を行い、設定と警告を確認してください。必要な修正に対応し、画像生成は行わないでください。

### キャラクターの特徴を変えたとき

例えば人間がショートヘアからツインテールへ変えたら、Codexが `input/novelai/characters.json` のミオの `features` にある髪の特徴を、新しいプロンプトと同じ語へ変更します。Codexは髪が見えない手元のコマでは `cast` の対象を調整します。人間がJSONを手作業で編集する必要はありません。

スクリプトは登録した特徴の文字列が要求文に含まれるかを調べます。スクリプトは言い換えの意味、どの人物に特徴が付くか、生成画像に実際にツインテールが描かれたかを判定しません。人間とCodexは生成後に画像を別途確認します。特徴一覧がなければスクリプトは特徴チェックを行いません。絵柄・背景用の同等の特徴一覧チェックはありません。

Codexは警告の内容を確認し、原則としてプロンプトを直します。人間とCodexが意図して残すと判断した場合、Codexが `docs/production/NOVELAI-BATCH.md` に理由を記録します。その後、人間または実行担当のCodexが生成コマンドへ `--accept-warnings` を追加できます。費用の確認やエラーを省略する引数ではありません。

## 6. 人間が費用・利用枠を確認し、生成を実行する

人間は今回の画風・モデル・全設定の費用を確認します。Codexが確認を支援した場合も、人間は結果と未確認事項を確認してから実行を判断してください。Opusでも、契約があるだけでは今回の0 Anlasを確認したことになりません。人間はV5の利用枠も確認します。詳細は [接続・費用の手順](../knowledge/novelai-api.md#確認後に生成する)。確認できなければ人間もCodexも送信しません。

**今回の全設定が0 Anlasで、V5の利用枠も確認済みの場合だけ**、人間は次のV5用のコマンドを実行します。人間は `--cost-note` の本文を実際の確認方法と日時へ書き換えてください。V4／V4.5の場合、人間は `--confirm-v5-allowance` を外します。

```powershell
python -X utf8 scripts/novelai_batch.py generate --page 1 --execute --confirm-zero-anlas --confirm-v5-allowance --cost-note '今回の全設定の費用と利用枠を確認した方法・日時を記入'
```

`--execute` は実際に生成を送信する指定です。スクリプトは１ページの各コマを１枚ずつ生成し、以前の画像を上書きせず候補を追加します。画像生成前の作品では初回生成、プレビュー完成後の作品では再生成になります。失敗した場合、スクリプトは自動再送しません。人間は結果と消費を確認し、必要ならCodexへ状況の整理を依頼します。

人間が生成をCodexへ任せる場合の依頼例：

> 変更後の１ページ目をNovelAIで生成してください。今回の全設定で0 Anlasを確認でき、V5なら利用枠も足りる場合だけ実行してください。確認できなければ送信せず教えてください。有料利用と失敗時の自動再送は許可しません。

普段の再生成はSeed（生成のばらつきを決める数値）が変わる場合があります。プロンプト変更だけを比べたい場合、人間は生成前にCodexへ同じSeedでの比較を依頼してください。Codexが変更前・変更後の要求の `parameters.seed` を同じにし、`--seed request` 付きのコマンドを用意します。Seedが同じでもキャラや構図の一致は保証されません。

## 7. 人間が画像を確認し、新しい候補を採用する

人間は次のコマンドで候補と採用状況を確認します。

```powershell
python -X utf8 scripts/novelai_batch.py list --page 1
```

候補は例えば `output/novelai/candidates/p01-02/r003.png` にあります。人間は画像を開き、外見・背景・動作・人物の位置を確認して使う候補を選びます。`p01-02` は１ページ目の２コマ目、`r003.png` は候補番号３です。人間は選んだ候補の採用コマンドを実行します。

```powershell
python -X utf8 scripts/novelai_batch.py adopt p01-02 --candidate 3
```

人間は要求IDと候補番号を実在するものへ書き換え、変更した各コマを採用します。初回生成の場合、人間はページ内の全コマを採用します。再生成だけでは採用画像は切り替わらないため、ここを飛ばすと古い画像でページが組み直される場合があります。

人間が採用の記録をCodexへ任せる場合の依頼例：

> 画像を確認しました。p01-02は候補３を使います。adoptで採用を記録してください。

Codexは人間が指定した候補を採用記録へ反映します。人間が画像レビューも依頼した場合、Codexは画像を実際に開いて確認し、採用案を説明します。

## 8. 人間がページPNGを組み直し、完成ページを確認する

プレビュー完成済みの作品では、人間が既存のページ構成を使って次のbuildコマンドを実行します。画像生成前から始めた作品でページ構成・文字配置・組版環境が未準備なら、人間は先にCodexへ準備を依頼します。Codexは作画後の照合を行い、必要な構成を用意します。準備後、人間が次を実行します。

```powershell
python -X utf8 scripts/novelai_batch.py build --page 1
```

スクリプトは結果を `output/build/page-01/v001/` のように版ごとのフォルダへ保存します。人間は実行結果に出た保存先のページPNGを開き、切り抜き後の見え方・文字・読み順を確認してください。buildはNovelAIへ生成を送信しません。

人間がbuildと点検をCodexへ任せる場合の依頼例：

> 採用した画像で１ページ目のPNGを組み直し、完成ページを点検して提示してください。ページ構成や文字配置が未準備なら先に整えてください。今回はPSDは作らないでください。

修正がある場合、人間はCodexへ修正箇所を伝えます。Codexは修正したPNGを再提示し、人間が最新のPNGを確認します。

### 人間がPSDも作りたい場合

人間が自分で調整用PSDを作る場合、次のコマンドを実行します。

```powershell
python -X utf8 scripts/novelai_batch.py build --page 1 --write-psd
```

人間がこのコマンドを使って作ったPSDは、ペイントソフトで調整するための原稿です。人間がCodexへPSDの作成・引き渡しを依頼する場合、最新PNGの修正確認を済ませてから「このPNGは修正なしです。PSDも作成・検証して引き渡してください」と伝えます。既にPSD作成を指示している場合、CodexはPNGの修正確認後に作成・検証へ進みます。

## 人間が困ったときの確認先

| 表示・状況 | 人間が確認・依頼すること |
| --- | --- |
| 使えない変数名 | 人間が表示をCodexへ伝える。Codexが許可された３種類の変数名とスクリプトの版を確認する |
| 変数がありません | 人間がテキストの反映を済ませたか確認する。参照設定に問題があればCodexへ依頼する |
| 同じ変数が複数の場所にあります | 人間がCodexへ重複の整理を依頼する。Codexが環境変数・`.env`・`.secrets/novelai.env`・`.secrets/.env` の１か所へ揃える |
| 値は１行にしてください | 人間が編集した本文の途中の改行を除き、１行で保存する |
| テキストが見つからない | 人間がCodexから案内されたファイル名と反映コマンドを確認する |
| 設定を変えたのに変わらない | 人間が新しい候補を生成・採用したか確認する。Codexが要求の変数参照を確認する |
| buildが失敗する | 人間がエラーをCodexへ伝える。Codexが採用・ページ構成・文字配置・組版環境を確認する |

初期の要求を変数へ置き換える `templatize` は、同じ文がある箇所をまとめて変更します。**Codexが初回の準備時に** `--dry-run` で対象を確認してから使います。人間の通常の編集では、Codexが設定した変数の本文を変更するだけでよく、`templatize` を毎回実行する必要はありません。
