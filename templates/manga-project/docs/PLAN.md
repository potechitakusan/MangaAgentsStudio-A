# 制作計画

状態: 新規作成。作品の内容は未設定。

最初の作業でOPTIONの実効値を解決し、[任意の推敲スキル](knowledge/optional-skills.md)を初期化する。有効なら自動導入し、無効なら取得しない。Git未導入時はインストールの許可を、Gemini版は環境の有無によらず導入前に文章送信・利用枠消費の許可を得る。推敲の導入保留中も通常の制作は進める。

1. キャラ・あらすじ・ページ数を受け取り、OPTION.mdの既定値でWeb用PNGの制作を始める。採用値を進捗へ、依頼と仮決めした詳細をdocs/story/BRIEF.mdへ記す。オプションや印刷の全項目への回答は求めない。
2. 登場人物と欲求・障害・結末を決め、シーンの変化を設計する。
3. 漫画の字コンテから本番量の文字を置いたネームを作る。必要な場面で複数案を比較し、通読・レビュー・統合改稿を行う。映画カットとの対応は必要時だけ使う。
4. 参照絵と少数の生成テストでキャラの基準を決め、コマを制作する。生成時の希望寸法と実寸を区別し、[ページ設定](knowledge/page-layout.md) に従って枠配置・最終PNGの寸法を決める。余白と線幅も換算する。
5. 採用した文字方向（既定は縦書き）とDIALOGUE.mdの用途別設定で文字を入れ、読み順・時間の切替・画面密度・移動のつながりを点検する。次ページでは採用済みの修正条件が当てはまるか確認する。
6. 指定された全ページのPNGを順序が分かる名前で作り、補助線がないことと掲載相当の寸法での可読性を点検してユーザーへ提示する。修正があれば反映・再提示し、最新のPNGについて修正がないことを確認する。
7. PSD作成の指示がなければ作るか聞いて回答を待ち、まだ作らない。既に指示があれば再確認しない。確認したPNGの版・対象ページ・回答と作成指示をdocs/production/PSD-HANDOFF.mdへ記録する。
8. PNGの修正確認とPSD作成指示がそろったら、対象ページのPSDを作成し、再読込・レイヤー・確認済みPNGとの合成結果の照合・全ページの通読を検証する。
9. セリフ原文とPSDの仕様・検証結果、人間に残す仕上げをdocs/production/へ記録して引き渡す。依頼されたPSDはここまでをCodex側の完了とする。
10. 人間がCLIP STUDIO PAINTで仕上げ、外部公開を判断する。フィードバックは記録を依頼された場合だけ残し、記録するかの確認はしない。

現在の依頼ごとに対象、成果物、完了条件を具体化する。PNG確認待ち・PSD作成回答待ちは正規の待機段階とし、返答なしを「修正なし」や作成指示とみなさない。PNGだけの依頼やPSD作成不要・保留の回答なら、その範囲と状態を記録する。

各工程の着手前にOPTION.mdの変更を確認し、採用済みのオプションを上の既定工程へ反映する。開始後の意図未確認の変更は関連作業への適用を保留する。

参照：[オプションの適用手順](knowledge/project-options.md)、[ノウハウ一覧](MANGA-KNOWHOW.md)、[PSD引き渡し](knowledge/psd-handoff.md)。CBZは明示指定時だけ作成する。
