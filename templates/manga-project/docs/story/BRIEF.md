# 作品の狙い

開始に必要なのはキャラ・あらすじ・ページ数。以下はCodexが依頼から整理し、未指定の詳細は仮決めする。全欄をユーザーの必須入力にしない。

- 指定されたキャラ・設定・参照：
- 指定されたあらすじ：

- 読者:
- 想定ページ数・話数:
- 右綴じページ漫画 / その他の形式:
- ジャンル・絵柄:
- 読み終えたときの感情:
- 主人公の欲求・欠けているもの:
- 障害・対立:
- 結末で変わること:
- 必ず描きたいシーン:
- 制約・避けたい表現:
- 今回の成果物と完了条件:

まずPNGプレビューで確認・修正し、修正がないことを確認してからPSD作成へ進む。PSD作成の指示がなければ作るか聞いて回答を待ち、既に指示があれば再確認しない。依頼されたPSDは作成・検証・引き渡しまで行う。人間がCLIP STUDIO PAINTで仕上げて外部公開する。

- PNGプレビューの対象ページ：
- PSD作成指示：なし（指示がある場合は内容・対象を記録）
- PSD対象ページ・レイヤー方針：
- 生成する画像の希望寸法／生成後の実寸：使用ツールに合わせる／生成後に確認
- 生成環境・モデル・契約プラン／Steps・１回の枚数・追加機能・費用条件：利用時に記録。Opusは [Anlasを消費しない条件](../knowledge/ai-production.md#novelai-opus)を適用
- 枠を合わせる寸法：１ページ全体の生成画像の実寸に合わせる。コマ別生成では組み立て先のページ寸法を決める
- 最終PNGの寸法：枠配置と同じ。別寸法を指定した場合は変換方法も記録
- Web用の色・表示形式：白地、RGB／sRGBを基準、単ページ（変更指定があれば優先）
- 基本枠・文字安全範囲：`config/page-layout.json`。印刷を選んだ場合だけ `PRINT-OPTION.md` を参照
- 人間が仕上げる内容：
- CBZ：作成しない（明示指定がある場合だけ対象を記録）

参照：[ノウハウ一覧](../MANGA-KNOWHOW.md)、[情報管理](INFORMATION-SHEET.md)、[PSD引き継ぎ](../production/PSD-HANDOFF.md)。
