## 読者体験と紙面

- 読者に追ってほしい人物・感情：
- 場面前→後の変化：
- 主人公と相手の目的・障害：
- 場所・時間・人物の位置関係：
- ページ形式・読む方向・開始位置：
- 単ページ／見開き／縦スクロールの表示単位：
- 読者が既に知ること／まだ知らせないこと：
- 最も大切な発見・選択と読後感：

## コマ候補

| コマ・予定ページ | 変化の単位 | 最初に見せる主対象 | 距離・角度・視点 | 実際に描く行動・反応 | 縦書きセリフ・内語と話者 | 音・効果 | 次へ渡す理解・間の役割 |
| --- | --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |  |

「悲しそう」だけでなく、目を伏せる、手を引くなど見える変化を書く。作者だけが知る内面を、読者へ既に伝えた情報として扱わない。

## ネームに配置して確認する

- 本番量の文字を置いた読み順と話者：
- 同時に見えると困る台詞・絵と、実際のめくり境界：
- 無言コマで誰の何を待つか：
- 左右・持ち手・出入口・視線・移動のつながり：
- 省略・統合・分割したコマと、保つ効果／失う効果：
- 比較案の差と採用理由：
