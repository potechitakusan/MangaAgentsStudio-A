## コマ候補

| コマ・予定ページ | 変化の単位 | 最初に見せる主対象 | 距離・角度・視点 | 実際に描く行動・反応 | セリフ・内語と話者（採用した文字方向） | 音・効果 | 次へ渡す理解・間の役割 |
| --- | --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |  |

「悲しそう」だけでなく、目を伏せる、手を引くなど見える変化を書く。作者だけが知る内面を、読者へ既に伝えた情報として扱わない。

原則として１コマに主動作を１つ置き、複数の動作を入れる場合は読者が同時に認識すべき関係を明記する。手や道具などの接点がある場面は、接触前・接触中・接触後のどの段階を描くか、誰のどの手が何に触れるかを記録する。人物を増やして説明を補わず、必要なら前後のコマへ分ける。

セリフ・ナレーションに「。」は使わない。「、」は１枠の本文が20文字以上で、長文を読みやすく区切るために必要な場合だけ使う。つながった吹き出し・ナレーション枠は１個として合算し、接続関係を記す。セリフの配置は原則上詰め。数え方と配置の詳細は [上詰めと句読点](../knowledge/japanese-manga-readability.md#dialogue-typesetting)を参照する。

回想・省略・同時進行がある場合だけ、該当コマに場面・時点の識別、出来事の前後と提示順、語る時点／描く時点、切替と戻りの手掛かりを付記する。時間が切り替わらないコマまで記入項目を増やさない。
