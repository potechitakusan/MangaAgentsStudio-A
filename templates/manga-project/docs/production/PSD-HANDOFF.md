# PSD引き継ぎ仕様と検証記録

まずPNGプレビューで確認・修正し、修正がないことを確認してからPSDを作る。PSD作成の指示がなければ作るか聞いて回答を待ち、既に指示があれば再確認しない。依頼されたPSDの完成範囲は作成・検証・引き渡しまで。人間がCLIP STUDIO PAINTで仕上げてから外部公開する。CBZは明示指定時だけ作る。詳細は [PSD引き渡しの条件](../knowledge/psd-handoff.md)。

## PNGの確認とPSD作成指示

- 現在の段階：未着手（PNG確認待ち／PNG修正中／PSD作成回答待ち／PSD作成不要・保留／PSD作成・検証中／PSD引き渡し完了）
- 最新のPNGプレビュー：パス・版・対象ページ・提示日時
- 修正内容と反映・再提示の記録：
- 最新のPNGに修正がないことの確認：未確認（ユーザーの回答・日時・対象の版を記録）
- PSD作成指示：なし（既に指示があれば、その回答・日時・対象ページを記録）
- PSDを作るかの質問と回答：未実施（既に作成指示がある場合は再確認不要）

返答なしを「修正なし」や作成指示とみなさない。PNGへの「修正なし」だけではPSD作成を始めず、作成指示も確認する。進捗にも現在の段階を記録する。

## PNGとPSDの共通仕様

PNGだけの制作でも必要な範囲を使う。印刷専用の設定・検証は [PRINT-OPTION.md](../../PRINT-OPTION.md) に記録し、Web制作で必須にしない。

- 対象の話・ページとページ順：
- 生成時の希望寸法／実ファイルの寸法：未確定／未確認（幅×高さ、１ページ全体かコマ別かも記録）
- 枠を合わせる寸法：既定は１ページ全体の生成画像と同じ。コマ別生成では組み立て先のページ寸法
- 最終PNGの寸法：既定は枠配置と同じ。実ファイルの幅×高さを記録
- 生成画像→枠配置→最終PNGの変換：元寸法・先寸法・倍率・手段。実寸未確認や未変換の状態を完了扱いしない
- 基本枠／文字安全範囲／枠線：`config/page-layout.json` の基準値・固定指定と、ページごとの `layout.json` の換算後の値
- 色の扱い・プロファイル：白地、RGB／sRGBを基準。実際の書き出し設定を記録
- 掲載先・表示寸法：未指定なら単ページとスマートフォン相当の縮小で点検
- 補助線：掲載PNGへ含めない。PSDでは独立した非表示レイヤー
- 仕様の出典・確認日／仮設定の項目：
- CLIP STUDIO PAINTの使用版：
- レイヤー構成の方針：
- CBZ作成：なし（明示指定があった場合だけ、依頼と対象を記録）
- 外部公開：人間が仕上げ後に判断
