# 確定セリフと文字配置の原文

セリフ・モノローグは既定で縦書き。採用した変更指定を優先する。絵中の短い説明は横書き可。PSD内の文字がCLIP STUDIO PAINTで再編集できることは前提にしない。絵から分離した仮配置と、この原文を引き継ぐ。

セリフは原則上詰めとし、縦書きの各列の書き出しを上でそろえる。セリフ・ナレーションに「。」は使わない。「、」は１個の吹き出し・ナレーション枠の本文が20文字以上で、長文を読みやすく区切るために必要な場合だけ使う。つながった枠は１個として合算する。本文の数え方は [上詰めと句読点](../knowledge/japanese-manga-readability.md#dialogue-typesetting)に従う。

## 作品の文字設定

未指定なら、最初のページでCodexが読みやすい会話の基準を仮決めし、掲載相当の寸法で確認して以降へ適用する。ユーザーにフォントの選択や全行の記入を要求しない。表は使う用途だけ記録し、数値を未確認の画像から推定しない。

- 基準のページ・コマ／確認用PNGと表示寸法：
- 使用フォント・代替候補・利用条件の確認先（フォントを使った場合）：
- 共通の文字方向・文字色・基準サイズと単位・行間・余白：
- セリフの文字揃え：原則上詰め（変更・例外があれば対象と理由を記録）

| 用途 | 基準から変える点 | 使う条件 | 例外・掲載寸法での確認 |
| --- | --- | --- | --- |
| 会話 | 基準 | 通常の発話 |  |
| 小声 | 声量を示す表現を選ぶ | 小さな発話 | 必要な文字を読めなくする縮小は避ける |
| 叫び | 大きさ・太さ・フキダシ等 | 声を張る場面 | 内語と混同しない |
| 内語 | 発話と区別する表現 | 心の中の言葉 | 視点人物を保つ |
| 説明 | 地の文・場所・時点等 | 必要な補足 | 台詞の読み順を妨げない |
| 効果 | 場面に応じた描き文字等 | 音・状態 | 意図した例外を残す |

長文は縮小だけで収めず、台詞・フキダシ・コマ配置の変更を比較する。好みのフォントや強調方式は会話で変更できる。具体的な採用値はここに一度記録し、次ページでは同じ用途に合うか確認する。フォントファイルの配布は別に利用条件を確認する。

制作メモの区切り記号をセリフへ混入させない。つながった枠は「配置の指示」に接続先の文字番号を記し、読点を使う箇所だけ、合計文字数と読みやすく区切る必要性を添える。訂正時は原文と仮配置を両方更新し、読み順・話者・誤字・句読点・上詰めを照合する。

文体推敲を選択したときだけ、原文と候補・採否理由を修正記録へ残す。意味・口調・含み・文字量を比べ、採用した原文だけを文字配置へ反映する。手順は [読みやすさ](../knowledge/japanese-manga-readability.md#optional-polish)。
