# コマ割りテンプレートと採用方針

更新日：2026-09-15。日本語右開きのページ漫画向けの初期設定と素材仕様。コマ割りを選ぶときに必要な節だけ参照する。

割合・制限は作品に合わせて変更できる。[OPTION.md](../../OPTION.md) で受け付けた設定を [適用手順](../knowledge/project-options.md) に従って設定JSONへ反映する。テンプレートを使用しない指定なら、テンプレート由来の配分・制限を要求しない。ユーザー指定を優先し、短編では比率の厳密な再現を求めない。４コマ漫画・縦スクロールなど形式が異なる場合は、この配分をそのまま適用しない。

## 選ぶ入口

- [コマ割り一覧](../../templates/panel-templates/index.html)：コマ数・基本／斜線／演出・用途で絞り込む。画像を押すと読む順と説明を拡大表示する。
- [全テンプレートJSON](../../templates/panel-templates/catalog.json)：形状・用途・読む順・素材パス。
- [作品設定JSON](../../config/panel-layout-policy.json)：検証する制限と割合の目安。変更時の正本。
- [20ページの採用例](../../templates/panel-templates/plan-example-20.json)：通常20ページの構成例。

## 79種類の内訳

| 種類 | 数 | 内容 |
| --- | ---: | --- |
| ３コマ | 9 | 上２・下１／上１・下２と各左右斜線、横長３段と横境界の両傾斜 |
| ４コマ | 3 | 上下２コマで左上・右下が広い案、右上・左下が広い案、上２・中１・下１ |
| ５コマ | 54 | ３配置×３種類の幅×２種類の高さ×直線／斜線Ａ／斜線Ｂ |
| ６コマ | 3 | ３段２コマ、各段の縦区切りが揃わない幅の組み合わせ |
| ２コマ・大コマ | 6 | 全面１コマ、上正方形下横長、上横長下正方形、上下均等２分割、上下大小２種 |
| 人物ぶち抜き | 2 | ５コマを基礎に、右／左の重ね描き領域を示す |
| 時間経過 | 2 | ５コマの横長枠を、大きさが変わる白コマ３つへ置換。適用後７コマ |
| 合計 | **79** | 基本の５コマ18種を一覧の初期表示にする |

### ５コマの組み合わせ

- 配置：上から `2-1-2`、`1-2-2`、`2-2-1`。
- 幅：２コマ段が等幅／最初の２コマ段が右広めで次が左広め／最初が左広めで次が右広め。両方とも右広め・両方とも左広めの案は作らない。
- 高さ：３段を約３分の１ずつ／横長の段を24％、２コマの段を38％ずつ。枠間隔を引く前の比率。
- 縦区切り：直線18種。全18種に対して斜線Ａ・Ｂを作り、斜線は計36種。Ａ・Ｂは２本の傾きを互いに逆向きにした左右反転の組み合わせ。
- 左右の幅は、左端から43％・57％を境界の基準とする。傾斜によって上下端で幅が変わる。

### ２コマの組み合わせ

- 上正方形下横長（`P2-top-square`）：上のコマが幅・高さともに等しい正方形（880×880）、下が横長コマ。人物や重要な対象を正方形でしっかり見せ、下に状況や台詞を置く。
- 上横長下正方形（`P2-bottom-square`）：上のコマが横長、下のコマが正方形（880×880）。上の横長で状況や風景を示し、下の正方形で人物の感情や決め絵を受け止める。
- 上下均等２分割（`P2-half`）：真ん中で上下均等に２分割した横長２コマ。２つの場面の対比や、静かな時間の流れを見せる。
- 上下大小（`P2-large-bottom`, `P2-large-top`）：上下の比率が0.3と0.7の横長２コマ。静かな余韻や大きな空間対比に用いる。

## 初期設定で検証する制限

以下はキットの既定値。作品で変更した場合は設定JSONの値を使う。

1. **横長３段を使ったら、次の使用まで間に４ページ以上を挟む。** ページ番号の差は５以上。p1で使ったら次はp6以降。
2. **任意の連続20ページで、横長３段は最大３回。** p1〜20、p21〜40という固定区間だけでなく、p2〜21、p3〜22なども検証する。
3. 傾斜付き横長３段も同じ `horizontal-three` 集計群に含める。傾斜やテンプレートIDを変えて回数制限を避けない。
4. **５コマの採用数を最多にする。** 機械検証では20ページ以上の計画で、他の各コマ数より５コマが多いことを確認する。

横長３段以外の同一テンプレートに、上記の４ページ間隔を必須として課してはいない。通常の配置も連続使用を避け、前後を見て選ぶ。連続見開きは２ページで一つの画作りとして判断する。

## 採用割合

制作開始時に、次の割合をデフォルトの目安として使い、作品や希望に合わせて変更できると一度説明する。数値の厳密な一致を合格条件にはしない。

| コマ数 | 通常20ページの目安 | 割合 |
| --- | ---: | ---: |
| ５コマ | 12 | **60％** |
| ４コマ | 3 | 15％ |
| ３コマ | 3 | 15％ |
| ６コマ | 2 | 10％ |
| 大コマ・２コマ | 演出に応じて調整 | - |

- 通常20ページの３コマ３回のうち、横長３段は２回を目安にする。残りは半ページ大コマを持つ配置へ。
- 斜めの５コマは、任意の20ページに１回以下が目安。種類が多くても採用数を増やさない。
- ぶち抜き・時間経過・２コマは、演出意図に応じて選ぶ。必須の割当てではない。
- 全テンプレートから等確率で選ぶと斜線の使用が増えるため、先にコマ数と用途を決め、その中から幅・高さを選ぶ。

設定変更は `config/panel-layout-policy.json` に反映する。割合は `recommended.standardPercent`、横長３段は `hardRules.horizontalThree` の間隔・窓幅・上限、最多のコマ数は `hardRules.mostCommonPanelCount` で変える。横長３段の検査は `enabled: false`、最多条件は `mostCommonPanelCount: null` で無効にできる。作品の判断は通常の進捗に残し、説明を再開のたびに繰り返さない。一覧HTMLと採用例は配布時の既定値を示す参考資料で、作品設定の変更を自動反映しない。

## ぶち抜き・時間経過の使い方

### 人物の登場

`FX-breakout-right` と `FX-breakout-left` は、元の５コマの読む順を残し、人物が段をまたぐ候補領域を示す。建屋横の全身像、扉の前の人物などに使える。

橙の破線は人物の占有予定域で、独立した時系列コマではない。実際の人物を置いた後、その輪郭にかかる枠線だけを消す。背景、顔、セリフを同じ領域へ詰め込まず、手前に大きく出る人物で後続コマの出来事を先に明かさない。枠PNG自体は消去前の基礎枠である。

### 時間経過

`FX-time-grow` と `FX-time-shrink` は、中央の横長枠を３つの白コマに置き換える。右から左へ、面積が段階的に増減する。元の５コマから実際には７コマになるため、比率の集計で５コマに数えない。

空白だけで時間経過が伝わるかは前後の絵次第。必要なら同じ物の光、湯気、指先など最小の変化を置く。コマの大小だけから経過時間を秒数で固定しない。

## 作画とファイル

| 形式 | 用途 |
| --- | --- |
| `svg/ID.svg` | 編集用。透明背景とコマ枠。コマごとにpolygonを保持。演出領域はガイドSVGで確認する。 |
| `png/ID.png` | 2000×3000画素、透明なコマ枠。番号・色面は入らない。作画に重ねる枠素材。 |
| `guides/ID.svg` | 読む順の番号、段ごとの色分け、演出領域付き。選択・ネーム用。 |
| `previews/ID.png` | 2000×3000画素の番号付き確認画像。 |
| `json/ID.json` | その１種類の概要・座標・用途・素材パス。 |

座標系は1000×1500、左上原点。枠は上下左右60内側。数値はSVGのユーザー単位で、透過PNGでは２倍になる。印刷用の判型やdpiを確定する規格ではない。

SVG／PNGはCLIP STUDIO PAINTの「コマ枠フォルダー」を直接作る形式ではない。CSPでの実読込は未検証。SVGの個別polygonとJSONから、必要な原稿寸法へ再生成できる。

## JSONの読み方

`catalog.json` の `templates` をスクリプトで用途・コマ数に絞り込み、全文を会話に読み込まない。IDが分かる場合は `json/ID.json` だけを読む。素材パスはカタログがある `templates/panel-templates/` を基準に解決する。個別JSONも同じ基準を使う。

| フィールド | 意味 |
| --- | --- |
| `id` / `name` / `summary` | 固定ID、日本語の名前、形と用途の概要 |
| `panelCount` / `rows` | 実際のコマ数、上から各段のコマ数 |
| `rowHeightRatios` / `splitPositionsFromLeft` | 段の高さと、各段の縦区切りの位置 |
| `widthPattern` / `shortWidePanel` | 幅の組み合わせ、横長枠を低くした派生か |
| `verticalTilt` / `horizontalTilt` | 傾きの座標差。角度の度数ではない |
| `usage` / `frequency` | 選ぶ目的、主力・少なめ等の頻度区分 |
| `restrictionGroup` | 横長３段の回数制限を共有する集計群 |
| `panels[].order` / `polygon` | 読む順、４頂点の座標。文字の読む順は作画時に別途設計 |
| `baseTemplateId` / `modifiers` | ぶち抜き・時間経過で元にしたテンプレートと変更条件 |
| `coordinateSystem` / `assets` | 個別JSONの座標系、SVG・PNG等への相対パス |

ページ別採用案は `pages` に `page` と `templateId` を並べる。

## 割当て案の検証

作品ルートから実行する。

```powershell
python scripts/validate_panel_plan.py <plan.json>
```

この検証は配置の割当てと設定値を照合する。絵と文字を入れた後の読みやすさはPNGで別途確認する。
