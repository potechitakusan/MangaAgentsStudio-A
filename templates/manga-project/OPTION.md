# 漫画制作のオプション

キャラ・あらすじ・ページ数を指定すれば、追加設定なしでインターネット公開用のページ漫画をPNGまで制作できます。「現在の設定」を書き換えるか、会話で変更を伝えてください。以下は配布時のデフォルトです。全項目に回答する必要はありません。

| 項目 | 現在の設定 | 変更例・補足 |
| --- | --- | --- |
| 掲載形式 | Web用の単ページ漫画・右から左 | 縦長の縦横比2:3を目安に、使用ツールに合わせる。見開き、横読み、縦スクロール、投稿先指定も可。白地・RGB／sRGBを基準にする |
| 生成する画像の寸法 | 使用する画像生成ツールに合わせる。実寸は生成後に確認 | 幅×高さで希望を指定可。完成ページの寸法とは別 |
| NovelAI Opusの生成条件 | Anlasを消費しない条件に合わせる。１回１枚・28ステップ以下（V5は初期値23、V4.5以前は28）。参照等の追加機能は使わない | NovelAIでOpusを使う場合だけ適用。実行前に0 AnlasとV5の利用上限の残量を確認し、不足時は回復待ち。有料利用は明示した範囲でのみ行う |
| 枠を合わせる寸法 | １ページ全体の生成画像と同じ | 絵・枠・文字を配置する作業用ページ。生成前は予定寸法で仮配置し、生成後に実寸と照合する。コマ別生成では組み立て先のページ寸法を決める |
| 最終PNGの寸法 | 枠を合わせる寸法と同じ（拡大なし） | 例：「最終PNGだけ幅2000×高さ3000px」。生成時の画素数を保証する指定ではない。比率が異なる場合は配置も調整する |
| 基本枠の余白 | ページ寸法に連動（基準2000×3000pxで上下左右120px） | ページ端からの距離。左右は幅、上下は高さに比例して換算。「左だけ80pxで固定」などの指定も可。はみ出しを一律禁止しない |
| 文字安全範囲の余白 | ページ寸法に連動（同じ基準で上下左右160px） | 必要な文字を端に寄せすぎない目安。寸法変更時に換算する。pxで固定する指定も可 |
| 枠線の太さ | ページ寸法に連動（同じ基準で10px） | 幅・高さの倍率の小さい方で換算。「6pxで固定」などの指定も可 |
| 基本枠ガイド | 表示しない | 「表示する」でネーム・編集用の別ガイドを作る。掲載PNGには常に含めない |
| 日本語推敲スキル | 使用しない | 「humanizer-jp」（Gemini不使用）または「japanese-natural-writing」（Gemini使用）。「使用する」だけならhumanizer-jp。有効時は作品での初回作業時に自動導入。Gemini版は利用枠の消費許可を必ず得てから導入 |
| 日本語推敲の対象 | 台詞・内語 | スキル有効時のみ。「説明文だけ」「作品紹介だけ」等も可。通常の誤字・話者・意味の点検は常に行う |
| コマ割りテンプレート | 使用する | 「使用しない」で自由にコマ割りを設計する。その場合、下の採用率・反復制限・斜め５コマの目安は適用しない |
| コマ数別の採用率 | ５コマ60％・４コマ15％・３コマ15％・６コマ10％ | 例：５コマ40％・４コマ30％・３コマ20％・６コマ10％。合計100％の目安。大コマ・２コマなどは演出に応じて調整する |
| 横長３段の反復制限 | 間に４ページ以上・任意の連続20ページで最大３回（傾斜版も合算） | 間隔・集計ページ数・上限を変更できる。「制限なし」も可 |
| 斜め５コマの頻度 | 任意の連続20ページで１回以下を目安にする | 回数を変更できる。「制限なし」も可 |
| セリフ・モノローグの文字方向 | 縦書き（絵中の短い説明は横書き可） | 「横書き」や場面ごとの指定も可 |
| PSD作成 | 作成指示がなければ、作るか聞いて回答を待つ | 「作成する」「作成しない」「保留」も可。作成指示済みなら再質問しない。作成はPNGの修正確認後 |
| CBZ作成 | 明示依頼時のみ | 「作成する」「作成しない」も可 |
| 動画試作 | 明示依頼時のみ | 「試作する」「試作しない」も可 |
| フィードバック記録 | 記録を依頼された場合のみ | 「制作の節目ごとに記録」「記録しない」も可。通常の進捗・修正・検証の記録は別に残す |

## 設定の扱い

- 生成画像の実寸が幅1024×高さ1536pxなら、既定では枠配置も最終PNGも1024×1536pxです。これは寸法の関係を示す例です。基準寸法2000×3000pxは余白・線幅の換算用で、生成や書き出しの指定ではありません。
- Opusの条件と公式出典は [Anlasを消費しない生成手順](docs/knowledge/ai-production.md#novelai-opus)を参照します。V5には回復式の利用上限があり、参照・編集機能にも別の費用条件があります。寸法とステップ数だけで無料とは判断しません。
- 印刷専用の設定は [PRINT-OPTION.md](PRINT-OPTION.md) に分けています。既定は使用しないため、Web制作では読む・埋める必要はありません。
- 枠の設定は [ページの寸法・基本枠](docs/knowledge/page-layout.md)、推敲の導入・許可は [日本語推敲スキル](docs/knowledge/optional-skills.md) を参照します。Gitがなければインストールしてよいか確認します。Geminiを使える環境でも利用枠の消費許可は省略しません。
- PSDの依頼例：「PNG確認後、絵・フキダシ・文字を分けたPSDも作って」。分離して制作した要素を動かせますが、文字が画像の場合は文字列を直接編集できません。台詞原文を一緒に渡します。

- このファイルがない場合、項目を削除した場合、現在の設定を空欄にした場合は、その項目のデフォルトで進めます。デフォルトは [オプションの適用手順](docs/knowledge/project-options.md) にも保存されています。会話で明示した指定があれば優先します。
- 制作開始時は採用する設定の要点を説明します。変更希望がなければ、そのまま進められます。
- 制作開始後に書き換えた場合は、開始・再開・次の工程への着手時に差分を確認し、意図した変更かを聞きます。項目やファイルの削除によるデフォルトへの復帰も同じ扱いです。
- 回答までは、その変更が関係する作業への適用を保留します。会話で既に変更を指示した内容を反映しただけなら、再質問しません。
- PNGの修正確認と、外部公開・送信の指示は別に扱います。このファイルの設定だけで、未確認のPNGを確認済みにしたり、外部公開したりしません。
