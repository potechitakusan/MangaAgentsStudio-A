# コマ割りテンプレート集 v1

**[一覧から選ぶ](index.html)**。全79種類。初期表示は主力の５コマ・直線18種類。

- 編集用SVG、作画に重ねる透過PNG、番号付きプレビュー、個別JSONを同じIDで用意した。
- [カタログJSON](catalog.json)に形・用途・読む順・コマ座標・素材パスを収録。
- [制作方針と使い方](../../docs/production/PANEL-LAYOUT-POLICY.md)に全種類の内訳、採用割合、ぶち抜き・時間経過、JSON仕様を記載。
- 初期割合の目安：５コマ60％、４コマ15％、３コマ15％、６コマ10％。制作開始時に説明し、作品とユーザー指定に合わせて変更できる。
- 横長３段の既定値は、使用の間に４ページ以上を挟み、任意の連続20ページで最大３回。傾斜版も合算する。作品の設定を優先する。
- ２コマは正方形と横長の組み合わせ（上正方形下横長、上横長下正方形）、上下均等２分割、余韻用大小を用意。
- [20ページの採用例](plan-example-20.json)を同梱。

SVGは1000×1500の座標系、PNGは2000×3000画素。透過枠PNGには番号や色面を入れていない。CSPのコマ枠フォルダーを直接作る形式ではなく、CSPでの読込は未検証。
一覧と採用例は配布時の初期設定を示す。作品設定JSONの変更は自動反映されない。座標を読むときは必要なIDの個別JSONを参照する。
