# 共通設定の記入例（APIキー・接続先URLなど）。実値は作品内の .env、.secrets/ または環境変数へ設定する。
# 設定ファイルは３つに分ける。
#   .env          APIキー・URLなどの共通設定（このファイルの見本）
#   .env.novelai  NovelAI用のキャラクター・絵柄・背景のプロンプト変数と補助設定（見本は .env.novelai.example）
#   .env.pixai    PixAI用のキャラクター・絵柄・背景・LoRAのプロンプト変数と補助設定（見本は .env.pixai.example）
# .env.example・.env.novelai.example・.env.pixai.example 自体は読み込まない。キーの実値をここへ書き込まない。
# 左辺の設定名は公開してよい。秘密にするのは右辺のトークン。Bearer接頭辞、メールアドレス、パスワードは不要。

# NovelAI（Persistent API token）。novelai_api.py の読込順: 環境変数 → .secrets/novelai.env → .secrets/.env → .env
# ファイル内にも設定名が必要: NOVELAI_API_KEY=実際のトークン
NOVELAI_API_KEY=

# PixAI（https://pixai.art/profile/edit/api で作るAPIキー）。pixai_api.py の読込順: 環境変数 → .secrets/pixai.env → .secrets/.env → .env
# ファイル内にも設定名が必要: PIXAI_API_KEY=実際のキー
PIXAI_API_KEY=
